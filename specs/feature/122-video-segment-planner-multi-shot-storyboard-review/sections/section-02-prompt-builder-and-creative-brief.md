# Section 02: Prompt Builder And Creative Brief

## Goal

Create the shared prompt builder and creative brief normalization layer. Marketplace initial handoff and Storyboard Review regeneration must both use this builder for final provider prompts.

## Depends On

- Section 01 shared contracts and planner.

## Files To Create

- `apps/web/shared/videoSegmentPlanner/promptBuilder.ts`
- `apps/web/shared/videoSegmentPlanner/creativeBrief.ts`
- `apps/web/shared/videoSegmentPlanner/__tests__/promptBuilder.test.ts`
- `apps/web/shared/videoSegmentPlanner/__tests__/creativeBrief.test.ts`

## Files To Reuse

- `apps/web/shared/hyperframes/autoReviewCreativePresets.ts`
- `apps/web/shared/storyboardPromptAudio.ts`

## Behavior

Implement:

- `normalizeVideoSegmentCreativeBrief(input)`
- `buildVideoSegmentPrompt(input)`
- dialect support for `generic`, `veo`, `kling`, and `seedance`

Prompt output must be plain text. It must include:

- segment objective;
- reference contract;
- sub-shot timeline;
- product facts lock;
- creative preset/brief guidance;
- audio policy;
- negative constraints.

For `separate_tts_voiceover`, forbid native speech and state that storyboard `voiceoverScript` and `shot.voiceover` are the single spoken source. For Thai/Seedance combinations, preserve the existing guard that Thai narration must be generated by separate TTS.

## Creative Brief Rules

The brief is guidance only. It may change tone, pacing, camera, and story emphasis. It must not change product identity, product claims, character identity, reference frame roles, provider policy, brand/logo/text, or Thai audio policy.

## Test First

Add tests for:

- plain-text output, no JSON wrapper;
- reference role text for each reference mode;
- multi-shot timeline with durations;
- preset directive included as guidance;
- creative brief included without overriding product locks;
- Thai separate TTS and Seedance guard;
- native audio only when capability supports it.
