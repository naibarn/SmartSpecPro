# Spec 231 PostgreSQL integration evidence

## Local run

Run the self-contained harness from any directory inside the repository:

```bash
apps/web/scripts/test-spec231-inference-postgres.sh
```

The script discovers installed PostgreSQL server binaries, creates a fresh temporary UTF-8 cluster and minimal referenced-table fixture, applies migrations 0353–0362 transactionally, runs the focused suite with DB integration enabled, and removes the temporary cluster on exit. It does not connect to or change the default PostgreSQL cluster. Set `PG_BIN` if the server binaries are installed outside `/usr/lib/postgresql/*/bin`.

For manual runs, the opt-in `persistence.integration.test.ts` suite requires the Spec 231 migrations to be applied to a disposable database and an existing `tenants` row with ID `tenant-1`.

```bash
DATABASE_URL='postgres:///' \
PGHOST=/path/to/postgres-socket \
PGPORT=55432 \
PGUSER=postgres \
PGDATABASE=postgres \
RUN_INFERENCE_DB_TESTS=true \
npm test -- --environment jsdom server/services/inference/__tests__/persistence.integration.test.ts
```

The latest combined verification used PostgreSQL **17.11**, installed from the Debian repository. The self-contained harness created and removed its temporary cluster. This validates against that disposable version only; it is not a production clone or the PostgreSQL 15 target requested by the earlier G3 work.
