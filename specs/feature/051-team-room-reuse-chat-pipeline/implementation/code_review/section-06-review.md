### Summary

The `teamRunSkillExecutor.test.ts` unit test file (section-03) is well-structured and covers the critical contracts: LLM path exclusivity, skill resolution fallback chain, `nextSpeakerHint` parsing, and source-file negative assertions. The `teamRunIntegration.test.ts` file covers the happy-path routing scenarios correctly but undermines its own purpose by mocking `promptComposer` — the primary internal component it is supposed to validate. This means three plan-required scenarios (entity memory injection, consecutive-turn history continuity, and internal wiring validation) are absent, leaving the highest-value cross-section integration path untested. The conditional assertion guards on lines 305–310 further risk false-positive passes if a regression flattens the messages array.
