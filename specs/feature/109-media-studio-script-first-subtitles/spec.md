# Feature 109: Media Studio Script-First Subtitles For Storyboard Video

Version: 0.1
Date: 2026-05-03
Status: Proposed
Depends-on: 012-AddTextClip, 063-MediaStudioContentComposer, 102-fal-ai-gemini-3-1-flash-tts, deep_plan/feature/099-ElevenLabsDirectProvider, 108-elevenlabs-elevenagents-runtime-integration
Audience: Media Studio, Video Editor, Media Render Worker, Audio Generation, News Storyboard, i18n, QA

---

## 1. Executive summary

Media Studio should be able to create burned-in subtitles for generated storyboard videos by using the same script that drives voiceover or news narration.

The key product decision is **script-first subtitles**:

1. Prefer the exact `VOICEOVER SCRIPT`, `voiceoverScript`, or prepared audio script used to generate the voiceover.
2. In news mode, prefer the rewritten narration produced by the storyboard skill, not the visual video prompts.
3. Use speech-to-text only as an optional fallback or verification signal.
4. Add subtitle text clips to the Video Editor timeline before render.
5. Let the existing render pipeline burn the text clips into the MP4 via the established text/subtitle render path.

This avoids the main weakness of direct STT subtitle generation: transcription mistakes caused by music, mixed audio, AI voice artifacts, Thai segmentation, and video-native audio noise.

---

## 2. Current context

### 2.1 Existing subtitle/text render foundation

Feature `012-AddTextClip` introduced the foundation required for text/subtitle rendering:

- Video Editor has a `text` track.
- Shared media job conversion maps Video Editor `text` tracks to media timeline `subtitle` tracks.
- Python `render_mp4_h264` extracts text-capable clips and burns them into video with FFmpeg.
- The render worker can use ASS/libass for robust Unicode text rendering and drawtext for eligible fast-path cases.

This feature should reuse that path instead of introducing a separate subtitle renderer.

### 2.2 Existing Media Studio storyboard and audio flow

Media Studio already supports:

- video storyboard prompt generation
- separate voiceover workflows
- prepared audio-first storyboard timing
- existing/uploaded/library audio as a storyboard timing source
- companion voice/music tracks in generated Video Editor projects
- muting native video clip audio when external voiceover is used

The missing piece is converting the reliable script source into timed subtitle text clips.

### 2.3 Existing STT capability

SmartSpecPro has STT routes and media models such as ElevenLabs Speech-to-Text. These are useful, but for this feature STT should be optional because the text source is already known when:

- TTS was generated from text
- news mode rewrote narration into `VOICEOVER SCRIPT`
- the user supplied a voiceover script
- the user selected a prepared audio source that has an associated prompt/script

## 3. Problem statement

Users generate storyboard videos from news or voiceover text, then combine separate video clips and audio in Video Editor. They often need burned-in subtitles in Thai or English.

If subtitles are generated by transcribing the final video or audio directly:

- Thai transcription can be inconsistent with the original wording.
- AI voice pronunciation, music, and sound effects can reduce STT accuracy.
- Generated video clips may contain unwanted native audio unless muted.
- STT may rewrite punctuation, casing, names, technical terms, and numbers.
- News scripts can lose source nuance or caveats.

The system already has a better source of truth: the script used to create or align the voiceover.

Therefore the feature should produce subtitles from script text first, use timing from the known audio/video duration, and optionally use STT only to validate or repair alignment.

---

## 4. Goals

### 4.1 Product goals

1. Let users enable subtitles when sending storyboard output to Video Editor.
2. Generate Thai and English subtitle text from the same script used for narration.
3. Keep subtitles aligned with the external voiceover track and storyboard duration.
4. Let users review and edit subtitles before render.
5. Burn subtitles into the rendered video without requiring manual Video Editor work.
6. Reduce transcription errors compared with audio-only STT.

### 4.2 Engineering goals

1. Reuse existing Video Editor text track and media job render pipeline.
2. Keep subtitle generation deterministic enough for unit tests.
3. Avoid adding provider-specific subtitle logic to the render worker.
4. Preserve existing storyboard/video/audio flows when subtitles are disabled.
5. Keep the first implementation local and synchronous in the frontend/domain layer; defer STT verification to a later phase.

---

## 5. Non-goals

1. Do not implement karaoke/word-by-word highlighting in the first phase.
2. Do not make STT the default source for subtitles when a script exists.
3. Do not hardcode Thai-only or English-only subtitle behavior.
4. Do not introduce a new video render engine.
5. Do not require ElevenLabs or any specific provider for subtitle generation.
6. Do not replace the existing text track editor.
7. Do not create soft subtitle muxing as the MVP output. Burn-in is enough for this feature.

---

## 6. Source priority

Subtitle source text must be resolved in this order:

1. Explicit user-edited subtitle text, if provided in the review panel.
2. `VOICEOVER SCRIPT:` from the storyboard skill output.
3. `audioWorkflow.voiceoverScript` / `voiceoverScript` structured skill output.
4. Prepared storyboard audio script used for audio-first timing.
5. Media Studio `voiceoverScript` field.
6. News mode rewritten narration.
7. News source text, only if no rewritten narration exists.
8. Attached audio asset prompt/metadata, if it plausibly contains the script.
9. STT transcript from selected audio, only as fallback.

Video generation prompts must not be used as subtitle text because they contain visual directions, camera notes, and continuity locks rather than spoken narration.

## 7. Subtitle timing strategy

### 7.1 MVP timing

The MVP should use deterministic proportional timing:

1. Determine total subtitle duration:
   - prefer companion voiceover visible duration
   - else use prepared audio duration
   - else use project/video duration
2. Split script into subtitle cues.
3. Weight each cue by estimated speech units:
   - English: word count with punctuation pauses
   - Thai: character/grapheme length with punctuation pauses
   - mixed language: combined units
4. Allocate cue durations proportionally across the total audio duration.
5. Add small gaps or merge very short cues to avoid flicker.
6. Clamp cue start/end to the project duration.

### 7.2 Segmented audio timing

If Media Studio generated multiple TTS segments, subtitle generation should respect segment boundaries:

- Each segment gets its own script slice when available.
- Cue timings are allocated within each segment duration.
- Cue boundaries should not cross segment boundaries unless the source script cannot be split safely.

### 7.3 Future timing improvement

Later phases may add:

- STT verification against the generated audio.
- Word timestamps from providers that support them.
- Forced alignment.
- Manual drag handles in the Video Editor subtitle track.

---

## 8. Subtitle cue generation rules

### 8.1 Shared rules

1. Preserve the original meaning and wording of the voiceover script.
2. Normalize whitespace and remove labels that should not be spoken, such as `Speaker 1:` when they are only structural labels.
3. Keep punctuation useful for reading.
4. Do not include visual prompt lines such as `Continuity Lock`, `Camera`, `Lighting`, `Background Visuals`, or `No subtitles`.
5. Prefer 1-2 lines per cue.
6. Avoid very long single cues that overflow mobile vertical video.
7. Avoid cues shorter than 0.8 seconds unless the full video is extremely short.

### 8.2 Thai rules

1. Split primarily on Thai and Latin punctuation:
   - `.` `!` `?` `,` `;` `:` `…`
   - `ครับ` / `ค่ะ` may be soft break candidates when followed by a new sentence-like phrase.
2. Do not split in the middle of common numeric, model, or brand-like tokens when avoidable.
3. Use character/grapheme count rather than whitespace-only word count.
4. Target shorter line lengths than English because Thai text can be visually dense.

### 8.3 English rules

1. Split on sentence punctuation first.
2. Split long sentences at commas, conjunctions, or phrase boundaries.
3. Preserve proper nouns, version names, and numbers.

## 9. Subtitle style defaults

The default subtitle style should be readable, neutral, and suitable for generated video:

### 9.1 9:16 vertical video

- Position: lower center around 78-84% of frame height.
- Font size: 52-64 px at 1080x1920.
- Color: white.
- Effect: outline or shadow.
- Text alignment: center.
- Max lines: 2.

### 9.2 16:9 landscape video

- Position: lower center around 82-88% of frame height.
- Font size: 44-56 px at 1920x1080.
- Color: white.
- Effect: outline or shadow.
- Text alignment: center.
- Max lines: 2.

### 9.3 Safety

1. Text must not overlap core UI controls or layout chrome in the editor preview.
2. Text must stay inside frame safe margins.
3. Generated subtitle clips should be editable as normal text clips in Video Editor.

## 11. Data model and API shape

### 11.1 Frontend domain types

Add a reusable subtitle domain model:

```ts
export interface StoryboardSubtitleCue {
  id: string;
  text: string;
  startTimeSeconds: number;
  durationSeconds: number;
  source: "voiceover_script" | "news_script" | "manual" | "stt_fallback";
  language?: "th" | "en" | "mixed" | "auto";
  confidence?: number;
  warnings?: string[];
}

export interface StoryboardSubtitleOptions {
  enabled: boolean;
  source: "auto" | "voiceover_script" | "news_script" | "manual" | "stt_fallback";
  language: "auto" | "th" | "en";
  manualText?: string;
  stylePreset?: "default" | "large_mobile" | "minimal";
}
```

### 11.2 Storyboard project options

Extend `BuildStoryboardProjectOptions`:

```ts
export interface BuildStoryboardProjectOptions {
  projectName?: string;
  defaultDurationSeconds?: number;
  companionAudio?: StoryboardCompanionAudioCandidate[];
  muteVideoClipAudio?: boolean;
  subtitles?: {
    enabled: boolean;
    cues: StoryboardSubtitleCue[];
    stylePreset?: "default" | "large_mobile" | "minimal";
  };
}
```

### 11.3 Text clips

Generated subtitle cues should become normal text clips:

- track: first unmuted `text` track
- `startTime`: cue start
- `duration`: cue duration
- `trimIn`: 0
- `trimOut`: cue duration
- `textConfig.text`: cue text
- `textConfig.fontFamily`: existing render-safe default
- `textConfig.fontSize`: style preset by aspect ratio
- `textConfig.color`: `#FFFFFF`
- `textConfig.effect`: `outline` or `shadow`
- `transform.x`: 0.5
- `transform.y`: aspect-ratio-specific lower-center position

## 12. Implementation plan

### Phase 1: Deterministic subtitle domain helpers

Add `apps/web/client/src/lib/mediaStudioSubtitles.ts`.

Responsibilities:

1. Resolve subtitle source text from known Media Studio/storyboard state.
2. Normalize script text.
3. Detect language.
4. Split text into cue text blocks.
5. Estimate timing from total or segment durations.
6. Build Video Editor text clips from cues.

Tests:

- Thai script split does not rely on spaces.
- English script split preserves sentence order.
- Mixed Thai/English script keeps model/version tokens intact.
- Cue timings cover the target duration without exceeding it.
- Very short cues are merged or clamped.
- Empty/visual-only prompt text returns no cues and a warning.

### Phase 2: Storyboard project integration

Update `apps/web/client/src/lib/storyboardVideoProject.ts`.

Responsibilities:

1. Accept subtitle options/cues.
2. Find or create text track.
3. Add subtitle clips with deterministic styles.
4. Preserve existing audio/video behavior.
5. Store cue metadata in `generationExtraParams` or clip metadata where appropriate.

Tests:

- `buildStoryboardVideoProject` creates text clips when subtitles are enabled.
- Subtitle clips align to project duration.
- Existing companion audio tests still pass.
- Disabled subtitles produce no text clips.

### Phase 3: Media Studio UI and state wiring

Update Media Studio video/storyboard controls.

Responsibilities:

1. Add subtitle enable/source/language/style controls.
2. Auto-populate source from `VOICEOVER SCRIPT`, prepared audio script, or news narration.
3. Show review panel with generated cues.
4. Pass subtitle cues into `buildStoryboardVideoProject`.
5. Keep default disabled unless a script source exists, or default enabled only for explicit separate voice workflow if product agrees.

Tests:

- Separate voice storyboard with script can generate subtitle preview.
- News mode uses narration script, not video prompts.
- Manual subtitle text overrides auto source.
- Existing video generation flow remains unchanged when subtitles are disabled.

### Phase 4: Render verification

Use existing render worker; add focused tests only if needed.

Responsibilities:

1. Verify text clips from generated subtitle project reach media timeline as `subtitle` track.
2. Verify render path extracts text clips and chooses ASS/libass for multiline or styled subtitle clips.
3. Ensure Unicode Thai subtitles survive render payload conversion.

Tests:

- `projectToTimeline` preserves generated textConfig.
- Render worker receives text clips with Thai Unicode.
- Existing media job tests still pass.

### Phase 5: Optional STT verification/fallback

Add later if MVP quality is insufficient.

Responsibilities:

1. Call configured STT provider for audio only when no script exists or user requests verification.
2. Compare transcript with source script.
3. Surface mismatch warnings such as:
   - "audio may not match script"
   - "subtitle source is longer than voiceover duration"
   - "STT could not verify Thai names/model numbers"
4. Do not silently rewrite script-first subtitles from STT unless user accepts changes.

## 13. Quality gates

### 13.1 Functional gates

1. User can generate storyboard video with separate voiceover and subtitles.
2. User can generate news narration storyboard and subtitles from the news narration.
3. User can open the generated project in Video Editor with text clips already present.
4. Rendered MP4 includes burned-in subtitles.
5. Thai and English subtitles render correctly.

### 13.2 Accuracy gates

1. Subtitle text must match script source exactly except for safe whitespace normalization.
2. Subtitles must not include prompt engineering lines.
3. Cue count and timing must be deterministic for the same input.
4. Total cue span must not exceed project duration.
5. Cue order must match script order.

### 13.3 Regression gates

1. Existing storyboard project generation without subtitles stays unchanged.
2. Existing companion audio alignment stays unchanged.
3. Existing render path for text clips continues to pass.
4. Existing Media Studio video generation is unaffected when subtitles are disabled.

## 14. Risks and mitigations

### Risk 1: Timing is not perfect without forced alignment

Mitigation:

- Use script-first text for accuracy.
- Use proportional timing for MVP.
- Support manual correction in Video Editor.
- Add STT/forced alignment later.

### Risk 2: Thai line breaking overflows video

Mitigation:

- Use Thai-aware character limits.
- Prefer 2-line cues.
- Use large safe margins and outline.
- Add visual preview and warnings.

### Risk 3: Script source differs from uploaded existing audio

Mitigation:

- Show source label and confidence.
- For existing audio with no trusted script, default to "review required".
- Offer STT fallback/verification.

### Risk 4: Video prompt text accidentally becomes subtitle text

Mitigation:

- Source priority excludes provider-facing video prompts.
- Filter known prompt engineering labels.
- Add tests with `Continuity Lock`, `Camera`, `Lighting`, `Background Visuals`, and `No subtitles` lines.

---

## 15. Acceptance criteria

1. A separate-voice storyboard project can be generated with subtitle text clips already placed on the text track.
2. The subtitle source defaults to `VOICEOVER SCRIPT` or the prepared voiceover script when available.
3. News mode subtitles use the rewritten narration, not visual prompt blocks.
4. Thai subtitle cues are generated without depending on whitespace tokenization.
5. English subtitle cues preserve sentence order and punctuation.
6. Subtitle clips have sane bottom-center styling for 9:16 and 16:9 videos.
7. Rendered output burns subtitles through the existing render path.
8. No subtitle clips are generated when subtitles are disabled.
9. Unit tests cover source resolution, cue splitting, timing allocation, and storyboard project insertion.
10. Existing storyboard audio/video tests remain green.

## 16. Open questions

1. Should subtitles be enabled by default for separate voice workflows, or only suggested?
2. Should the MVP include timing editing in Media Studio, or rely on Video Editor for timing corrections?
3. Should final render also export `.srt` or `.vtt` artifacts, or only burn-in subtitles?
4. Should subtitle style presets be global user preferences?
5. Should STT verification use ElevenLabs STT first when the selected voice provider is ElevenLabs?

## 17. Recommended MVP decision

Ship MVP with:

- script-first source resolution
- Thai/English deterministic cue splitting
- proportional timing from voiceover/project duration
- Video Editor text-track insertion
- burn-in render through existing text/subtitle pipeline
- review panel with warnings

Defer:

- word-level alignment
- karaoke subtitles
- automatic STT correction
- soft subtitle muxing
- multi-style subtitle templates beyond three presets
