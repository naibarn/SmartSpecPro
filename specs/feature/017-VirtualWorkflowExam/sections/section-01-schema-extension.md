### What is missing

| Column | Type | Purpose |
|---|---|---|
| `previewSvg` | `text` | Pre-generated SVG topology diagram string (generated by the SVG utility in Section 02) |
| `industry` | `json typed string[]` | Industry/sector tags (e.g., `["E-commerce", "Retail"]`) for filtering |

All five columns are nullable (no `.notNull()`) — this is intentional. The table may contain user-created templates that predate this feature, and those rows will not have these values populated.
