# Section 01 — Modular Runner Runtime

Inspect the real Runner package, installed Codex authentication, Modular Core routes, release target, and service controller. Establish a distinct Modular DEV Runner only when an existing authenticated Gateway enrollment/publication protocol is available for the Modular tenant. Never retarget `smartaihub-runner.service`, reuse its credentials, insert registry rows manually, or fabricate execution evidence.

Acceptance: a separate Runner service is enrolled against the verified Modular endpoint and publishes a fresh authenticated Codex capability/heartbeat; otherwise record the precise missing endpoint/controller and continue independent source work.
