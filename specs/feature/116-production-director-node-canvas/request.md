# Request

User feedback on 2026-05-22:

Production Director should not be implemented as a form that pushes Image/Video/Audio tab content below it. It should be a separate planning workspace where the user defines a goal, drags in assets from library/search, selects a planning skill, and lets an LLM create a node-based production plan/canvas similar to modern visual AI spaces.

The Production tab should focus on planning only. Image, Video, and Audio remain separate execution tabs. The generated plan should appear as editable React Flow nodes and edges, and the user should be able to revise/reconnect before approval and before any credit-spending generation.
