The public MCP Skills extension stable source (retrieved on 2026-09-28) describes `skills/list`, `skills/get`, ordinary `resources/read` for Skill files and optionally negotiated `resources/directory/read`; the format itself remains governed by the Agent Skills specification. This R1.2 pack does **not** invent any new MCP wire method. The strict public catalog is solely a proposed internal SmartAIHub product/API projection to reconcile with the existing gateway. Do not infer native client support without version-specific interoperability tests.
