## Historical R4 hardening deltas

The R2 companion incorporates the additional audit findings from passes 13–24. Implementers MUST preserve these behaviors across all interfaces:

1. **Decision-scoped research convergence:** research stops because current evidence is sufficient for a scoped decision, not because a provider claims completion or a fixed number of pages/rounds was reached.
2. **Blind-spot challenge:** consequential decisions receive a bounded check for missing stakeholder, failure mode, alternative mechanism, source class and local context.
3. **Branch Portfolio controls:** avoid near-duplicate alternatives and unbounded paid fan-out; dominated/parked branches retain evidence and can be revived when constraints change.
4. **Artifact-driven requirements:** visible outputs are requirement-elicitation instruments. `not right` feedback becomes typed preference/constraint/goal deltas or one minimal discriminating question rather than blind regeneration.
5. **Preference drift:** explicit later user intent supersedes future planning without rewriting historical decisions; inferred preferences remain provisional.
6. **Research Snapshot Manifest:** consequential synthesis pins source/tool/model/query/policy/evidence revisions without storing private chain-of-thought. Dynamic facts carry TTL and are selectively refreshed.
7. **Experiment feedback:** failure is classified before choosing targeted repair, more research, an alternate tool, or a new branch. Repeated identical failure trips a loop breaker.
8. **Governed knowledge compounding:** project-private findings remain local until explicit declassification/promotion into reusable Skills/templates/domain knowledge.
9. **Non-coercive option presentation:** do not force a single ranked winner when trade-offs are not commensurable; preserve reversible alternatives.
10. **Recursive research containment:** child questions have depth/fan-out/time/budget bounds and explicit parent-decision dependencies.
11. **Modality escalation:** image/video/2.5D/3D/BIM/code are interchangeable strategy lanes; visual realism never becomes measured truth automatically.
12. **Post-acceptance staleness:** accepted decisions may reopen; refresh only affected dynamic claims and provide impact preview.
13. **Semantic branch merge:** merge is a new synthesis revision with compatibility checks across assumptions, constraints, applicability, units, locale and time.
14. **Evidence applicability rebasing:** prior evidence is reused only after explicit context/applicability checks; Project membership alone is not enough.
15. **No model-vote truth:** multiple agents agreeing does not upgrade evidence unless independent qualifying sources support the claim.
16. **Independent evaluation:** deterministic validators and independent evaluator profiles prevent a generator from being sole acceptance authority.
17. **Source manipulation resistance:** source class, syndication, commercial bias and suspicious duplication are modeled instead of equating search frequency with truth.
18. **Partial-result transparency:** failed source/provider attempts remain visible so incomplete coverage cannot silently look complete.
19. **Cancellation/sunk-cost salvage:** cancel safe work, reconcile already-running external effects and preserve reusable artifacts without resurrecting obsolete branches.
20. **Long-lived context reconstruction:** active context is rebuilt from versioned Project Knowledge Packs, current decisions and evidence anchors rather than replaying entire transcripts.
21. **Domain adapter calibration:** adapters declare jurisdiction/units/assumptions/risk/fixtures and return `OUTSIDE_CERTIFIED_SCOPE` rather than extrapolate unsafely.
22. **Irreversible-effect boundary:** goal changes after purchase/deploy/publish/physical action create remediation paths; they are not fake rollbacks.
23. **Revocation propagation:** corrected/deleted sources and measurements trigger targeted dependency invalidation and re-evaluation.
24. **Cognitive-load control:** keep a small active comparison set while preserving the full branch portfolio for advanced inspection.
25. **Concurrent mutation safety:** stale user/agent/background writes cannot overwrite newer semantic state; CAS and semantic conflict review are mandatory.
26. **Quantified uncertainty:** numeric evidence retains precision/range/source class and uncertainty propagates through calculations.
27. **Locale/jurisdiction normalization:** original and normalized units/currency/tax/market applicability coexist; no silent cross-market assumptions.
28. **Cache/dedup safety:** reuse keys include authorization, variant, freshness, locale and goal context; semantic similarity is never authority.
29. **Source-rights governance:** adapters declare permitted acquisition, retention and redistribution; no access-control/paywall bypass.
30. **Delegated authority:** approvals/spend delegation are explicit, bounded, expiring, revocable and fully attributable.
31. **Durable decision rationale:** accepted decisions retain provider-independent evidence/rationale bundles without hidden chain-of-thought dependency.
32. **Observability/SLO:** coverage, freshness debt, contradictions, branch age, budget burn, cancellation and provider failures are measurable.
33. **Quality regression gate:** provider/model/parser changes require benchmark qualification and contamination-aware fixtures.
34. **Human correction protection:** expert/user corrections are versioned, auditable and cannot be silently overwritten by later extraction.
35. **Research debt:** accepted provisional paths carry explicit unresolved risk with owner/trigger/expiry/blocking class.
36. **Portability/graceful degradation:** canonical Project state remains exportable/readable/resumable even when a provider or adapter disappears.
