## Follow-up: thumbnail sizing correction

- **Cause:** the thumbnail stylesheet referenced `var(--spacing-20)`, which is not defined by the Astryx spacing scale. The browser discarded the width and height declarations, so the Astryx thumbnail expanded to the image's intrinsic size.
- **Fix:** `smartaihub-platform/main@fb3c66dd21938259a145e838f055b4a59b0abae0` changes the thumbnail to Astryx `--spacing-12` (48×48 CSS pixels). Astryx Lightbox keeps `object-fit: contain`, so the full source image remains visible without cropping or stretching for square (1:1), portrait (9:16) and landscape (16:9) images.
