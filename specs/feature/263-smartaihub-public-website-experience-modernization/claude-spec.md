# Synthesized Implementation Scope — Spec 263

## Objective

Modernize the unauthenticated public website into an outcome-led SmartAIHub experience with AI Film/Vertical Series as flagship proof, while preserving broader platform capabilities and safe authenticated handoffs.

## Authorities

- Spec 263 owns public positioning, content truth, route/discovery, conversion, accessibility, SEO, privacy, performance, trust, and rollout evidence.
- Spec 270 owns canonical design requests/artifacts, provider policy, component resolution, lineage, and visual verification.
- Spec 224 owns implementation, tests, and final verification. Billing, Film Studio, public APIs, and worker jobs retain their existing authorities.

## Required outcomes

1. Capture route/crawl/redirect/locale/metadata baseline and the minimum design, claim, asset, and traceability registries.
2. Establish SmartAIHub-owned public UI primitives, Astryx token/layout policy, and canonical design artifacts before high-fidelity page implementation.
3. Recompose homepage around real task/product evidence and the Film flagship, with truthful research/create/build/automation breadth.
4. Add a dedicated public Film destination with approved demo provenance, rights/disclosure, media fallback, and correct product handoff.
5. Preserve pricing, legal, trust, contact, marketplace, docs/blog, account, and authenticated routes with explicit metadata/index/locale behavior.
6. Remove stale public discovery claims for retired /workflows without reviving that path or engine.
7. Deliver bilingual responsive/accessibility UX, safe handoff/analytics, SEO, observability, rollback, and requirement evidence.

## Constraints

Do not invent pricing, customers, models, capability, performance, availability, or security claims. Do not put prompts in URLs/analytics or transmit private data externally. Use existing route/SEO/worker/authority seams. Production analytics, legal/rights, CDN/rollback, and indexed crawl evidence remain external release gates.
