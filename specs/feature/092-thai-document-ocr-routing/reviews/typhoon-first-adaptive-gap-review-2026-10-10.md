## Ten review passes

| Pass | Review dimension | Finding and disposition |
|---:|---|---|
| 1 | Architecture duplication | SPEC-267 already owns durable execution/capacity; SPEC-229 owns the document RAG index; SPEC-266 owns provenance/evidence. Add no queue, index, registry, or execution engine. |
| 2 | Existing integration compatibility | Preserve current Typhoon adapter, setting IDs, and deployment choices. Keep the existing ADE path available; do not force migration. |
| 3 | Typhoon-first policy | Make Typhoon the preferred Thai OCR route while keeping eligibility subject to configured route, availability, and tenant policy. |
| 4 | API quota / throughput | Replace product-level dependence on fixed vendor quotas with configurable capabilities and observed quota/`Retry-After` inputs to existing capacity admission. |
| 5 | Queue durability / recovery | Require SPEC-267 durable delayed retry, page idempotency/checkpoints, partial completion, cancellation, and restart recovery. Never retry completed pages needlessly. |
| 6 | Self-host feasibility | Make Local Runner optional; require capability, model/runtime, GPU/VRAM, resource-limit, compatibility, quality, and accepted-page cost evidence before production routing. |
| 7 | RAG / provenance correctness | Preserve original reference, source/page locations, structure, extraction version, uncertainty, and citations through SPEC-229/266. |
| 8 | Security / PDPA / tenant isolation | Every candidate route remains subject to credential, tenant, user intent, residency, external-processing, and rights policy. No implicit cross-tenant credential pooling. |
| 9 | Cost and operational complexity | Meter provider usage and successful accepted output through existing budget/billing owners; avoid a parallel OCR control plane. |
| 10 | Autonomous completion / guardrail deadlocks | Keep extraction quality, retrieval usability, and action safety separate; retain uncertain partial output where useful and reserve stronger validation for risk-sensitive use. Ordinary OCR requires no mandatory approval. |
