# Section 04 — Canonical Non-Git General Work

## Objective

Plan and prove a first bounded Chat-origin general-work task that can produce a verified artifact without requiring GitHub, a repository, branch or worktree.

## Requirement IDs

R1.2 §L–§N; R1.3.4; A41, A48, A64.

## Scope

Consume existing Work Context/Workspace, canonical job/outbox, Runner or approved cloud execution, Gateway/economic, Library/artifact and Task Control authorities. Start with read-only analysis/report output. Do not add a Workspace SoT or a parallel job/credit ledger.

## Prerequisites

G1 contract acceptance; existing executor and artifact ACL; non-production user/tenant; real Gateway, credit and execution authority. Git path remains optional and visibly absent.

## Deliverable and completion predicate

One canonical job and attempt produce a real report/artifact whose digest, provenance, Gateway usage and settled credit receipt correlate. Workspace ACL and stale/offline state are truthful. No Git metadata is fabricated.

## Verification and evidence

Authorization, replay, ACL, traversal/symlink, recovery and artifact integrity tests, followed by a real non-production receipt set. Mock Gateway or local fixture alone cannot satisfy A64.

## Blocker challenge

If no local Runner is available, use only an already approved cloud executor when the user/policy selected it and authority exists. Otherwise leave live completion pending and continue contract validation.
