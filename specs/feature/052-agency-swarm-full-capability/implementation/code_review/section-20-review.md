### Summary

The core backend work is solid: `agency_skill_input_mapper.py` and `agency_skill_discovery.py` are correctly implemented with good test coverage, the orchestrator integration follows established patterns, and the Zod validation in `agency.ts` is well-structured. However, four gaps require fixes before merge: (1) the internal auth env var name does not match the token the Node.js endpoint actually checks, causing silent auth failures in production; (2) the Python caller's `maxResults` cap of 10 exceeds the endpoint's hard `max(5)` limit, causing HTTP 400 for any node configured above 5 results; (3) the required Vitest test file for the two new Zod blocks is entirely absent; and (4) `SkillInputMapper.tsx` was created but never wired into `SkillCallForm`, leaving the feature's primary UI enhancement inert. The `ExportAsSkillDialog` is a no-op shell that should either be completed or explicitly marked deferred with a clear comment.
