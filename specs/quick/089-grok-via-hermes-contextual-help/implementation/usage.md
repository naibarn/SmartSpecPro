# Usage

- User account setup: open `/settings`, find **Grok via Hermes**, and select
  **Grok via Hermes Help**.
- Platform setup: open `/admin/settings` and select **Setup Help** on the Grok
  via Hermes card.
- Tenant rollout: open `/admin/tenants`, edit a tenant, and select
  **Setup Help** above Feature Flags.
- Worker App pairing: open `/workers/connect` from Worker App and select
  **Worker App Help**.
- Operations: open `/admin/monitoring` and select **Grok Media Help** in
  **Claw Workers**.
- Use the existing language control in the Help side panel to switch English
  and Thai.
