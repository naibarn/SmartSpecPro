# Request

Create complete contextual help for every Grok via Hermes UI surface. Help must
explain setup locations, connection scopes, operating steps, readiness,
monitoring, and troubleshooting in English and Thai. Each relevant page must
expose the existing Help side panel through a clearly labeled Help button.

## Scope

- User connections: `/settings`
- Platform and tenant administration: `/admin/settings`, `/admin/tenants`
- Private Worker App connection: `/workers/connect`
- Operations monitoring: `/admin/monitoring`
- Bilingual Markdown help content, contextual routing, and regression tests

## Non-goals

- Changing Hermes connection behavior, authentication, database schema, or
  deployment state
- Replacing the existing Hermes Agent Gateway help topic
