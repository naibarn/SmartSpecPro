# Stakeholder decisions

No additional interview was required after the user explicitly approved the
QC plan and instructed autonomous spec writing and implementation.

The approved decisions are:

- Minimum automatic pass is 9.0/10, not the guideline's illustrative 8/10.
- Maximum improvement budget is 10 rounds; the user may choose a lower budget.
- Baseline evaluation is mandatory; each improvement round is revise then
  evaluate; keep only the best candidate.
- Stop on pass or two consecutive non-improvements.
- Credits must be estimated and explained before QC starts, with reservation and
  refund semantics.
- Existing story/series content and existing duration/shot behavior must remain
  compatible.
- UI must show the rubric and state clearly in Thai and English.
- The implementation must use a distinct skill contract rather than silently
  repurposing the existing episode/script evaluation skill.
