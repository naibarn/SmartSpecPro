# Section 01: Skill Direction

## Goal
Reposition the skill as a cinematic video prompt director that upgrades a rough idea into a polished prompt with clear visual language, motion logic, and continuity guardrails.

## Deliverables
- Rewrite `skill.md` and `SKILL.md`
- Remove provider-specific prompt syntax
- Add explicit reference image handling guidance
- Define a cleaner output contract

## Key details
- The prompt should feel like a short director's brief.
- It should describe opening frame, motion progression, camera behavior, lighting, and finishing image.
- Guardrails should stay inside the main prompt language, not as a separate negative-prompt section.

## Risks
- If the prompt becomes too generic, it will lose cinematic specificity.
- If it stays too technical, it will remain inaccessible to non-expert users.
