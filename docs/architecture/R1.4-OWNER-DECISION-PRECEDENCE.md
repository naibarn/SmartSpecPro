## Conflict examples and resolution

- Historic 'all services use shared `smartspec`' → **Core only; legacy exception; no new Mini App domain data in Core**.
- Historic 'need all Cloudflare cutover gates green before any launch' → **new `smartsihub.com` isolated restricted beta may launch safe slices**; old SPEC-311 concerns retiring old runtime, not marketing new go-live as complete old migration.
- Historic 'Moli-first production' → **only optional eligible fast-path after SPEC-208 proof; Chromium remains compatible reference**.
- Historic 'every subscription makes every used Skill free' → **only newly authored app-exclusive Skill inside its exact subscribed app**.
- Historic 'all users need paid SmartSIHub subscription' → **account mandatory, paid platform plan optional unless an explicit offer says otherwise**.
- Historic 'any browser closure proves always-on cloud continuation' → **remote approved executor must remain available; offline sole Runner produces WAITING_FOR_EXECUTOR, not Running (Cloud)**.

**No live GitHub registry, actual database column or deployed Cloudflare Account was modified.** Repository checks were read-only, and the exact unverified production realities must be checked at implementation time without blocking independent safe work.
