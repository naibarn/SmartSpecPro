### Summary

The implementation is structurally sound and correctly extracts context-building logic from `chat.ts` and `teamRunSkillExecutor.ts` into a modular service. All five exported functions are present, error handling is non-blocking throughout, and the URL resolution and knowledgebase trimming logic faithfully matches the reference implementations. Two issues require fixes before merge: `buildTeamContext` has an unguarded non-null assertion on `request.teamContext` that will crash on misuse, and the `hasOverrides` flag relies on `JSON.stringify` key-order stability rather than an explicit accumulator flag. Two medium-priority gaps in test coverage should also be closed: the token-budget test case is entirely missing, and the entity memory fetching ignores `CHAT_ENTITY_MEMORY_BUDGET`, allowing unbounded memory injection that could silently exceed the intended 6K context budget.
