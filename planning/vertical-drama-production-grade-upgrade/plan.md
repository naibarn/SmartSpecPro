guided wizard with spot repair, quality QC + bounded auto-improve v2,
measured production-grade tie-in, and preset visual identity + verifiable
blending. Spec/contracts are final; this plan sequences the code.

## Hard Constraints

- All new behavior behind §17 flags, default OFF; flags-off = byte-compatible shipped behavior. Every agent must verify no regression to existing tests (24 files, 261+ green).
- No new generation paths: paid media calls stay on `mediaGenerationService` async submit + poll (repo hard constraint 4B).
- `shared/verticalDramaSeries/dialogueQuality.ts` is the ONLY speech estimator; constants unchanged.
- Append-only artifacts (run/artifact ledger, stage tags) — NO new tables. Only 2 nullable ADD COLUMNs (below).
- Memory kinds are varchar (no CHECK) → new kinds need no migration.
- DB Safety Protocol for the 2 columns: backup affected tables → apply → verify counts. Note: drizzle snapshot chain has a known pre-existing break → apply via manual SQL (`ALTER TABLE ... ADD COLUMN IF NOT EXISTS`) + update `drizzle/schema.ts` types, matching the Phase-2 precedent.
- Max 2 file-editing agents in parallel; DB ops single-owner (conductor).
