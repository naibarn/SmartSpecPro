#### 3. Brute-Force Protection

Use Redis to track verification attempts per chat_id:

```python
async def check_rate_limit(redis: Redis, chat_id: int) -> None:
    """
    Checks if chat_id has exceeded 5 attempts in the last hour.
    Raises HTTPException(429) if limit exceeded.
    """
    key = f"telegram:attempts:{chat_id}"
    count = await redis.incr(key)
    if count == 1:
        await redis.expire(key, 3600)  # 1 hour TTL
    if count > 5:
        raise HTTPException(status_code=429, detail="Too many verification attempts")
```

#### 7. Main Webhook Endpoint

```python
@router.post("/webhook/telegram")
async def telegram_webhook(
    update: TelegramUpdate,
    request: Request,
    db: Session = Depends(get_db),
    redis: Redis = Depends(get_redis)
):
    """
    Telegram Bot webhook endpoint.
    Handles /start {code} verification and account linking.
    """
    # 1. Validate webhook secret header
    await validate_webhook_secret(request, db)
    
    # 2. Extract message (return 200 OK if no message)
    if not update.message:
        return {"ok": True}
    
    message = update.message
    
    # 3. Validate private chat only
    if message.chat.type != "private":
        return {"ok": True}  # Ignore group/channel messages silently
    
    # 4. Extract chat_id and text
    chat_id = message.chat.id
    text = message.text or ""
    
    # 5. Handle /start {code}
    if not text.startswith("/start "):
        return {"ok": True}  # Ignore other messages
    
    code = text[7:].strip()  # Extract code after "/start "
    
    # 6. Check brute-force limits
    await check_rate_limit(redis, chat_id)
    
    # 7. Verify code
    verification_data = await verify_code(redis, code)
    if not verification_data:
        # Invalid/expired code
        return {"ok": True}  # Don't reveal error details to user
    
    user_id = verification_data["userId"]
    username = message.from_.username
    
    # 8. Update database (single statement)
    await link_telegram_account(db, user_id, chat_id, username)
    
    # 9. Send confirmation message
    bot_token = await get_bot_token(db)  # Fetch + decrypt from system_settings
    await send_telegram_message(
        bot_token=bot_token,
        chat_id=chat_id,
        text="✅ Your Telegram account has been linked to SmartSpecPro!"
    )
    
    # 10. Delete verification code from Redis
    await redis.delete(f"telegram:verify:{code}")
    
    return {"ok": True}
```

## Security Considerations

1. **Webhook Secret Validation:** Always validate `X-Telegram-Bot-Api-Secret-Token` header first. Without this, anyone could send fake webhook requests.

2. **Private Chat Enforcement:** Ignore non-private chat messages to prevent abuse (users adding bot to groups and triggering verification in public).

3. **Brute-Force Protection:** Limit verification attempts per chat_id (5/hour) and per code (3 total) to prevent enumeration attacks.

4. **Code Format Validation:** Reject codes that don't match `^[a-f0-9]{32}$` to prevent injection or parsing errors.

5. **Silent Failures:** Return 200 OK for invalid codes to avoid revealing system state to attackers.

6. **Constant-Time Comparison:** Use `secrets.compare_digest()` when comparing webhook secret to prevent timing attacks.

7. **Single Database Statement:** Update all four user columns in one statement to avoid partial state (e.g., chatId set but verified still false).
