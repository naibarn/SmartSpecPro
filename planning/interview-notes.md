# Interview Notes

**Q: What is the primary user flow for this feature?**
A: A user clicks "Draft with AI", enters a topic or prompt (e.g., "Why kids don't eat veg"), and the system generates 5 fully laid-out slides automatically, complete with text, AI-selected SVGs, and placeholder/AI images.

**Q: How will the layouts be determined?**
A: The LLM will choose from a predefined list of layout templates (e.g., SplitTextRight, SplitTextLeft, FeatureGrid) for each slide. A TypeScript Layout Engine will construct the actual x/y coordinates.

**Q: Will we generate real images via AI or use placeholders for now?**
A: If an image generation API is available in the backend, use it. Otherwise, use a placeholder image service (like Unsplash source) using keywords generated by the LLM.

**Q: How do we handle SVG Graphics?**
A: The LLM should select a generic category (e.g., "Health", "Communication"), and the backend will randomly select 1-3 matching SVG geometries from our existing `SVG_GRAPHICS` library that was built earlier.
