### Summary

The core Section 10 migration objective is correctly implemented: `MarkdownFileEditor` has been replaced by `UnifiedDocumentSurface` in `DocumentPreviewPanel`, all split-panel state variables and their associated UI blocks have been removed, the mobile tab type has been narrowed, and the resize handler signature has been simplified. The rollback comment is in place and `MarkdownFileEditor.tsx` is untouched. The primary concerns are: (1) a potentially unsafe `undefined` propagation when `uploadStatusById` lookup returns a record with a missing `item` field, which can corrupt `selectedItem`; (2) three missing i18n keys from both locale files (`strikethrough`, `divider`, `table` in the toolbar namespace) plus a value discrepancy on `editor.save.conflict`; and (3) the mobile-tab test is a non-asserting placeholder that provides no real regression protection. The diff also bundles significant out-of-scope functionality (OCR mode, upload pipeline UI, semantic search routing) that inflates the review surface — these changes appear correct individually but should be noted as scope creep relative to the section plan.
