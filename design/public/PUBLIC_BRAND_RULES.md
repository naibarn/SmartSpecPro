# SmartAIHub public brand rules

- SmartAIHub owns public identity, content, visual patterns, and acceptance criteria, independent of the component vendor.
- Use the existing SmartAIHub primary brand token through the scoped public theme. Do not override global colors or add the vendor CSS reset globally.
- Use the same centered page frame for public Home's bounded sections; set `margin-inline: auto` explicitly because Astryx `Section` does not center itself when a max width is set.
- Keep one clear primary action per narrative region and preserve existing approved destinations.
- Prefer tangible, truthful workflow explanation over generic AI imagery, fabricated dashboard screenshots, customer quotations, or decorative claims.
- Keep logos and language controls within the existing tenant-aware navigation shell.
