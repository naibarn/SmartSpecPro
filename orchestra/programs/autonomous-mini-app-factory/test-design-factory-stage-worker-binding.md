| Stage execution uses canonical `worker_jobs` + outbox | A ready DevelopmentRun stage creates one idempotent canonical job and publishes through the existing outbox; no parallel queue is created. | PostgreSQL integration, `apps/web/scripts/test-mini-app-factory-stage-worker-runtime.sh` | On `origin/main` a2971a43, `rg` found no Factory worker job type/producer/executor; only the inline callback executor was present. | PASS: `TMPDIR=/home/dev/.cache/codex/miniapp-runtime-tmp pnpm --filter @smartspec/web exec vitest run server/services/miniAppFactoryStageWorker.test.ts server/services/miniAppFactoryRunExecutor.test.ts server/services/__tests__/jobTransportAdapters.test.ts` (3 files, 13 tests), plus `pnpm --filter @smartspec/web run test:mini-app-factory-stage-worker-runtime` (disposable PostgreSQL 17; two stages, idempotent admission, transient retry/recovery, worker/outbox consumption). | Synthetic stage handler proves the binding contract, not production stage-handler configuration or external provider execution. |
| Worker is authorized from canonical job identity | Worker resolves the DevelopmentRun using job tenant and requesting user; payload cannot override them. | Unit and PostgreSQL integration, `miniAppFactoryStageWorker.test.ts` and runtime script | No worker binding exists. | PASS: PostgreSQL runtime harness executes the default registry handler; job context tenant/user scopes the persisted DevelopmentRun and source SHA is checked against its durable state. | Authenticated producer/API authorization remains the caller's responsibility. |
| Stage checkpoint precedes job settlement and resumes idempotently | Worker persists the stage checkpoint before succeeding; a retry after checkpoint returns an idempotent result without advancing another stage. | PostgreSQL integration, runtime script | No worker binding exists. | PASS: runtime harness confirms checkpointed SPEC automatically enqueues TEST, then transient TEST failure retries and recovers; duplicate admission reuses the same canonical job. | A hard process kill between checkpoint and job settlement is not injected in this harness; the handler idempotency path covers redelivery after the checkpoint. |
| Missing runtime fails closed and stays retryable | Unconfigured stage runtime does not fabricate success; canonical job remains retryable. | Unit, `miniAppFactoryStageWorker.test.ts` | No binding exists. | PASS: unit test asserts unconfigured runtime throws `FACTORY_STAGE_RUNTIME_NOT_CONFIGURED` classified retryable; no completion is fabricated. | Trusted worker startup composition must still register real stage handlers; only the disposable harness configures a synthetic handler. |
