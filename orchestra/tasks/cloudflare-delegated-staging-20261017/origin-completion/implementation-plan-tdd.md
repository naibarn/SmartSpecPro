Run `pnpm exec vitest run server/__tests__/auth-cookies.test.ts` from apps/web. **Completed: 12 passed; isolated Chromium proof also passed.**

Test partial provider writes and current-lease rechecks.

7. Regression/operations: production cookie/callback/health unchanged, parent-domain cookie collision test before custom-domain staging, bounded upload/SSE and WebSocket disposition, no duplicate schedulers/queue consumers, no DB relocation and no unintended IAM/DNS change. Missing permissions/configuration or unavailable tools remain NOT_RUN/BLOCKED for the exact action, never PASS.
