# SPEC-205 WSS Credential Rotation Test Design

| Requirement | Observable behavior | Test level/location | Expected RED evidence | Residual boundary |
|---|---|---|---|---|
| Active process adopts persisted token B | After storage changes A→B, the next keepalive and capability publication authenticate with B and receive an acknowledgement. | Loopback HTTP/WSS integration in `apps/runner-app/src/diagnostics.rs` or `transport.rs` tests. | Existing loop has no credential reload/handoff; mock sees A after B is written. | Synthetic credentials and local mock do not prove the installed Windows process. |
| Reconnecting after socket close adopts B only after explicit handoff | A socket close without replacing transport still authenticates with A; credential handoff creates a new transport/proof and authenticates with B. | `transport.rs` loopback WSS test. | Reconnect on an unchanged transport sends A. | Does not prove server deployment configuration. |
| Preserve session and tenant binding | B with a different session/tenant/runner identity is rejected before reconnect; no command/receipt is rebound. | Unit + loopback integration in diagnostics tests. | No current live-loop credential replacement path exists. | Server remains authoritative for token signature and policy. |
| Pending receipts remain idempotent | A failed delivery persists; after B is adopted, replay uses the same event/idempotency key and accepts a duplicate acknowledgement without re-execution. | Receipt journal + WSS loopback tests in diagnostics tests. | No live credential rotation/replay sequence exists. | Mock does not prove server database idempotency. |
| Active jobs/cancellation survive same-session rotation | Existing process and cancellation target remain bound to the original command/session; rotation does not start a duplicate command. | Focused process/journal tests in diagnostics tests. | No rotation path currently exists. | Does not prove arbitrary external agent behavior. |
| Failure/revocation/restart remain safe | Missing/invalid store, session mismatch, rejected B, network timeout, repeated rotation, and restart fail closed or recover using persisted receipts without credential leakage. | Unit + local mock tests. | Missing cases/path. | Process restart tests do not equal Windows service acceptance. |
| Exported diagnostics are sanitized and typed | Report contains credential revision, rotation time, transport recreation/ack state, and typed failure; never token/JWT/private-key/header material. | Unit serialization/redaction tests. | Current debug report has generic runtime error and no revision/ack timeline. | Desktop export acceptance still requires approved Windows review candidate. |
