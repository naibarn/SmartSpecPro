# Global progressive integration policy test design

| Requirement | Observable behavior | Test level and location | RED evidence | GREEN command | Residual boundary |
|---|---|---|---|---|---|
| A verified WorkUnit may integrate while its parent remains open | An independently mergeable verified slice reaches the normal integration path with `parent_spec_status=OPEN` | Policy unit: `skills/orchestra/tests/test_lifecycle_policy.py::test_open_spec_slice_integrates_then_resumes_next_ready_workunit` | Before implementation, missing merge-control facts still returned `INTEGRATE_NORMAL_PATH`; the continuation assertion also failed without a valid completion predicate | `python3 -m unittest skills.orchestra.tests.test_lifecycle_policy.AutonomousCompletionPolicyTests.test_open_spec_slice_integrates_then_resumes_next_ready_workunit -v` | Exercises deterministic policy decisions; not a live GitHub merge or preview deployment |
| Required integration controls cannot be omitted | Missing or false checks, freshness, slice readiness, authority, serialization, or safe main health returns `REPAIR_OR_RECONCILE` | Policy unit and AC-39/AC-41 scenarios | Before implementation, all ten missing/false gate variants incorrectly integrated | `python3 -m unittest skills.orchestra.tests.test_lifecycle_policy.AutonomousCompletionPolicyTests.test_safe_pr_integration_requires_slice_readiness_and_all_merge_controls -v` | Authority and impact facts are supplied by the configured repository/controller; this test does not independently authenticate them |
| Unrelated pre-existing baseline failures do not block a disjoint slice | A classified baseline failure allows integration only when task regression is absent and impact is disjoint | AC-40/AC-41 policy scenarios and focused unit | Before implementation, the kernel did not distinguish baseline health or task regression | `python3 -m unittest skills.orchestra.tests.test_lifecycle_policy -v` | Requires post-merge CI to detect regressions on the integrated SHA |
| Integration resumes the next WorkUnit from the recorded canonical SHA | After WU-1 evidence binds to the new canonical SHA, WU-2 is selected only when its completion predicate is machine-verifiable | Policy unit: `test_open_spec_slice_integrates_then_resumes_next_ready_workunit` | Initial test fixture without a completion predicate correctly remained waiting | Same focused command | Does not establish that an external PR was actually merged; integration mechanics remain owned by Integration Controller |
