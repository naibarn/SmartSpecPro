# Image, Video, and Audio Generation

## Generating media from Chat

All media generation starts in Chat. Describe what you want and the platform handles the rest.

- **Generate Image** — Start your message with `create image:` and describe the visual outcome you want. For example: `create image: a minimalist office desk with a laptop and coffee cup, top-down view, soft lighting`.
- **Generate Video** — Start with `create video:` for motion-focused outputs. For example: `create video: a serene mountain river flowing at sunrise, cinematic, 4K`.
- **Generate Audio** — Use this when you want voice narration, background music, or sound effects.
- **Prompt enhancement** — Already have a rough image idea but want a better result? Type your idea and use the **prompt-enhance** action to have the system refine the prompt before generating.
- **Reference images** — Attach a reference image and ask the model to edit, extend, or use it as a style guide.

## Media Studio

Generated media is saved to **Media Studio** where you can:

- Browse your generation history (last 7 days, up to 50 items).
- Download or share individual items.
- Re-use prompts to generate variations.

## Tips for better results

| Goal | Tip |
|---|---|
| Consistent style | Use a style reference image or mention the style explicitly in your prompt |
| Exact dimensions | Specify aspect ratio: `16:9`, `1:1`, `9:16` |
| Photorealistic image | Add `photorealistic, DSLR, 4K, detailed` to your prompt |
| Animation style | Specify motion type: `slow pan`, `zoom in`, `timelapse` |
| Improved prompt quality | Always try prompt-enhance on rough ideas before generating |

## Supported providers

Media generation routes to the best available provider for your request type. Providers include image, video, and audio AI services configured by your administrator. Available models may vary based on your account plan.
