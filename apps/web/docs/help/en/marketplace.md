# Marketplace

## What is the Marketplace?

The Marketplace is the central hub for discovering and installing community-created content — skills, pre-built agencies, and agency templates. Instead of building workflows from scratch, start from a proven starting point and customize it to fit your needs.

## Skill Marketplace (/marketplace)

The Skill Marketplace lets you browse and install AI skills created by the SmartAI Hub community and the platform team.

### Browsing skills

- Use the **search bar** to find skills by name or description.
- Filter by **category**: content writing, research, image generation, video, audio, analysis, productivity, and others.
- Sort by **most installed**, **top rated**, or **newest**.
- Each skill card shows the skill name, description, category icon, install count, and average rating.

### Installing a skill

1. Click a skill card to open the detail page.
2. Review the skill description, example prompts, and input fields.
3. Click **Install** — the skill is added to your account immediately.
4. The skill becomes available in the Chat slash-command menu (`/`) and in the Skills panel.

### After installing

- Installed skills sync automatically — no server restart required.
- You can uninstall a skill at any time from **Settings → Skills**.
- If a skill is updated by its author, you can choose to update to the new version from the Marketplace.

## Agency Marketplace (/agencies/marketplace)

The Agency Marketplace lets you discover complete, pre-built multi-agent teams ready to run.

### Browsing agencies

- Browse by **use case**: research, content creation, data analysis, video production, productivity.
- Each agency listing shows the agents involved, typical output type, average run time, and user rating.
- Click any agency to preview its agent configuration before installing.

### Installing an agency

1. Open an agency listing and review the agent setup.
2. Click **Install Agency** — it appears in your Agencies list immediately.
3. Open the agency and type your request to start a run.

## Agency Templates (/agencies/templates)

Agency Templates are curated starting points for the most common agency use cases. Templates are maintained by the platform team and are always up to date.

### Available template categories

- **Deep Research** — Multi-source research with executive summary, key findings, and recommendations.
- **Storyboard Planner** — Scene-by-scene video planning with dialogue, camera angles, and audio/video prompts.
- **Deck Builder** — Full presentation deck generation with slides, speaker notes, and graphic suggestions.
- **Comparison Agent** — Side-by-side option comparison with pricing, evidence links, and recommendations.
- **Custom** — Blank agency template for building entirely from scratch.

### Creating from a template

1. Go to **Agencies → Templates**.
2. Click any template card to preview it.
3. Click **Use Template** — a new agency is created with all agents and workflows pre-configured.
4. Give the agency a name and customize any agent instructions before your first run.

## Tips

- **Try templates first** before building from scratch — templates encode best practices for common workflows.
- **Check ratings and install counts** before installing a community skill or agency. Higher numbers indicate reliability.
- **Preview configurations** before installing agencies — understanding the agent structure helps you write better prompts.
- If a skill or agency does not perform as expected after installation, leave a rating and check if an updated version is available.
