# Skill Browser

## Overview

The Skill Browser gives you a full catalog of every skill available on the platform. You can search by name, filter by category, toggle individual skills on or off for your account, and control whether each skill activates automatically based on your message content. Group owners have additional controls for sharing private skills with their groups.

## Getting there

Click **Skills** in the main sidebar. The browser opens with a searchable, paginated grid of all skills your account can access.

## Key capabilities

- Search skills by name or description using the search bar
- Filter by category (image generation, video, audio, prompt enhancement, chat assistant, and more)
- Toggle a skill enabled or disabled — disabled skills are hidden from Chat and other surfaces
- Toggle auto-trigger on or off per skill — auto-trigger allows the system to activate the skill when it detects a matching intent in your message
- View skill details including description, author, tags, and credit multiplier
- Paginate through large skill catalogs without losing your search or filter state
- Group owners can manage which private skills are shared with specific groups

## Workflow

1. Open **Skills** from the sidebar.
2. Use the search bar to find a skill by keyword or browse by category using the filter dropdown.
3. Click the toggle on a skill card to enable or disable it for your account.
4. Click **Auto-trigger** on a skill to control whether it fires automatically when the system detects a match.
5. Click a skill card to open the detail view with full description, input schema, and configuration options.
6. If you own a group, open the sharing panel from the skill detail view to add or remove group access.

## Tips

- Disabling a skill only affects your account — it does not remove it for other users.
- Auto-trigger works best for skills with very specific trigger phrases. Disable it for broad skills to avoid unexpected activations during general chat.
- The category filter and search bar work together — you can combine both to narrow results.
- Credit multiplier shown on each card tells you how much that skill costs relative to a standard LLM call — useful for managing usage.
