# Create Presentations

## Triggering a presentation from Chat

You can generate a full slide deck directly from Chat. The AI understands natural language requests for presentations.

### Trigger phrases

- `create a presentation about...`
- `build a deck on...`
- `make slides for...`
- `write a presentation with X slides about...`

### Example requests

- `Create a 6-slide presentation on AI trends in 2026 with an executive summary slide`
- `Build a pitch deck for a fintech startup, 10 slides, include a problem, solution, market size, and team`
- `Make slides for a quarterly business review with charts and bullet points`

## Presentation parameters

| Parameter | How to specify | Example |
|---|---|---|
| Slide count | `X slides` | `8 slides` |
| Audience | `for investors`, `for a technical team` | `for a general audience` |
| Tone | `formal`, `casual`, `persuasive` | `formal executive tone` |
| Sections | List them | `include intro, problem, solution, roadmap, and call to action` |
| Visual style | Describe it | `minimal design, dark background` |

## How it works

1. You send a presentation request in Chat.
2. The AI generates a structured deck with titles, content, and speaker notes for each slide.
3. A **Preview Card** appears in Chat with a summary of the generated deck.
4. Click **Save as Presentation** to open it in the **Presentation Editor**.
5. Edit slides, rearrange content, apply themes, and export to your preferred format.

## Using the Presentation Editor

Once saved, your deck opens in the full Presentation Editor where you can:

- Edit slide content inline (click any text to edit).
- Add, remove, or reorder slides in the slide panel.
- Apply layout themes and background styles from the toolbar.
- Insert generated images into slides via drag-and-drop.
- Use the **AI Draft** button to regenerate content for individual slides.
- Undo/redo with keyboard shortcuts (Ctrl+Z / Ctrl+Shift+Z).

## Play Mode

Click the **Play Mode** button in the editor toolbar to present your deck:

- Full-screen slideshow with smooth transitions.
- Navigate with arrow keys or click.
- Press Escape to exit play mode.
- Accessible via direct link: `/presentation/{id}/play`.

## Exporting

- Click **Export** in the editor toolbar.
- Available formats: PDF export.
- Export runs as a background task — download link appears when ready.
- Exported files are saved to your Library for later access.

## Presentation Library

Navigate to **Presentations** in the sidebar to see all your decks:

- View, edit, duplicate, or delete presentations.
- Sort by date created or last modified.
- Quick preview thumbnails.

## Using Agencies for presentations

For more complex decks (investor presentations, full pitch decks), use the **Deck Builder** agency template instead of Chat. The agency uses a multi-agent workflow to research, outline, draft, and assemble a professional-grade deck automatically.
