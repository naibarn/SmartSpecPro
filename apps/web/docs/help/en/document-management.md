# Document Management

## Overview

Document Management is the central library for everything you upload, generate, or save on SmartAI Hub. Files created in Media Studio, attachments from chat, and manually uploaded documents all live here. Use it to find, organize, and reuse content across all features.

## Library view

- Browse all your files in a grid or list layout.
- **Filter by type** — Images, Videos, Audio, Documents, or All.
- **Search** by filename, tag, or date range.
- **Sort** by creation date, name, or file size.
- Thumbnails display inline for images and videos so you can identify content at a glance.

## Media History

Media History shows a chronological feed of AI-generated outputs — images, videos, and audio from Media Studio and chat generation requests.

- Retention: **12 days** and up to **100 items**. Older or excess items are removed automatically.
- Each entry shows the generation prompt, model used, creation time, and output.
- Click any item to open a detail view with download and re-use options.
- **Regenerate** — resubmit the original prompt with the same or a different model.
- **Copy prompt** — copy the generation prompt to use in a new request.

## Uploading files

- **Drag and drop** files anywhere on the library page to upload.
- **Click to browse** — use the upload button to open a file picker.
- Supported formats: JPG, PNG, GIF, WebP, MP4, MOV, MP3, WAV, PDF, DOCX, TXT, and common spreadsheet formats.
- Maximum file size: 50 MB per file.
- Uploaded files are available immediately in chat attachments, skills, and the gallery share flow.

## Organizing files

- **Create folders** — right-click in the file list or use the New Folder button.
- **Move files** — drag into a folder or use the context menu.
- **Tags** — add custom tags to files for cross-folder categorization.
- **Rename** files and folders inline by double-clicking the name.
- **Bulk select** — hold Shift or Ctrl/Cmd to select multiple files, then move, tag, or delete in one action.

## Sharing

- **Share a file** — generates a public link valid for 7 days, or set a custom expiry.
- **Publish to Gallery** — makes the item visible on the public Gallery page.
- **Embed link** — copy a direct URL for use in external tools or documents.
- Revoke a share link at any time from the file's detail panel.

## Storage

- Your storage quota is displayed in the library sidebar.
- Generated media counts toward your storage allowance; uploaded files also count.
- Delete items you no longer need to free space — deletions are permanent after a 24-hour grace period.
- Storage limits depend on your current plan — see **Settings → Billing** for details.
