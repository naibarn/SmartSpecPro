# My Feedback

## Overview

My Feedback shows all the support tickets you have submitted to the platform team. Each ticket has a type, status, and full conversation thread with admin replies. You can track the progress of bug reports, feature requests, observations, and general questions from a single page.

## Getting there

Click **My Feedback** in the sidebar or navigate directly to `/my-feedback`. To open a specific ticket directly, append `?ticketId=X` to the URL — for example, a link shared by an admin will include this parameter.

## Key capabilities

- View all your submitted tickets in a sortable list
- See current status for each ticket: open, in progress, resolved, or closed
- Read admin replies and the full conversation thread for each ticket
- View file attachments that were included with the ticket or added by admins
- Deep-link to a specific ticket using `?ticketId=X` in the URL
- Filter or sort tickets by type or status

## Ticket types

| Type | When to use |
|---|---|
| `bug` | Something is broken or behaving incorrectly |
| `feature_request` | A capability you would like to see added |
| `observation` | A note or concern that does not fit bug or feature |
| `question` | A question about how something works |

## Workflow

1. Open **My Feedback** from the sidebar.
2. Browse your ticket list. Tickets are sorted by most recent activity by default.
3. Click a ticket to expand the full detail view including description, status history, and replies.
4. Review admin replies in the conversation thread.
5. View or download any attached files using the attachment list in the detail panel.
6. To return to a specific ticket later, copy the URL — it includes `?ticketId=X`.

## Tips

- Status changes are shown in the conversation thread so you can see exactly when an admin picked up or resolved your ticket.
- File attachments are preserved for the lifetime of the ticket — you can access screenshots or documents you uploaded at any time.
- If an admin requests more information, you will see their reply in the thread. You can submit new feedback to follow up if the ticket has been closed.
- Use the `?ticketId=X` deep link when you want to share a specific ticket with a team member who also has access to the platform.
