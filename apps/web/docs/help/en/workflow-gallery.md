# Workflow Gallery

## Overview

The Workflow Gallery is the home screen for all your automation workflows. It lists saved workflows alongside available templates, lets you filter by category, and provides quick actions to run, edit, or delete each workflow. Use this page as the starting point whenever you want to launch an existing workflow or build a new one.

## Getting there

Click **Workflows** in the main sidebar. The gallery opens and loads your saved workflows and the template marketplace together.

## Key capabilities

- View all saved workflows in a card or list layout
- Browse the template marketplace for pre-built workflow patterns
- Filter workflows and templates by category
- Create a new blank workflow directly from this page
- Create a new workflow pre-loaded with a template
- Run a saved workflow without opening the full editor
- Edit an existing workflow in the Workflow Editor
- Delete saved workflows you no longer need

## Workflow

1. Open **Workflows** from the sidebar.
2. Browse your saved workflows and templates. Use the category filter to narrow the view.
3. To start from a template, click the template card and choose **Use Template** — this opens the editor pre-populated with the template's nodes and configuration.
4. To create a blank workflow, click **New Workflow** — this opens the editor with an empty canvas.
5. To run a saved workflow immediately, click **Run** on its card. The workflow executes and you can watch output in the run panel.
6. To modify a saved workflow, click **Edit** to open it in the Workflow Editor.
7. To remove a workflow, click the overflow menu on its card and select **Delete**.

## Tips

- Templates are a good starting point for common patterns such as content pipelines, research workflows, and media generation chains.
- Workflows you save appear at the top of the gallery so your most-used automations are always easy to find.
- The category filter applies to both your saved workflows and templates at the same time.
- Running directly from the gallery skips the editor — useful for workflows you have already configured and just want to re-execute.
