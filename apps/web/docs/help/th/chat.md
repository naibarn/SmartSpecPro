# คู่มือ Chat

## Chat เหมาะกับงานประเภทใด

Chat เป็นช่องทางที่เร็วที่สุดในการถามคำตอบ ร่างเนื้อหา ระดมสมอง สร้างพรอมต์ วิเคราะห์ และทำงานต่อเนื่อง เริ่มต้นที่นี่เมื่อต้องการโต้ตอบโดยตรงกับโมเดล AI และย้ายไปใช้ Browser Session หรือ Agencies เฉพาะเมื่องานต้องการพื้นที่ทำงานที่แตกต่างออกไป

## พื้นฐานการใช้ Chat

1. **พิมพ์ข้อความปกติ** เพื่อแชทกับโมเดลที่เลือก
2. **ใช้ตัวเลือกโมเดล** ด้านบนของบทสนทนาเพื่อเปลี่ยน LLM ที่ใช้งานได้ทุกเมื่อ
3. **ใช้ Persona Selector** ในแถบเครื่องมือเพื่อเลือก persona ที่คุยอยู่ในบทสนทนานี้
4. **ใช้ทีม AI** เมื่อต้องการให้โมเดลหลายตัวร่วมกัน — ไปที่หน้า Teams เพื่อเริ่มอภิปราย
5. **แนบไฟล์หรือรูปภาพ** เมื่องานต้องใช้เอกสารประกอบ เช่น เอกสาร ภาพหน้าจอ หรือรูปอ้างอิง

## Personas ใน Chat

- Persona ที่ active อยู่จะแสดงในแถบเครื่องมือด้านบนของบทสนทนา
- การเปลี่ยนจาก Persona Selector จะมีผลกับข้อความถัดไปทันที
- หากคุณตั้ง **default persona** ไว้ การสนทนาใหม่จะเริ่มด้วย persona นั้นโดยอัตโนมัติ
- หาก persona มี **nickname** คุณสามารถเรียกด้วย `@nickname` หรือเรียกชื่อเล่นตรงๆ เพื่อให้ระบบสลับ persona ให้
- การดูสถานะงาน ร่างงาน และ long memory จาก Chat จะอิง **persona ที่ active อยู่ตอนนั้น** เป็นหลัก

## Skills และคำสั่ง Slash

- พิมพ์ `/` ในช่องข้อความเพื่อเปิดเมนู slash-command skill และเรียกดู workflow ที่มีอยู่
- เปิดแผง **Skills** (ผ่านแถบเครื่องมือ) เพื่อควบคุมว่า skill ใดเปิดใช้งานในบทสนทนาปัจจุบัน
- ใช้ skills เมื่อต้องการให้ผู้ช่วยทำตามขั้นตอนเฉพาะทาง แทนการตอบแบบทั่วไป
- หากงานซ้ำๆ หรือเฉพาะด้าน ให้เลือก skill แทนการพิมพ์คำสั่งเดิมซ้ำทุกครั้ง
- Skills ทำงานผ่าน **ระบบ Unified Execution** — skill เดียวกันจะให้ผลลัพธ์เหมือนกันไม่ว่าจะเรียกใช้จาก Chat, Team Room หรือ Agency

## การสร้างรูปภาพ วิดีโอ และเสียง

- **Generate Image** — เริ่มต้นด้วย `create image:` แล้วอธิบายภาพที่ต้องการ เช่น `create image: โต๊ะทำงานมินิมอลพร้อมแล็ปท็อปและกาแฟ`
- **Generate Video** — เริ่มต้นด้วย `create video:` สำหรับผลลัพธ์แบบมีการเคลื่อนไหว
- **Generate Audio** — ใช้เมื่อต้องการเสียงพูด เพลง หรือเสียงประกอบ
- **Prompt enhancement** — พิมพ์ไอเดียคร่าวๆ แล้วใช้ action prompt-enhance เพื่อให้ระบบปรับปรุง prompt ก่อนสร้างสื่อ
- **แนบรูปอ้างอิง** — แนบรูปภาพและขอให้โมเดลแก้ไข ต่อยอด หรือใช้เป็น style guide ได้
- การสร้างสื่อมี **Rate Limit** — สูงสุด 15 ครั้งต่อนาทีต่อผู้ใช้ เพื่อให้ใช้งานได้อย่างเท่าเทียมทั่วทั้งแพลตฟอร์ม

## Memory

- เปิด **Memory** เพื่อดูข้อเท็จจริงที่บันทึกไว้ ความชอบ บทสรุป และบริบทที่เชื่อมกับโปรเจกต์
- ใช้ **Save to Memory** เมื่อข้อความมีสิ่งที่ต้องการนำมาใช้ใหม่ในอนาคต
- Memory รับรู้บริบทบทสนทนาและสามารถพาบริบทโปรเจกต์ข้ามการสนทนาต่อเนื่องได้
- ใช้ Memory เมื่อต้องการให้ผู้ช่วยจำความชอบที่คงที่ แทนการบอกซ้ำทุกครั้ง
- **Long memory** จะถูกโหลดตาม persona ที่ active อยู่ ทำให้แต่ละ persona มี memory ระยะยาวของตัวเองได้
- **Summary ของบทสนทนา** ยังอยู่ตาม session แชตเดิมตามปกติ แม้คุณจะสลับ persona กลางทาง

## งานของ Persona, Draft, และ Artifact

- หาก persona ที่กำลังคุยอยู่เป็นสมาชิกของทีมและมีงานค้าง ระบบสามารถใช้บริบทของงานนั้นมาตอบใน Chat ได้ดีขึ้น
- คุณสามารถถามลักษณะนี้ได้ เช่น:
  - `งานของน้องเจนมีอะไรค้างอยู่บ้าง`
  - `ข่าววันนี้เช็คไปถึงไหนแล้ว`
  - `ขอดู draft ล่าสุด`
  - `มีภาพหรือข้อความสำหรับโพสต์ถัดไปหรือยัง`
- ระบบจะพยายามสรุปสถานะงาน สิ่งที่เตรียมไว้ draft ล่าสุด artifact ที่อ้างถึง และการอัปเดตล่าสุดของห้องทีมนั้นให้
- การดึงบริบทแบบนี้จะอิง **persona ปัจจุบันเท่านั้น** ไม่ดึงงานของ persona อื่นมาปนในแชตเดียวกัน

## Approval และ Workflow จาก Chat

- หากงานของ persona อยู่ในสถานะรอมนุษย์อนุมัติหรือรอ feedback Chat จะช่วยอธิบายสถานะและขั้นตอนถัดไปได้
- หน้า Chat จะแสดง **action card / link** เพื่อพาไปยัง **Team Room** หรือ **Workflow Board** ที่เกี่ยวข้อง
- ใช้ลิงก์เหล่านี้เพื่อ:
  - เปิดห้องงานที่เกี่ยวข้อง
  - ไปยัง thread ที่ต้องตอบกลับ
  - เปิด Workflow Board ของห้องนั้นโดยตรง
- การ **approve / reject / send back** ยังควรทำใน Team Room ไม่ใช่ใน Chat โดยตรง

## เริ่มงานที่ติดตามได้จาก Chat

- ใช้การ์ด **เริ่มงานที่ติดตามได้** เมื่อบทสนทนานี้ควรกลายเป็น request จริง ไม่ใช่แชทที่ไม่มีการติดตาม
- เปิดหน้า **Work Request** เมื่อต้องการสร้าง request เอง
- เปิด **คู่มือ Work OS** ถ้าต้องการอธิบายแบบทีละขั้นว่าการรับงานเข้าระบบทำงานอย่างไร
- เปิด **Work OS Console** เมื่อต้องการจัดเส้นทาง request แนบงานเก่า หรือดู lifecycle ของงานแบบครบถ้วน
- ถ้างานมาจากระบบอื่น ให้ใช้ webhook หรือ API intake เพื่อให้ request เข้ามาใน Work OS โดยไม่ต้องคัดลอกเอง

## Browser Session จาก Chat

- ใช้ **Browser Session** เมื่องานต้องการเว็บไซต์จริง การเปรียบเทียบข้ามหน้าเว็บ หรือ workflow ในเบราว์เซอร์จริง
- เริ่ม Browser Session จาก Chat แล้วทำงานต่อในพื้นที่ live หรือส่งคำสั่งเบราว์เซอร์ด่วนจาก Chat ต่อได้
- Browser Session เหมาะสำหรับการหาเว็บไซต์ นำทางหน้าเว็บ เปรียบเทียบตัวเลือก และหยุดรอสำหรับขั้นตอนที่ต้องการอนุมัติ

## รูปแบบการใช้งานทั่วไป

| เป้าหมาย | สิ่งที่ควรทำ |
|---|---|
| คำตอบด่วน + บันทึกการตัดสินใจ | Chat → Save to Memory |
| เปลี่ยนคนคุยเป็น persona เฉพาะ | Persona Selector หรือพิมพ์ `@nickname` |
| workflow เฉพาะด้าน | พิมพ์ `/` แล้วเลือก skill |
| แนวคิดภาพพร้อม prompt ที่ดีขึ้น | พิมพ์ไอเดีย → prompt-enhance → Generate Image |
| ต้องการข้อมูลเว็บจริง | ย้ายไป Browser Session |
| เปรียบเทียบสองแนวทาง | ใช้ทีม AI |
| รายงานวิจัยหรือสไลด์ | ใช้ Agencies |
| ตรวจสถานะงานหรือ draft ของ persona | ถามใน Chat แล้วใช้ action card เพื่อเปิด Team Room / Workflow Board |
