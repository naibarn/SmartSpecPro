# เรียกดูสกิล

## ภาพรวม

หน้าเรียกดูสกิลเป็นศูนย์กลางสำหรับค้นหาและจัดการสกิล AI ทั้งหมดในระบบ คุณสามารถกรองสกิลตามหมวดหมู่ เปิดหรือปิดใช้งานสกิลแต่ละรายการ และกำหนดว่าสกิลใดควรทำงานโดยอัตโนมัติเมื่อตรวจพบจากข้อความของคุณ

## วิธีเข้าถึง

คลิก **สกิล** ในเมนูด้านซ้าย หรือพิมพ์ URL `/skills` โดยตรง หน้านี้แสดงรายการสกิลทั้งหมดที่มีในระบบพร้อมตัวเลือกการจัดการ

## ความสามารถหลัก

- ค้นหาสกิลตามชื่อหรือคำอธิบายด้วยช่องค้นหา
- กรองสกิลตามหมวดหมู่ เช่น การสร้างรูปภาพ การสร้างวิดีโอ การเขียน และการวิเคราะห์
- เปิดหรือปิดใช้งานสกิลแต่ละรายการตามความต้องการ
- เปิดหรือปิดโหมดออโต้ทริกเกอร์ ซึ่งช่วยให้สกิลทำงานอัตโนมัติเมื่อตรวจพบจากข้อความใน Chat
- จัดการการแชร์สกิลในกลุ่มหรือทีม
- ดูรายละเอียดสกิล ประเภทผลลัพธ์ และเครดิตที่ใช้ต่อครั้ง

## ขั้นตอนการใช้งาน

1. เปิดหน้าเรียกดูสกิลจากเมนูด้านซ้าย
2. ใช้ช่องค้นหาหรือตัวกรองหมวดหมู่เพื่อหาสกิลที่ต้องการ
3. คลิกสกิลเพื่อดูรายละเอียด เช่น คำอธิบาย ฟิลด์อินพุต และประเภทผลลัพธ์
4. สลับสวิตช์ **เปิดใช้งาน** เพื่อเพิ่มหรือนำสกิลออกจากรายการสกิลที่ใช้งานได้ใน Chat
5. สลับสวิตช์ **ออโต้ทริกเกอร์** หากต้องการให้ระบบตรวจจับและเรียกใช้สกิลโดยอัตโนมัติ
6. หากต้องการแชร์สกิลกับกลุ่ม ให้เลือกสกิลแล้วคลิก **แชร์กับกลุ่ม**

## เคล็ดลับ

- ปิดออโต้ทริกเกอร์ของสกิลที่มักถูกเรียกโดยไม่ตั้งใจ เพื่อป้องกันการใช้เครดิตโดยไม่จำเป็น
- สกิลที่ปิดใช้งานจะไม่แสดงในเมนู slash-command ใน Chat แต่ยังสามารถเปิดใช้งานคืนได้ทุกเมื่อ
- ใช้ตัวกรองหมวดหมู่ร่วมกับช่องค้นหาเพื่อค้นหาสกิลที่ต้องการได้อย่างแม่นยำ
- สกิลที่แชร์กับกลุ่มจะมองเห็นได้โดยสมาชิกทุกคนในกลุ่มนั้น
