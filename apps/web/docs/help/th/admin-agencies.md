# จัดการเอเจนซี่

## ภาพรวม

หน้าจัดการเอเจนซี่ช่วยให้แอดมินตรวจสอบ อนุมัติ หรือปฏิเสธเอเจนซี่ที่ส่งเข้ามาก่อนเผยแพร่บนแพลตฟอร์ม แต่ละเอเจนซี่ประกอบด้วยทีม AI agent ที่ทำงานร่วมกัน

## การตรวจสอบเอเจนซี่

ตารางหลักแสดงเอเจนซี่ที่ส่งเข้ามาทั้งหมดพร้อม:

- **ชื่อ** และคำอธิบาย
- **จำนวน agent** — จำนวน AI agent ในเอเจนซี่
- **สถานะ** — รอตรวจ, อนุมัติ, ปฏิเสธ หรือเผยแพร่แล้ว
- รายละเอียด **ค่าธรรมเนียม/แบ่งรายได้**
- **วันที่ส่ง**

กดแถวเพื่อขยายรายละเอียดเอเจนซี่

## ขั้นตอนการอนุมัติ

1. ตรวจสอบคำอธิบาย รายการ agent และการตั้งค่าของเอเจนซี่
2. ตรวจสอบเงื่อนไขการแบ่งรายได้และราคา
3. กด **Approve** เพื่อรับเอเจนซี่เข้าเผยแพร่
4. หรือกด **Reject** พร้อมหมายเหตุอธิบายเหตุผล

เอเจนซี่ที่อนุมัติแล้วจะปรากฏใน Agency Marketplace ให้ผู้ใช้เรียกดูและใช้งาน

## การจัดการเอเจนซี่ที่เผยแพร่แล้ว

- **Unpublish** — ถอนเอเจนซี่ออกจาก marketplace ชั่วคราวโดยไม่ลบ
- **Feature** — ทำเครื่องหมายเป็นเอเจนซี่แนะนำบนหน้าแรก marketplace
- **Edit** — แก้ไขการตั้งค่า ราคา หรือคำอธิบายเอเจนซี่

## รายได้และค่าธรรมเนียม

แต่ละเอเจนซี่สามารถกำหนด:

- **ค่าธรรมเนียมต่อการใช้** — เครดิตที่เรียกเก็บทุกครั้งที่ผู้ใช้รันเอเจนซี่
- **สัดส่วนรายได้** — เปอร์เซ็นต์ระหว่างแพลตฟอร์มและผู้สร้างเอเจนซี่

ข้อมูลเหล่านี้แสดงระหว่างตรวจสอบและปรับได้ก่อนอนุมัติ
