# การเชื่อมต่อ Grok ผ่าน Hermes

ไปที่ **การตั้งค่า > การเชื่อมต่อ > Grok via Hermes** การเชื่อมต่อนี้ใช้
สมาชิก Grok ของคุณผ่าน Hermes Media Worker เพื่อสร้างภาพและวิดีโอ
เป็นคนละระบบกับ **Hermes Agent Gateway** ที่ใช้เชื่อม external agent

## ทำอะไรได้บ้าง

บัญชีที่อนุญาตแล้วอาจรองรับ:

- สร้างภาพ
- แก้ไขภาพโดยใช้ภาพอ้างอิงได้สูงสุด 3 ภาพ
- สร้างวิดีโอ เมื่อแพลตฟอร์ม tenant และสิทธิ์ของบัญชีเปิดครบ

ให้ยึดความสามารถที่แสดงบนการ์ด connection เป็นหลัก การเชื่อมต่อสำเร็จ
ไม่ได้หมายความว่าบัญชีมีสิทธิ์ใช้ทุก operation

## เลือกประเภทการเชื่อมต่อ

### บัญชีกลางของ tenant

ผู้ดูแลเชื่อมบัญชี Grok หนึ่งบัญชีให้สมาชิกที่ได้รับสิทธิ์ใช้ร่วมกัน
โควตาและประวัติการสร้างเป็นของบัญชีกลาง เหมาะกับบัญชีทีม

### บัญชีส่วนตัวบนเซิร์ฟเวอร์

เชื่อมบัญชี Grok ของคุณเอง แต่งานรันบน server worker ที่ระบบดูแล
credential profile แยกจากผู้ใช้อื่น เหมาะเมื่อไม่ต้องการเปิดคอมพิวเตอร์ไว้

### เครื่องของฉัน (Worker App)

เชื่อมบัญชีและรันงานผ่าน Worker App บนเครื่องของคุณ แอปต้อง Online อยู่
เหมาะเมื่อบัญชีและ runtime ต้องอยู่บนเครื่องผู้ใช้

## ขั้นตอนเชื่อมบัญชี

1. ตรวจให้ readiness ที่จำเป็นของโหมดนั้นขึ้น **พร้อม**
2. เลือกประเภทการเชื่อมต่อ ถ้าเลือก **เครื่องของฉัน** ให้เลือก Worker App
   ที่ Online ซึ่งระบบแสดงให้
3. ยอมรับว่าการใช้งานจะหักจากสมาชิก Grok ของบัญชีที่เชื่อม
4. กด **เชื่อมต่อ**
5. เปิด URL ของ xAI และกรอก device code ที่หน้าจอแสดง
6. อนุญาตบน xAI แล้วกลับมาที่ Smart AI Hub
7. รอจนสถานะเป็น **เชื่อมต่อแล้ว**

Smart AI Hub จะไม่ขอรหัสผ่าน Grok, browser cookie หรือ access token ที่ต้อง
คัดลอกมาวางเอง

## ค่าเริ่มต้นและการทดสอบ

- ตั้ง **ค่าเริ่มต้นสำหรับภาพ** หรือ **ค่าเริ่มต้นสำหรับวิดีโอ** เมื่อมี
  connection ที่ใช้ได้มากกว่าหนึ่งรายการ
- กด **ทดสอบ connection** เพื่ออ่าน capability และ entitlement ล่าสุด
- เมื่อเริ่มสร้างงาน ระบบอ่าน connection และขอบเขตการแชร์ปัจจุบันจากฐานข้อมูล

## เมื่อเชื่อมต่อไม่ได้

- **แพลตฟอร์มหรือ tenant ปิดอยู่:** ให้ผู้ดูแลทำตาม
  [การดูแล Grok ผ่าน Hermes](./grok-via-hermes-admin.md)
- **Server worker ไม่พร้อม:** ผู้ดูแลต้องติดตั้ง/จับคู่ host worker และตรวจ
  version กับ heartbeat
- **Worker App Offline:** เปิดแอปและรอจนสถานะ Online
- **ต้องเชื่อมต่อใหม่ / authorization หมดอายุ:** กด **Reconnect** และอนุญาตใหม่
- **Entitlement restricted:** บัญชี Grok ยังไม่ประกาศสิทธิ์ operation ที่ต้องการ
- **Quota หรือ rate limit:** รอ provider reset หรือใช้ connection อื่น

ไม่ควร reconnect บัญชีที่ยังปกติเพื่อแก้ Worker Offline เพราะเป็นคนละเงื่อนไข
