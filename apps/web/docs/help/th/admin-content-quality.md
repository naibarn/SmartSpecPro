# แดชบอร์ดคุณภาพเนื้อหา

## ภาพรวม

แดชบอร์ดคุณภาพเนื้อหาช่วยให้แอดมินติดตามว่าเนื้อหาที่ AI สร้างออกมานั้นมีคุณภาพดีเพียงใด ระบบวัดผลจากหลายมิติและแสดงแนวโน้มตามเวลา เพื่อให้คุณสังเกตเห็นการเสื่อมลงของคุณภาพได้รวดเร็วและแก้ไขได้ทัน

## ตัวชี้วัดคุณภาพ

ระบบประเมินเนื้อหาจาก 3 มิติหลัก:

### ความแม่นยำ (Accuracy)

วัดว่าเนื้อหาตรงกับข้อมูลและคำขอของผู้ใช้มากน้อยเพียงใด เนื้อหาที่ผิดข้อเท็จจริงหรือไม่ตรงประเด็นจะได้คะแนนต่ำ

### ความเกี่ยวข้อง (Relevance)

วัดว่าเนื้อหาตอบโจทย์ความต้องการของผู้ใช้จริงๆ หรือไม่ ตรวจสอบจาก feedback ที่ผู้ใช้ให้หลังได้รับผลลัพธ์

### ความสมบูรณ์ (Completeness)

วัดว่าเนื้อหาครอบคลุมครบถ้วนตามที่ขอหรือไม่ เช่น บทความที่ขาดส่วนสำคัญหรือตอบแค่บางส่วนของคำถาม

## การกรองข้อมูล

ปรับมุมมองข้อมูลได้ด้วยตัวกรอง:

| ตัวกรอง | ตัวเลือก |
|--------|--------|
| **ช่วงเวลา** | วันนี้, 7 วัน, 30 วัน, กำหนดเอง |
| **Skill** | เลือกดูคุณภาพของ skill เฉพาะ |
| **Model** | เปรียบเทียบคุณภาพระหว่าง LLM models |
| **ผู้ใช้** | ดูแนวโน้มของกลุ่มผู้ใช้เฉพาะ |

## แนวโน้มคุณภาพ (Trends)

กราฟแสดงคะแนนคุณภาพเฉลี่ยตามเวลา แยกเป็น:

- **เส้นกราฟรวม** — ภาพรวมคุณภาพทุก output
- **เส้นแยก skill** — เปรียบเทียบคุณภาพระหว่าง skill ต่างๆ
- **เส้นแยก model** — ดูว่า model ไหนให้คุณภาพดีกว่าในบริบทใด

หาก **คะแนนลดลงอย่างกะทันหัน** อาจเกิดจาก model ถูกอัปเดต, prompt เปลี่ยน, หรือปัญหา API — ให้ตรวจสอบ audit log ในช่วงเวลานั้น

## การดำเนินการ

### แจ้งปัญหา Output คุณภาพต่ำ

เมื่อพบ output ที่มีคะแนนต่ำกว่าเกณฑ์ที่กำหนด:

1. คลิกที่รายการ output นั้นเพื่อดูรายละเอียด
2. กด **Flag as Low Quality** พร้อมระบุเหตุผล
3. ระบบจะสร้าง ticket ส่งให้ทีมเพื่อติดตาม

### ปรับ Prompt

หากพบว่า skill ใดสร้างเนื้อหาคุณภาพต่ำอย่างต่อเนื่อง:

1. กด **View Skill** เพื่อไปยังหน้าแก้ไข skill
2. ปรับ system prompt หรือ output format ในไฟล์ `skill.md`
3. ทดสอบโดยรัน skill กับ prompt ตัวอย่าง
4. ติดตามแนวโน้มคะแนนในสัปดาห์ถัดไป

## การแจ้งเตือนคุณภาพ

ตั้งค่าเกณฑ์แจ้งเตือนจาก **Settings > Quality Thresholds**:

- กำหนดคะแนนขั้นต่ำสำหรับแต่ละมิติ
- เลือกช่องทางรับแจ้งเตือนเมื่อคะแนนต่ำกว่าเกณฑ์ (email, Slack)
- กำหนดความถี่ในการตรวจสอบ (ทันที, ทุกชั่วโมง, รายวัน)

## เคล็ดลับการใช้แดชบอร์ด

- **ดูแนวโน้มรายสัปดาห์** — คะแนนรายวันอาจผันผวนได้ตามธรรมชาติ แต่แนวโน้มสัปดาห์บอกคุณภาพที่แท้จริงกว่า
- **เปรียบเทียบ model** — ใช้ตัวกรอง model เพื่อหา model ที่เหมาะที่สุดกับแต่ละ skill
- **ติดตาม skill ใหม่** — skill ที่เพิ่งสร้างควรได้รับการติดตามคะแนนอย่างใกล้ชิดในช่วง 2 สัปดาห์แรก
- **เชื่อมโยงกับ feedback ผู้ใช้** — คะแนนสูงจากระบบแต่ feedback ผู้ใช้ไม่ดี อาจหมายความว่าตัวชี้วัดยังไม่ครอบคลุมมิติที่สำคัญ
