# ตัวสร้างเวิร์กโฟลว์

## ภาพรวม

ตัวสร้างเวิร์กโฟลว์เป็นเครื่องมือแบบวิชวลที่ช่วยให้คุณออกแบบกระบวนการออโตเมชันโดยการลากและวางโหนดบนผืนผ้าใบ แต่ละโหนดแทนขั้นตอนการทำงานหนึ่งขั้นตอน เช่น รับข้อมูล ประมวลผลด้วย AI หรือส่งออกผลลัพธ์ ระบบรองรับการประมาณต้นทุนแบบเรียลไทม์และการทดสอบรันก่อนบันทึก

ความสามารถด้าน worker-runtime orchestration ยังเป็น rollout-gated ตัว editor ไม่ควรสื่อว่าทุก runtime ที่ระบบรู้จักมี drag-and-drop node ให้ใช้แล้วเสมอไป พื้นผิวสำหรับ dispatch, wait, publish และ indexing ของ worker จะปรากฏก็ต่อเมื่อ backend รองรับจริงและ tenant เปิด rollout flag ที่ตรงกันแล้วเท่านั้น

## วิธีเข้าถึง

ไปที่ **เวิร์กโฟลว์** ในเมนูด้านซ้าย แล้วคลิก **สร้างใหม่** หรือคลิกเวิร์กโฟลว์ที่มีอยู่เพื่อแก้ไข URL สำหรับสร้างใหม่คือ `/workflows/editor` และสำหรับแก้ไขคือ `/workflows/editor/:id`

## ความสามารถหลัก

- วางโหนดบนผืนผ้าใบแบบลากและวางจากแถบเครื่องมือด้านซ้าย
- เชื่อมต่อโหนดด้วยการลากจากจุดเชื่อมต่อของโหนดหนึ่งไปยังอีกโหนด
- กรอกฟอร์มแบบไดนามิกของแต่ละโหนดเพื่อกำหนดพารามิเตอร์การทำงาน
- ดูการประมาณต้นทุนเครดิตของเวิร์กโฟลว์ทั้งหมดก่อนรัน
- ทดสอบรันเวิร์กโฟลว์แบบเรียลไทม์และดูผลลัพธ์แต่ละโหนด
- บันทึกและตั้งชื่อเวิร์กโฟลว์เพื่อใช้ซ้ำในภายหลัง

## ขั้นตอนการใช้งาน

1. เปิดตัวสร้างเวิร์กโฟลว์จากหน้าแกลเลอรีหรือคลิก **สร้างใหม่**
2. เลือกโหนดจากแถบเครื่องมือด้านซ้ายและลากไปวางบนผืนผ้าใบ
3. คลิกโหนดเพื่อเปิดแผงคุณสมบัติด้านขวาและกรอกพารามิเตอร์
4. เชื่อมต่อโหนดตามลำดับที่ต้องการให้ข้อมูลไหล
5. ตรวจสอบการประมาณต้นทุนด้านล่างของผืนผ้าใบ
6. คลิก **ทดสอบรัน** เพื่อดูผลลัพธ์จริงก่อนบันทึก
7. ตั้งชื่อเวิร์กโฟลว์แล้วคลิก **บันทึก**

## เคล็ดลับ

- ใช้โหนดประเภท "เงื่อนไข" เพื่อแยกเส้นทางการทำงานตามผลลัพธ์ของขั้นตอนก่อนหน้า
- กดปุ่ม Ctrl+Z เพื่อย้อนกลับการเปลี่ยนแปลงบนผืนผ้าใบ
- คลิกขวาบนโหนดเพื่อดูตัวเลือกเพิ่มเติม เช่น ทำซ้ำหรือลบโหนด
- บันทึกเวิร์กโฟลว์บ่อยๆ ระหว่างการสร้างเพื่อป้องกันการสูญเสียงาน
- ถ้าเป็น flow ที่มี worker เข้ามาเกี่ยวข้อง ให้แยกสถานะเหล่านี้ออกจากกันเสมอ: dispatch accepted, worker execution completed, artifact publish completed, และ indexing completed เพราะ dispatch สำเร็จไม่ได้แปลว่าผลลัพธ์พร้อมค้นหาหรือพร้อมใช้งานแล้ว
