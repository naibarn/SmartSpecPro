# บันทึกการประสานงาน

## ภาพรวม

หน้าบันทึกการประสานงานแสดงประวัติการทำงานของ AI เอเจนต์และทีมในระบบ Virtual AI Office แอดมินสามารถติดตามว่าแต่ละรอบการทำงาน (Run) ดำเนินไปอย่างไร เอเจนต์ใดรับงาน ส่งต่องาน หรือตอบสนองอย่างไร ข้อมูลเหล่านี้มีประโยชน์อย่างมากในการดีบักปัญหา ปรับแต่งพฤติกรรมของเอเจนต์ และวิเคราะห์ประสิทธิภาพของทีม AI

## วิธีเข้าถึง

เข้าสู่ระบบในฐานะแอดมิน จากนั้นไปที่เมนูด้านซ้าย เลือก **Admin** และคลิก **Orchestration Logs** หรือไปที่ URL `/admin/orchestration-logs` โดยตรง

## ความสามารถหลัก

- ดูรายการรอบการทำงาน (Runs) ของทีม AI ทั้งหมด พร้อมสถานะและระยะเวลา
- ขยายดูรายละเอียดของแต่ละรอบ รวมถึง turn-by-turn interaction ระหว่างเอเจนต์
- กรองบันทึกตามทีม เอเจนต์ สถานะ หรือช่วงเวลา
- ค้นหาข้อความเฉพาะภายในบันทึกเพื่อหาเหตุการณ์ที่เกี่ยวข้อง
- ดู token usage และต้นทุนของแต่ละรอบการทำงาน
- ส่งออกบันทึกเพื่อวิเคราะห์ภายนอกหรือเก็บเป็นเอกสาร

## ขั้นตอนการใช้งาน

1. เปิดหน้า **Orchestration Logs** จากเมนู Admin
2. ใช้ตัวกรองด้านบนเพื่อจำกัดช่วงเวลาหรือเลือกทีม/เอเจนต์ที่ต้องการ
3. คลิกที่รอบการทำงานที่ต้องการดูรายละเอียด
4. ในแผงรายละเอียด ให้ดูลำดับการสนทนาและการส่งต่องานระหว่างเอเจนต์
5. หากพบข้อผิดพลาด ให้ตรวจสอบ error message และ stack trace ที่แสดงในบันทึก
6. ใช้ฟีเจอร์ค้นหาเพื่อหา trace ID เฉพาะหรือข้อความที่เกี่ยวข้องกับปัญหา
7. คลิกปุ่ม **Export** หากต้องการดาวน์โหลดบันทึกเป็นไฟล์ JSON

## เคล็ดลับ

- ใช้ trace ID ในการเชื่อมโยงบันทึกจากระบบนี้กับ log ที่อยู่ใน audit log ของระบบ
- รอบการทำงานที่ใช้เวลานานผิดปกติมักบ่งบอกถึง LLM provider ที่ตอบสนองช้า หรือ loop ที่ไม่สิ้นสุด
- หากเอเจนต์ตอบสนองซ้ำๆ หรือวนซ้ำโดยไม่สิ้นสุด ให้ตรวจสอบ system prompt ของเอเจนต์นั้น
- เก็บบันทึกของรอบการทำงานที่ผลดีเป็นตัวอย่าง (baseline) สำหรับเปรียบเทียบเมื่อเกิดปัญหา
