# จัดการผู้ใช้

## ภาพรวม

User Management ให้ผู้ดูแลระบบมองเห็นและควบคุมทุกบัญชีบนแพลตฟอร์มได้อย่างครบถ้วน จากที่นี่คุณสามารถค้นหาผู้ใช้ เปลี่ยน Role ปรับยอดเครดิต ระงับบัญชี และกำหนดค่าแพ็คเกจเครดิตที่เปิดให้ซื้อ

## รายการผู้ใช้

- **ตาราง Users** แสดงบัญชีที่ลงทะเบียนทั้งหมดพร้อมอีเมล ชื่อ Role ยอดเครดิต แผน วันที่สมัคร และสถานะ
- **ค้นหา** ด้วยชื่อหรืออีเมล
- **กรอง** ตาม Role (user, admin, domain_admin) สถานะ (active, banned) หรือแผน
- **เรียงลำดับ** ตามคอลัมน์ใดก็ได้ — วันที่สมัคร เครดิต ใช้งานล่าสุด — โดยคลิกส่วนหัวคอลัมน์
- คลิกแถวผู้ใช้เพื่อเปิดแผงรายละเอียด

## บทบาท (Roles)

แพลตฟอร์มใช้ลำดับชั้น Role สามระดับ:

| Role | คำอธิบาย |
|---|---|
| `user` | บัญชีมาตรฐาน — เข้าถึง Chat, สื่อ, Skill และเนื้อหาของตนเอง |
| `admin` | การเข้าถึงระดับสูง — จัดการผู้ใช้ ดู Audit Log ปรับเครดิต แต่ไม่สามารถเปลี่ยน System Settings |
| `domain_admin` | การเข้าถึงระดับสูงสุด — ทุกความสามารถของ Admin บวกกับ System Settings และการกำหนดค่า Provider |

หากต้องการเปลี่ยน Role ให้เปิดแผงรายละเอียดผู้ใช้และเลือก Role ใหม่จาก Dropdown การเปลี่ยนแปลงมีผลทันที

## การดำเนินการกับผู้ใช้แต่ละคน

- **แก้ไข Role** — เลื่อนตำแหน่งหรือลดตำแหน่งผู้ใช้ภายในลำดับชั้น Role
- **ปรับเครดิต** — เพิ่มหรือหักเครดิตพร้อมหมายเหตุเหตุผล (บันทึกใน Audit Log)
- **แบนผู้ใช้** — ระงับบัญชีทันที ผู้ใช้ไม่สามารถล็อกอินได้ แต่ข้อมูลทั้งหมดยังคงอยู่
- **ยกเลิกการแบน** — คืนสิทธิ์การเข้าถึงทันที
- **Impersonate** (เฉพาะ domain_admin) — ล็อกอินเป็นผู้ใช้เพื่อดีบักปัญหาในนามของพวกเขา การดำเนินการทั้งหมดขณะ Impersonate จะถูกบันทึกใน Audit Log
- **ลบบัญชี** — ลบผู้ใช้และข้อมูลทั้งหมดอย่างถาวร ต้องยืนยัน ไม่สามารถยกเลิกได้

## การจัดการเครดิต

- ใช้ **Adjust Credits** เพื่อให้หรือหักเครดิตด้วยตนเองสำหรับการสนับสนุน ชดเชย หรือทดสอบ
- ป้อนตัวเลขบวกเพื่อเพิ่มเครดิต หรือตัวเลขลบเพื่อหักเครดิต
- เพิ่ม **หมายเหตุเหตุผล** เสมอ — จะมองเห็นได้ในประวัติธุรกรรมเครดิตของผู้ใช้และ Audit Log
- **ตั้งขีดจำกัดเครดิต** — กำหนดเพดานเครดิตที่ผู้ใช้สามารถสะสมได้
- ดู **ประวัติธุรกรรม** ครบถ้วนของผู้ใช้จากแผงรายละเอียด

## แพ็คเกจ

แท็บ **Packages** จัดการระดับเครดิต Bundle ที่เปิดให้ซื้อด้วยตนเอง

- **สร้างแพ็คเกจ** — ตั้งชื่อ จำนวนเครดิต ราคา สกุลเงิน และสถานะ Active
- **แก้ไข** แพ็คเกจที่มีอยู่เพื่อปรับราคาหรือจำนวนเครดิต
- **เปิด/ปิดใช้งาน** — สลับการมองเห็นใน UI การชำระเงินของผู้ใช้โดยไม่ลบแพ็คเกจ
- **ลบ** — ลบแพ็คเกจอย่างถาวร ผู้ใช้ที่ซื้อไปแล้วไม่ได้รับผลกระทบ

## การดำเนินการแบบกลุ่ม

เลือกผู้ใช้หลายคนด้วย Checkbox เพื่อดำเนินการแบบกลุ่ม:

- **ปรับเครดิตแบบกลุ่ม** — ใช้การเปลี่ยนแปลงเครดิตเดียวกันกับผู้ใช้ที่เลือกทั้งหมดพร้อมกัน
- **เปลี่ยน Role แบบกลุ่ม** — เลื่อนหรือลดตำแหน่งกลุ่มผู้ใช้
- **แบน/ยกเลิกการแบนแบบกลุ่ม** — ระงับหรือคืนสิทธิ์กลุ่มบัญชี

การดำเนินการแบบกลุ่มทั้งหมดจะบันทึกแยกกันใน Audit Log สำหรับผู้ใช้แต่ละคนที่ได้รับผลกระทบ
