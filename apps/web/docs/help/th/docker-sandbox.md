# Docker Sandbox

## ภาพรวม

Docker Sandbox เป็นแดชบอร์ดจัดการคอนเทนเนอร์สำหรับตรวจสอบและควบคุม Docker container และ image ดูสถานะคอนเทนเนอร์แบบเรียลไทม์ การใช้ทรัพยากร ล็อก และรายละเอียด image

## การจัดการคอนเทนเนอร์

แท็บ **Containers** แสดงคอนเทนเนอร์ทั้งหมดพร้อม:

- **สถานะ** — กำลังรัน (เขียว), หยุด (เทา), หยุดชั่วคราว (เหลือง)
- **การใช้ทรัพยากร** — CPU และหน่วยความจำของแต่ละคอนเทนเนอร์
- **การควบคุม** — start, stop, restart หรือลบคอนเทนเนอร์

กดแถวคอนเทนเนอร์เพื่อขยายแผงรายละเอียด

## การดูล็อก

1. เลือกคอนเทนเนอร์จากรายการ
2. สลับไปแท็บ **Logs**
3. ล็อกจะ stream แบบเรียลไทม์พร้อม auto scroll
4. ใช้แถบค้นหาเพื่อกรองรายการล็อก
5. เปิด/ปิด **timestamps** เพื่อแสดงหรือซ่อนเวลาของล็อก

## การตรวจสอบ Image

แท็บ **Images** แสดงรายการ Docker image ทั้งหมดในระบบ:

- ชื่อ image, tag และขนาด
- วันที่สร้างและจำนวน layer
- Pull หรือลบ image จากอินเทอร์เฟซ

## ทรัพยากรระบบ

หัวแดชบอร์ดแสดงสถิติระบบรวม:

- จำนวนคอนเทนเนอร์ที่กำลังรัน
- การใช้ CPU และหน่วยความจำรวมทุกคอนเทนเนอร์
- การใช้ดิสก์ของ Docker volume

## เคล็ดลับ

- ใช้ตัวดูล็อกเพื่อ debug ปัญหาคอนเทนเนอร์โดยไม่ต้อง SSH
- หยุดคอนเทนเนอร์ที่ไม่ใช้เพื่อคืนทรัพยากรระบบ
- ตรวจสอบขนาด image เป็นประจำ — image ขนาดใหญ่ทำให้ deploy ช้าลง
