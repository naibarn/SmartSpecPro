# จัดการเอกสาร

## ภาพรวม

Document Management คือคลังส่วนกลางสำหรับทุกสิ่งที่คุณอัปโหลด สร้าง หรือบันทึกบน SmartAI Hub — ไฟล์ที่สร้างใน Media Studio ไฟล์แนบจากการสนทนา และเอกสารที่อัปโหลดด้วยตนเองทั้งหมดอยู่ที่นี่ ใช้เพื่อค้นหา จัดระเบียบ และนำเนื้อหากลับมาใช้ใหม่ในทุกฟีเจอร์

## มุมมอง Library

- เรียกดูไฟล์ทั้งหมดในรูปแบบ Grid หรือ List
- **กรองตามประเภท** — รูปภาพ วิดีโอ เสียง เอกสาร หรือทั้งหมด
- **ค้นหา** ด้วยชื่อไฟล์ แท็ก หรือช่วงวันที่
- **เรียงลำดับ** ตามวันที่สร้าง ชื่อ หรือขนาดไฟล์
- Thumbnail แสดงแบบ Inline สำหรับรูปภาพและวิดีโอ ช่วยระบุเนื้อหาได้อย่างรวดเร็ว

## Media History

Media History แสดงฟีดตามลำดับเวลาของผลลัพธ์ที่ AI สร้าง — รูปภาพ วิดีโอ และเสียงจาก Media Studio และคำขอสร้างสื่อในการสนทนา

- การเก็บข้อมูล: **12 วัน** และสูงสุด **100 รายการ** รายการที่เก่าเกินไปหรือเกินจำนวนจะถูกลบอัตโนมัติ
- แต่ละรายการแสดง Prompt การสร้าง โมเดลที่ใช้ เวลาสร้าง และผลลัพธ์
- คลิกรายการใดก็ได้เพื่อเปิดมุมมองรายละเอียดพร้อมตัวเลือกดาวน์โหลดและนำมาใช้ใหม่
- **Regenerate** — ส่ง Prompt เดิมใหม่ด้วยโมเดลเดียวกันหรือโมเดลอื่น
- **Copy Prompt** — คัดลอก Prompt การสร้างเพื่อใช้ในคำขอใหม่

## การอัปโหลดไฟล์

- **Drag and Drop** ไฟล์ไปยังหน้า Library เพื่ออัปโหลด
- **คลิกเพื่อเลือก** — ใช้ปุ่ม Upload เพื่อเปิดตัวเลือกไฟล์
- รูปแบบที่รองรับ: JPG, PNG, GIF, WebP, MP4, MOV, MP3, WAV, PDF, DOCX, TXT และรูปแบบสเปรดชีตทั่วไป
- ขนาดไฟล์สูงสุด: 50 MB ต่อไฟล์
- ไฟล์ที่อัปโหลดพร้อมใช้งานทันทีในไฟล์แนบการสนทนา Skill และขั้นตอนการแชร์ไปยัง Gallery

## การจัดระเบียบไฟล์

- **สร้างโฟลเดอร์** — คลิกขวาในรายการไฟล์หรือใช้ปุ่ม New Folder
- **ย้ายไฟล์** — ลากเข้าโฟลเดอร์หรือใช้เมนูบริบท
- **แท็ก** — เพิ่มแท็กกำหนดเองให้กับไฟล์เพื่อจัดหมวดหมู่ข้ามโฟลเดอร์
- **เปลี่ยนชื่อ** ไฟล์และโฟลเดอร์ได้โดยตรงด้วยการดับเบิลคลิกที่ชื่อ
- **เลือกหลายรายการ** — กด Shift หรือ Ctrl/Cmd เพื่อเลือกหลายไฟล์ แล้วย้าย แท็ก หรือลบพร้อมกัน

## การแชร์

- **แชร์ไฟล์** — สร้างลิงก์สาธารณะที่ใช้งานได้ 7 วัน หรือตั้งค่าหมดอายุเอง
- **เผยแพร่ไปยัง Gallery** — ทำให้รายการปรากฏบนหน้า Gallery สาธารณะ
- **Embed Link** — คัดลอก URL โดยตรงสำหรับใช้ในเครื่องมือหรือเอกสารภายนอก
- ยกเลิกลิงก์แชร์ได้ตลอดเวลาจากแผงรายละเอียดของไฟล์

## พื้นที่เก็บข้อมูล

- โควตาพื้นที่เก็บข้อมูลแสดงในแถบด้านข้างของ Library
- สื่อที่สร้างขึ้นนับรวมกับโควตาพื้นที่ ไฟล์ที่อัปโหลดก็นับด้วยเช่นกัน
- ลบรายการที่ไม่ต้องการอีกต่อไปเพื่อเพิ่มพื้นที่ — การลบถาวรหลังจากผ่านช่วงผ่อนผัน 24 ชั่วโมง
- ขีดจำกัดพื้นที่ขึ้นอยู่กับแผนปัจจุบัน — ดูรายละเอียดที่ **Settings → Billing**
