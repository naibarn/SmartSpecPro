# ตัวกำหนดเส้นทาง (Channel Router)

## ภาพรวม

Channel Router ช่วยให้คุณเชื่อมต่อช่องทางสื่อสารภายนอก เช่น Telegram, Slack, หรือ LINE เข้ากับ AI agents บนแพลตฟอร์ม เมื่อผู้ใช้ส่งข้อความมาจากช่องทางที่กำหนด ระบบจะส่งต่อไปยัง agent หรือ skill ที่ถูกต้องโดยอัตโนมัติ

## ช่องทางที่รองรับ

| ช่องทาง | สถานะ |
|--------|------|
| **Telegram** | พร้อมใช้งาน |
| **Slack** | พร้อมใช้งาน |
| **LINE** | พร้อมใช้งาน |
| **WhatsApp** | พร้อมใช้งาน |
| **Discord** | พร้อมใช้งาน |

แต่ละช่องทางต้องตั้งค่า webhook token และ credentials ก่อนเพิ่มเส้นทาง

## สร้างเส้นทาง (Route)

1. กด **+ New Route** ที่มุมขวาบน
2. **เลือกช่องทางต้นทาง** — ช่องทางที่ข้อความจะเข้ามา (เช่น Telegram bot ที่กำหนดไว้)
3. **เลือกปลายทาง** — agent เฉพาะ, ทีม AI, หรือ skill ที่จะรับงาน
4. **ตั้งค่าตัวกรอง** (ตัวเลือก) — กำหนดเงื่อนไขเพิ่มเติม
5. กด **Save Route**

### ตัวอย่างเส้นทาง

- Telegram channel "support-th" → agent ฝ่ายบริการลูกค้า
- Slack channel #content-requests → ทีม AI สร้างคอนเทนต์
- LINE OA → skill "ตอบคำถาม FAQ"

## ตัวกรอง (Filters)

### จับคู่คำสำคัญ

กำหนด **keyword** ที่ต้องมีในข้อความเพื่อให้เส้นทางนี้ทำงาน ตัวอย่าง:

- `สั่งซื้อ, order` → agent จัดการออเดอร์
- `ปัญหา, แจ้ง, error` → agent ฝ่ายสนับสนุน

หากไม่กำหนด keyword ข้อความทุกรายการจะถูกส่งต่อตามเส้นทางนี้

### กรองผู้ใช้

จำกัดเส้นทางให้ทำงานเฉพาะกับ user ID หรือกลุ่มผู้ใช้ที่กำหนด เหมาะสำหรับการทดสอบเส้นทางใหม่กับผู้ใช้บางกลุ่มก่อน

## พฤติกรรมเมื่อไม่ตรงเส้นทาง

เมื่อข้อความเข้ามาแต่ไม่ตรงกับเส้นทางใดเลย ระบบจะดำเนินการตาม **Default Action** ที่กำหนด:

- **ตอบกลับอัตโนมัติ** — ส่งข้อความ fallback ที่กำหนดไว้ (เช่น "ขอโทษ ไม่เข้าใจคำถาม")
- **ส่งต่อ default agent** — ส่งไปยัง agent กลางที่รับข้อความทั่วไป
- **ไม่ดำเนินการ** — ละเว้นข้อความโดยไม่ตอบกลับ

ตั้งค่า Default Action จาก **Settings > Fallback Behavior**

## ทดสอบเส้นทาง

ก่อน activate เส้นทาง ทดสอบได้โดย:

1. เลือกเส้นทางที่ต้องการทดสอบ
2. กด **Test Route**
3. พิมพ์ข้อความทดสอบในช่อง simulator
4. กด **Send** เพื่อดูว่าเส้นทางส่งต่อข้อความไปยังปลายทางที่ถูกต้องหรือไม่
5. ดูผลลัพธ์ในแถบ **Routing Log**

## ลำดับความสำคัญของเส้นทาง

หากข้อความตรงกับหลายเส้นทาง ระบบจะเลือกเส้นทางที่มี **priority** สูงสุดก่อน ลากเส้นทางในรายการเพื่อเรียงลำดับความสำคัญ

## เปิด/ปิดเส้นทาง

สลับสวิตช์ **Active** ข้างแต่ละเส้นทางเพื่อเปิดหรือปิดชั่วคราวโดยไม่ต้องลบออก
