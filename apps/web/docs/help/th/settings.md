# การตั้งค่าและความชอบ

## ภาพรวม

Settings คือแผงควบคุมส่วนตัวสำหรับทุกอย่างที่ส่งผลต่อการทำงานของ SmartAI Hub — ตั้งแต่ข้อมูลส่วนตัวและความปลอดภัย ไปจนถึงการชำระเงิน การผสานรวม และการตั้งค่าพฤติกรรม AI เข้าถึงได้จากแถบด้านข้างหรือเมนูนำทางด้านบน

## Profile

- อัปเดต **ชื่อที่แสดง** และ **อวตาร** — ปรากฏในเนื้อหาที่แชร์และบริบทของทีม
- เปลี่ยน **ที่อยู่อีเมล** — จะมีการส่งอีเมลยืนยันก่อนที่การเปลี่ยนแปลงจะมีผล
- เปลี่ยน **รหัสผ่าน** — ป้อนรหัสผ่านปัจจุบัน แล้วตั้งรหัสผ่านใหม่ (ขั้นต่ำ 8 ตัวอักษร)
- ป้ายยืนยันอีเมลจะปรากฏเมื่อยืนยันที่อยู่อีเมลแล้ว

## บัญชี

- ดูวันที่สร้างบัญชี แผนปัจจุบัน และ User ID เฉพาะของคุณ
- **การยืนยันอีเมล** — ส่งอีเมลยืนยันใหม่หากยังไม่ได้ยืนยัน
- การลบบัญชี — ลบข้อมูลทั้งหมดอย่างถาวร ดำเนินการนี้ไม่สามารถยกเลิกได้

## ความปลอดภัย

Two-Factor Authentication (2FA) ช่วยลดความเสี่ยงจากการเข้าถึงโดยไม่ได้รับอนุญาตได้อย่างมาก

- **เปิดใช้งาน TOTP 2FA** — สแกน QR Code ด้วยแอปยืนยันตัวตน (Google Authenticator, Authy, 1Password)
- **Recovery Codes** — บันทึก Recovery Codes แบบใช้ครั้งเดียวเมื่อเปิดใช้งาน 2FA ครั้งแรก ใช้สำหรับกู้คืนการเข้าถึงหากสูญเสียอุปกรณ์
- **ปิดใช้งาน 2FA** — ต้องป้อนรหัส TOTP ปัจจุบันเพื่อยืนยัน
- **Session ที่ใช้งานอยู่** — ดูและยกเลิก session บนอุปกรณ์อื่น

## ความชอบ

- **ภาษา** — เลือกภาษาอังกฤษหรือภาษาไทย UI เอกสารช่วยเหลือ และการตอบกลับ AI จะปรับตามนั้น
- **ธีม** — Light, Dark หรือ System (ตามการตั้งค่าระบบปฏิบัติการ)
- **การตั้งค่าการแจ้งเตือน** — ควบคุมการแจ้งเตือนทางอีเมลสำหรับงานที่เสร็จสมบูรณ์ การแจ้งเตือนเครดิต และประกาศระบบ

## การทำงานอัตโนมัติ

- **ค่าเริ่มต้น Browser Session** — ตั้งค่าความละเอียดเบราว์เซอร์ที่ต้องการและพฤติกรรมเริ่มต้นสำหรับขั้นตอนการอนุมัติ
- **บันทึกการสนทนาอัตโนมัติ** — สลับว่าจะบันทึก session การสนทนาในประวัติโดยอัตโนมัติหรือไม่
- **โหมด Skill เริ่มต้น** — เลือกว่า Skill ตรวจจับจากข้อความอัตโนมัติ หรือต้องเปิดใช้งานอย่างชัดแจ้ง

## API

- **Personal API Keys** — สร้าง Token สำหรับการเข้าถึง SmartAI Hub API แบบ Programmatic
- แต่ละ Key มีชื่อ วันที่สร้าง และ Timestamp ล่าสุดที่ใช้งาน
- Key จะแสดงเพียงครั้งเดียวเมื่อสร้าง — คัดลอกและเก็บไว้ทันที
- **ยกเลิก Key** ทีละรายการหรือทั้งหมดหากสงสัยว่า Key ถูกเปิดเผย
- การเข้าถึง API ต้องใช้เครดิต — การใช้งานจะถูกหักเช่นเดียวกับการโต้ตอบผ่าน UI

## Billing

- **ยอดเครดิต** — เครดิตที่มีอยู่ในปัจจุบันและการใช้งานที่รอดำเนินการ
- **ประวัติธุรกรรม** — บันทึกรายละเอียดของเครดิตที่ได้รับ ใช้ไป และซื้อ
- **เติมเครดิต** — ซื้อเครดิตเพิ่มเติมโดยตรงจากแท็บ Billing
- **การแจ้งเตือนงบประมาณ** — ตั้งค่าเกณฑ์เครดิตต่ำเพื่อรับคำเตือนทางอีเมลก่อนหมด
- **วิธีการชำระเงิน** — เพิ่มหรือลบบัตรเครดิตสำหรับการเติมเครดิตด้วยตนเอง

## การผสานรวม

- **Google Drive** — อนุมัติการเข้าถึงเพื่อนำเข้าเอกสารโดยตรงในการสนทนาและ Skill
- **OneDrive / SharePoint** — เชื่อมต่อ Microsoft Storage สำหรับความสามารถในการนำเข้าเดียวกัน
- **การเชื่อมต่อบุคคลที่สาม** — จัดการการอนุญาต OAuth ที่ให้แก่บริการภายนอก
- ยกเลิกการผสานรวมใดๆ ได้ทุกเมื่อ การยกเลิกจะเพิกถอนการเข้าถึงทันทีโดยไม่ลบข้อมูลของคุณ

## Personas

แท็บ Personas เป็นทางลัดสำหรับจัดการบุคลิก AI แบบกำหนดเอง ดูคู่มือ [AI Personas](./personas.md) สำหรับรายละเอียดเกี่ยวกับการสร้าง แก้ไข และใช้ Personas ในการสนทนา

## เคล็ดลับ

- การเปลี่ยนภาษาและธีมมีผลทันทีโดยไม่ต้องโหลดหน้าใหม่
- เก็บ Recovery Codes ไว้ใน Password Manager — ไม่มีวิธีกู้คืนบัญชีที่ล็อกด้วย 2FA โดยไม่มีรหัสเหล่านี้
- API Keys ที่สร้างที่นี่ใช้ Credit Pool เดียวกับคุณ — ควรระวังขอบเขตการใช้งานหากแชร์กับบริการบุคคลที่สาม
