# จัดการ Sandbox

## ภาพรวม

Sandbox คือสภาพแวดล้อมการรันโค้ดแบบแยกส่วนที่ระบบใช้เพื่อประมวลผลงาน AI ได้อย่างปลอดภัย แต่ละงานจะทำงานใน sandbox ของตัวเองเพื่อป้องกันไม่ให้งานหนึ่งกระทบต่องานอื่น แอดมินสามารถตรวจสอบสถานะ ดูผลลัพธ์ และจัดการ sandbox ที่ค้างอยู่ได้จากหน้านี้

## วิธีเข้าถึง

เข้าสู่ระบบในฐานะแอดมิน จากนั้นไปที่เมนูด้านซ้าย เลือก **Admin** และคลิก **Sandbox** หรือไปที่ URL `/admin/sandbox` โดยตรง

## ความสามารถหลัก

- ดูรายการ sandbox ที่กำลังทำงาน (Running) งานที่เสร็จสิ้นแล้ว (Completed) และงานที่ล้มเหลว (Failed)
- ตรวจสอบรายละเอียดของแต่ละ sandbox เช่น ID งาน เวลาเริ่มต้น ระยะเวลา และผลลัพธ์
- ยกเลิกหรือหยุด sandbox ที่กำลังทำงานและค้างนานผิดปกติ
- ดู log การทำงานของแต่ละ sandbox เพื่อวิเคราะห์ข้อผิดพลาด
- กรองงานตามสถานะ ประเภท หรือช่วงเวลา
- ลบข้อมูล sandbox เก่าเพื่อเพิ่มพื้นที่จัดเก็บ

## ขั้นตอนการใช้งาน

1. เปิดหน้า **Sandbox** จากเมนู Admin
2. เลือกแท็บตามสถานะที่ต้องการดู ได้แก่ Running, Completed หรือ Failed
3. คลิกที่แถวของ sandbox ที่ต้องการดูรายละเอียด
4. ในแผงรายละเอียด ให้ตรวจสอบ log การทำงาน ข้อความผิดพลาด และผลลัพธ์
5. หากต้องการหยุด sandbox ที่กำลังทำงาน ให้คลิกปุ่ม **Terminate** และยืนยันการดำเนินการ
6. ใช้ตัวกรองด้านบนเพื่อค้นหา sandbox ตาม ID งาน ประเภท หรือช่วงเวลาที่สร้าง

## เคล็ดลับ

- sandbox ที่อยู่ในสถานะ Running นานกว่า 30 นาทีอาจแสดงถึงปัญหาที่ต้องตรวจสอบ
- ตรวจสอบ log ของ sandbox ที่ Failed เสมอก่อนรีสตาร์ทงาน เพื่อหาสาเหตุที่แท้จริง
- งานประเภท media generation มักใช้เวลานานกว่างาน LLM ทั่วไป ให้พิจารณาตาม threshold ที่แตกต่างกัน
- หากพบ sandbox ค้างจำนวนมากพร้อมกัน ให้ตรวจสอบสถานะ Celery worker ที่หน้า Task Queue Monitor
