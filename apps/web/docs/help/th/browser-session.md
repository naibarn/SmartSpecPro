# Browser Session

## Browser Session ทำอะไร

คุณอธิบายผลลัพธ์ที่ต้องการ ระบบจะตรวจจับ browser skill ที่เหมาะสม ค้นหาเว็บไซต์ที่เกี่ยวข้อง เปิด browser session จริง และทำงานต่อไปขณะที่คุณดูแลอยู่ — หรือจะเข้ามาช่วยเฉพาะเมื่อจำเป็น

Browser Session เหมาะสำหรับงานที่ต้องการเว็บไซต์จริง การเปรียบเทียบข้ามหน้าเว็บ หรือ workflow ในเบราว์เซอร์จริงที่ Chat ทำไม่ได้โดยลำพัง

## เริ่มต้นใช้งาน

1. คลิก **Start Browser Session** จาก Chat
2. อธิบายผลลัพธ์ที่ต้องการเป็นภาษาธรรมชาติ
3. ให้ระบบค้นหาเว็บไซต์ที่เกี่ยวข้องและเริ่มท่องเว็บ
4. เปิด live session หากต้องการดูหรือบังคับทิศทางเบราว์เซอร์แบบ real-time
5. ส่งคำสั่งเพิ่มเติมแทนการเริ่มใหม่ตั้งแต่ต้น

## วิธีเขียนคำขอที่ดี

คำขอ Browser Session ที่ดีมีสามส่วน:

- **เป้าหมาย** — ผลลัพธ์ที่ต้องการ ไม่ใช่ทุกการคลิก
- **ข้อจำกัด** — งบประมาณ ภูมิภาค วันที่ แบรนด์ ตัวกรองที่ต้องมี หรือสิ่งที่ต้องการยกเว้น
- **ผลลัพธ์** — ขอรายการสั้น ตารางเปรียบเทียบ สรุป หรือลิงก์หลักฐาน

## ตัวอย่าง Prompt

> "ค้นหาเว็บไซต์โรงแรมบูทีคในโตเกียวสำหรับวันที่ 10-13 เมษายน 2026 งบคืนละไม่เกิน $150 และส่งกลับ 3 ตัวเลือกที่ดีที่สุดพร้อมข้อดีข้อเสีย"

> "วิจัย CRM สำหรับทีมขาย 10 คน เปรียบเทียบราคาและฟีเจอร์ automation และแนะนำตัวที่เหมาะสำหรับ startup งบน้อย"

> "หาแล็ปท็อปตัดต่อวิดีโอราคาต่ำกว่า $1,200 ไม่ต้องการสินค้า refurbished และอธิบายว่ารุ่นใดคุ้มที่สุด"

> "เปิด login flow ของ Service X นำไปที่หน้า account settings และหยุดรอเมื่อต้องใส่ OTP หรือ MFA"

> "หาสถานที่จัดงาน 3 แห่งในกรุงเทพฯ สำหรับเวิร์กช็อป 100 คน เปรียบเทียบราคาแพ็คเกจ และบันทึกที่จอดรถและระบบ AV"

## ขณะที่ Session กำลังทำงาน

- เปิด live Browser Session เพื่อดูเบราว์เซอร์แบบ real-time
- ใช้ **Send Browser Instruction** เพื่อปรับงานขณะที่ session กำลังทำงาน
- เปลี่ยน skill หากงานเปลี่ยนจากการวิจัยเป็นการเปรียบเทียบ การจอง หรือการเข้าถึงบัญชี
- หากระบบหยุดรอการอนุมัติ MFA หรือการชำระเงิน ให้เข้ามาช่วยชั่วคราวแล้วส่งคืนการควบคุม

## Best practices

- **เริ่มต้นด้วยผลลัพธ์ที่ต้องการ** เช่น "หา vendor ที่ดีที่สุด 3 ราย สำหรับ X และอธิบาย tradeoffs"
- **บอกสิ่งที่ต้องการหลีกเลี่ยง** เช่น "ไม่ต้องการ marketplace รายการโฆษณา และไซต์ที่ราคาไม่ชัดเจน"
- **บอก AI ว่าเมื่อใดให้หยุดรอ** เช่น "หยุดก่อนการชำระเงิน ยืนยัน login หรือ OTP"
- **ขอโครงสร้าง** เช่น "ส่งตารางเปรียบเทียบแบบ ranked พร้อมข้อดี ข้อเสีย และคำแนะนำสุดท้าย"
- **ใช้คำสั่งเพิ่มเติมแทนการเริ่มใหม่** เช่น "จำกัดให้เฉพาะตัวเลือกที่หาได้ในกรุงเทพฯ เท่านั้น"

## Use cases หลากหลาย

| หมวดหมู่ | ตัวอย่างงาน |
|---|---|
| วางแผนเดินทาง | หาเที่ยวบิน เปรียบเทียบโรงแรม และเลือก itinerary ที่ดีที่สุด |
| วิจัยสินค้า | เปรียบเทียบแล็ปท็อป โทรศัพท์ หรือกล้องจากหลายไซต์ |
| หา vendor | ค้นหา SaaS tools หรือ supplier และสรุปราคาและความสามารถ |
| อสังหาริมทรัพย์ | ค้นหารายการ เปรียบเทียบย่าน และระบุผู้สมัครที่ดีที่สุด |
| สรรหาบุคลากร | รวบรวมหน้าผู้สมัคร ลิงก์ portfolio และหลักฐานสำหรับ shortlist |
| Lead generation | ค้นพบเว็บไซต์บริษัทที่เกี่ยวข้องและรวบรวมบันทึกแบบมีโครงสร้าง |
| วิจัยตลาด | ระบุคู่แข่ง รูปแบบราคา และการจัดวาง feature |
| จัดซื้อ | หา distributor และเปรียบเทียบ minimum order และตัวเลือกการจัดส่ง |
| วางแผนงาน | ค้นหาสถานที่ เปรียบเทียบแพ็คเกจ และสรุปข้อกำหนดการจอง |
| การศึกษา | หาหลักสูตร เปรียบเทียบ syllabus และ shortlist ผู้ให้บริการตามตาราง |
| วิจัย grant | ค้นหาแหล่งข้อมูลทางการ เปรียบเทียบข้อกำหนด และสรุป deadline |
| ค้นหาพาร์ทเนอร์ B2B | ค้นหาพาร์ทเนอร์ที่มีศักยภาพในภูมิภาคและจัดอันดับตามความเหมาะสม |

## เมื่อใด AI ควรหยุดรอคุณ

AI จะหยุดและรอ input ของคุณเมื่อพบ:

- OTP, MFA หรือการยืนยันอุปกรณ์
- การชำระเงิน การจอง การซื้อ หรือการดำเนินการที่เปลี่ยนกลับไม่ได้
- สิ่งที่ละเอียดอ่อนใดๆ ที่คุณต้องการตรวจสอบก่อนส่ง
