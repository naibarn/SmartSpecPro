# แกลเลอรีเวิร์กโฟลว์

## ภาพรวม

แกลเลอรีเวิร์กโฟลว์เป็นหน้าหลักสำหรับดูและจัดการเวิร์กโฟลว์ออโตเมชันทั้งหมดของคุณ คุณสามารถดูเวิร์กโฟลว์ที่สร้างเองและเทมเพลตสำเร็จรูปได้ในหน้าเดียว รวมถึงสร้างเวิร์กโฟลว์ใหม่จากศูนย์หรือใช้เทมเพลตเป็นจุดเริ่มต้นได้โดยตรง

## วิธีเข้าถึง

คลิก **เวิร์กโฟลว์** ในเมนูด้านซ้าย หรือพิมพ์ URL `/workflows` โดยตรง หน้าแกลเลอรีจะแสดงเวิร์กโฟลว์ทั้งหมดในรูปแบบการ์ด

## ความสามารถหลัก

- ดูเวิร์กโฟลว์ที่คุณสร้างทั้งหมดในรูปแบบการ์ดพร้อมรายละเอียดสำคัญ
- เรียกดูเทมเพลตเวิร์กโฟลว์สำเร็จรูปตามหมวดหมู่การใช้งาน
- สร้างเวิร์กโฟลว์ใหม่จากศูนย์ด้วยคลิกเดียว
- ใช้เทมเพลตเป็นฐานและปรับแต่งให้เหมาะกับความต้องการ
- ค้นหาเวิร์กโฟลว์ตามชื่อหรือแท็ก
- ลบหรือทำสำเนาเวิร์กโฟลว์ที่มีอยู่

## ขั้นตอนการใช้งาน

1. เปิดหน้าแกลเลอรีเวิร์กโฟลว์จากเมนูด้านซ้าย
2. ดูรายการเวิร์กโฟลว์ที่มีอยู่ทั้งหมดในแท็บ **เวิร์กโฟลว์ของฉัน**
3. คลิกแท็บ **เทมเพลต** เพื่อดูเทมเพลตสำเร็จรูปตามหมวดหมู่
4. คลิก **สร้างใหม่** เพื่อเปิดตัวสร้างเวิร์กโฟลว์แบบว่างเปล่า
5. หรือคลิก **ใช้เทมเพลต** บนเทมเพลตที่ต้องการเพื่อเริ่มจากโครงสร้างที่มีอยู่
6. คลิกการ์ดเวิร์กโฟลว์เพื่อเปิดและแก้ไข หรือคลิก **รัน** เพื่อรันทันที

## เคล็ดลับ

- ตั้งชื่อเวิร์กโฟลว์ให้สื่อถึงเป้าหมาย เช่น "สร้างบทความจากหัวข้อ" แทน "เวิร์กโฟลว์ 1" เพื่อค้นหาได้ง่ายขึ้น
- เวิร์กโฟลว์ที่ใช้บ่อยสามารถปักหมุดไว้ด้านบนของแกลเลอรีได้
- ทำสำเนาเวิร์กโฟลว์ที่ใช้งานได้ดีก่อนแก้ไข เพื่อรักษาเวอร์ชันต้นฉบับไว้เสมอ
- เทมเพลตสำหรับงาน เช่น สรุปเอกสาร สร้างโพสต์โซเชียล และวิเคราะห์ข้อมูล พร้อมใช้งานได้ทันทีโดยไม่ต้องปรับแต่ง
