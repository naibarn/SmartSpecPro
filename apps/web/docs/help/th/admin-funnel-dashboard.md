# Funnel Dashboard

## ภาพรวม

Funnel Dashboard ช่วยให้แอดมินเข้าใจพฤติกรรมของผู้ใช้ในระบบ ตั้งแต่การเข้าใช้งานครั้งแรกไปจนถึงการดำเนินการสำคัญต่างๆ เช่น การสร้างเนื้อหา การชำระเงิน หรือการใช้งานฟีเจอร์ขั้นสูง แดชบอร์ดแสดงให้เห็นว่าผู้ใช้ออกจากกระบวนการ (Drop-off) ที่ขั้นตอนใด ซึ่งช่วยในการปรับปรุง UX และเพิ่มอัตราการแปลง (Conversion Rate)

## วิธีเข้าถึง

เข้าสู่ระบบในฐานะแอดมิน จากนั้นไปที่เมนูด้านซ้าย เลือก **Admin** และคลิก **Funnel Dashboard** หรือไปที่ URL `/admin/funnel` โดยตรง

## ความสามารถหลัก

- ดูภาพรวมฟันเนลการใช้งานของผู้ใช้ในแต่ละขั้นตอน
- วิเคราะห์อัตราการแปลง (Conversion Rate) ระหว่างขั้นตอนต่างๆ
- ระบุจุด Drop-off ที่มีอัตราสูงที่สุด เพื่อจัดลำดับความสำคัญในการปรับปรุง
- กรองข้อมูลตามช่วงเวลา ประเภทผู้ใช้ หรือแหล่งที่มา
- เปรียบเทียบประสิทธิภาพฟันเนลระหว่างช่วงเวลาต่างๆ เพื่อดูแนวโน้ม
- ดูข้อมูลแบบ Cohort เพื่อวิเคราะห์พฤติกรรมของกลุ่มผู้ใช้ที่สมัครในช่วงเวลาเดียวกัน

## ขั้นตอนการใช้งาน

1. เปิดหน้า **Funnel Dashboard** จากเมนู Admin
2. เลือกฟันเนลที่ต้องการวิเคราะห์จากเมนูด้านบน เช่น Onboarding, Content Creation หรือ Subscription
3. กำหนดช่วงเวลาที่ต้องการดูข้อมูลโดยใช้ Date Picker
4. ดูแผนภาพฟันเนลที่แสดงจำนวนผู้ใช้ในแต่ละขั้นตอนและอัตราการแปลง
5. คลิกที่ขั้นตอนที่ต้องการดูรายละเอียด เพื่อดูข้อมูลผู้ใช้ที่ผ่านและไม่ผ่านขั้นตอนนั้น
6. ใช้ปุ่ม **Compare** เพื่อเปรียบเทียบข้อมูลกับช่วงเวลาก่อนหน้า

## เคล็ดลับ

- ให้ความสนใจขั้นตอนที่มีอัตรา Drop-off สูงกว่า 50% เพราะมักเป็นจุดที่มีปัญหาด้าน UX
- เปรียบเทียบฟันเนลก่อนและหลังการอัพเดตฟีเจอร์สำคัญ เพื่อวัดผลกระทบของการเปลี่ยนแปลง
- ข้อมูลฟันเนลควรอ่านร่วมกับ Content Quality Dashboard เพื่อให้เข้าใจความสัมพันธ์ระหว่างคุณภาพเนื้อหาและ Engagement
- ตั้งค่า alert เมื่ออัตราการแปลงในขั้นตอนสำคัญลดลงเกินเกณฑ์ที่กำหนด
