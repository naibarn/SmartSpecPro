# สร้าง Presentation จาก Chat

## เรียก Presentation จาก Chat

คุณสามารถสร้างสไลด์ทั้งชุดได้โดยตรงจาก Chat AI เข้าใจคำขอภาษาธรรมชาติสำหรับ presentation

### วลีที่ใช้เรียก

- `สร้าง presentation เกี่ยวกับ...`
- `ทำสไลด์สำหรับ...`
- `สร้างสไลด์เรื่อง...ทั้งหมด X สไลด์`
- `create a presentation about...`
- `build a deck on...`

### ตัวอย่างคำขอ

- `สร้าง presentation 6 สไลด์เรื่องเทรนด์ AI ปี 2026 รวมสไลด์ executive summary ด้วย`
- `ทำ pitch deck สำหรับ startup fintech 10 สไลด์ มีปัญหา โซลูชัน ขนาดตลาด และทีม`
- `สร้างสไลด์สรุปผลงานรายไตรมาสพร้อมกราฟและ bullet points`

## พารามิเตอร์ Presentation

| พารามิเตอร์ | วิธีระบุ | ตัวอย่าง |
|---|---|---|
| จำนวนสไลด์ | `X สไลด์` หรือ `X slides` | `8 สไลด์` |
| กลุ่มเป้าหมาย | `สำหรับนักลงทุน`, `สำหรับทีมเทคนิค` | `สำหรับผู้บริหาร` |
| โทน | `เป็นทางการ`, `กันเอง`, `โน้มน้าว` | `โทนเป็นทางการ` |
| หัวข้อ | ระบุรายการ | `รวมบทนำ ปัญหา โซลูชัน แผนงาน และ call to action` |
| สไตล์ภาพ | อธิบาย | `ออกแบบมินิมอล พื้นหลังเข้ม` |

## วิธีการทำงาน

1. คุณส่งคำขอ presentation ใน Chat
2. AI สร้างสไลด์แบบมีโครงสร้างพร้อมหัวข้อ เนื้อหา และ speaker notes ทุกสไลด์
3. **Preview Card** ปรากฏใน Chat พร้อมสรุปสไลด์ที่สร้าง
4. คลิก **Save as Presentation** เพื่อเปิดใน **Presentation Editor**
5. แก้ไขสไลด์ จัดเรียงเนื้อหา ใช้ธีม และส่งออกในรูปแบบที่ต้องการ

## การใช้ Presentation Editor

หลังบันทึกแล้ว สไลด์จะเปิดใน Presentation Editor ที่ครบครัน ซึ่งคุณสามารถ:

- แก้ไขเนื้อหาสไลด์โดยตรง (คลิกข้อความเพื่อแก้ไข)
- เพิ่ม ลบ หรือจัดลำดับสไลด์ในแผงสไลด์
- ใช้ธีม layout และสไตล์พื้นหลังจากแถบเครื่องมือ
- แทรกรูปภาพที่สร้างด้วย AI ลงในสไลด์ด้วยการลากและวาง
- ใช้ปุ่ม **AI Draft** เพื่อสร้างเนื้อหาใหม่สำหรับสไลด์แต่ละอัน
- Undo/Redo ด้วยแป้นพิมพ์ลัด (Ctrl+Z / Ctrl+Shift+Z)

## โหมดนำเสนอ (Play Mode)

คลิกปุ่ม **Play Mode** ในแถบเครื่องมือ editor เพื่อนำเสนอสไลด์:

- แสดงเต็มจอพร้อม transition ที่ลื่นไหล
- เลื่อนด้วยปุ่มลูกศรหรือคลิก
- กด Escape เพื่อออกจากโหมดนำเสนอ
- เข้าถึงผ่านลิงก์ตรง: `/presentation/{id}/play`

## การส่งออก (Export)

- คลิก **Export** ในแถบเครื่องมือ editor
- รูปแบบ: PDF
- Export ทำงานเป็น background task — ลิงก์ดาวน์โหลดปรากฏเมื่อพร้อม
- ไฟล์ที่ส่งออกถูกบันทึกไว้ใน Library สำหรับเข้าถึงภายหลัง

## คลัง Presentation

ไปที่ **Presentations** ในแถบด้านข้างเพื่อดู deck ทั้งหมดของคุณ:

- ดู แก้ไข ทำซ้ำ หรือลบ presentation
- เรียงตามวันที่สร้างหรือแก้ไขล่าสุด
- ดูตัวอย่างด้วยภาพขนาดย่อ

## ใช้ Agencies สำหรับ Presentation

สำหรับ deck ที่ซับซ้อนกว่า เช่น investor presentation หรือ pitch deck เต็มรูปแบบ ให้ใช้เทมเพลต agency **Deck Builder** แทน Chat agency ใช้ workflow แบบ multi-agent ในการวิจัย ร่างโครงสร้าง เขียนเนื้อหา และประกอบ deck ระดับมืออาชีพโดยอัตโนมัติ
