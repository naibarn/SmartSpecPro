# การจัดการโดเมน

## Domain Administration คืออะไร?

Domain Administration ให้การควบคุมเต็มรูปแบบเหนือ Instance SmartAI Hub ขององค์กรคุณ คุณสามารถปรับแต่งแบรนด์ จัดการผู้ใช้ ควบคุมฟีเจอร์ที่มองเห็นได้ และเผยแพร่เนื้อหา — ทั้งหมดในสภาพแวดล้อมแบบ Isolated ของโดเมนคุณ

Domain Admin ใช้ได้สำหรับผู้ใช้ที่มีบทบาท **domain_admin** หรือ **admin** เข้าถึงได้ที่ **/domain-admin** หรือผ่านเมนู Admin

## ส่วนต่างๆ

### Dashboard

Dashboard แสดงภาพรวมของโดเมนคุณแบบคร่าวๆ:

- จำนวนผู้ใช้ที่ใช้งานอยู่และการลงทะเบียนใหม่
- การใช้เครดิตในเดือนนี้
- ฟีดกิจกรรมล่าสุด
- ลิงก์ด่วนไปยังแต่ละส่วนของ Admin

### Theme Editor

ปรับแต่งรูปลักษณ์ภาพของโดเมนคุณสำหรับผู้ใช้ทุกคน:

- **Logo** — อัปโหลด Logo ขององค์กร (PNG หรือ SVG แนะนำ 200×60 px)
- **Favicon** — อัปโหลด Favicon สำหรับแท็บเบราว์เซอร์ (ICO หรือ PNG ขนาด 32×32 px)
- **สีหลัก** — สีเน้นหลักที่ใช้กับปุ่มและ Highlight
- **สีรอง** — ใช้กับพื้นหลังและองค์ประกอบ UI รอง
- **การเลือกฟอนต์** — เลือกจากฟอนต์ System และ Google Fonts ที่มีให้
- **Custom CSS** — ผู้ใช้ขั้นสูงสามารถใส่ CSS เพื่อ Override สไตล์ใดๆ ก็ได้

การเปลี่ยนแปลงใน Theme Editor จะดูตัวอย่างได้แบบ Live และมีผลกับผู้ใช้โดเมนทั้งหมดเมื่อคุณคลิก **Save Theme**

### Content

จัดการหน้า Landing Page และเนื้อหาประกาศที่ผู้ใช้เห็น:

- **ข้อความต้อนรับ** — ข้อความที่แสดงบน Dashboard เมื่อผู้ใช้เข้าสู่ระบบครั้งแรก
- **ประกาศ** — ข้อความ Banner ที่แสดงที่ด้านบนของ Interface
- **Feature highlights** — การ์ดที่แสดงบนหน้าต้อนรับเพื่อนำเสนอฟีเจอร์สำคัญ
- **Custom landing page** — หน้า Landing Page ที่แก้ไขได้อย่างเต็มรูปแบบสำหรับผู้เยี่ยมชมที่ยังไม่ได้ยืนยันตัวตน

### Users

จัดการผู้ใช้ทั้งหมดที่ลงทะเบียนภายใต้โดเมนคุณ:

- **รายชื่อผู้ใช้** — ค้นหาและกรองตามชื่อ อีเมล บทบาท หรือสถานะ
- **เชิญผู้ใช้** — ส่งอีเมลเชิญพร้อมบทบาทที่กำหนดล่วงหน้า
- **แก้ไขบทบาท** — เลื่อนตำแหน่งหรือลดตำแหน่งผู้ใช้ระหว่าง Member, Admin และ Domain_admin
- **ระงับบัญชี** — ปิดใช้งานสิทธิ์เข้าถึงของผู้ใช้ชั่วคราวโดยไม่ลบข้อมูล
- **ดูกิจกรรม** — ดูสถิติการใช้งานต่อผู้ใช้และวันที่เข้าสู่ระบบล่าสุด
- **การจัดสรรเครดิต** — มอบเครดิตเพิ่มเติมให้ผู้ใช้เฉพาะรายได้

### Settings

ตั้งค่าพฤติกรรมระดับโดเมน:

- **ชื่อและคำอธิบายโดเมน** — ชื่อที่แสดงใน Interface
- **Feature flags** — เปิดหรือปิดฟีเจอร์เฉพาะ (Agency Builder, Workflows ฯลฯ) สำหรับโดเมนคุณ
- **AI Model เริ่มต้น** — กำหนด Model ที่ผู้ใช้ใหม่ทุกคนเริ่มต้นด้วย
- **นโยบายเครดิต** — ตั้งค่าการให้เครดิตรายเดือนและพฤติกรรมการยกยอด
- **การตั้งค่าการลงทะเบียน** — ลงทะเบียนเปิด, เฉพาะเชิญ หรือปิด

### Blog

เผยแพร่บทความและโพสต์ที่ผู้ใช้ในโดเมนมองเห็น:

- **สร้างโพสต์** — เขียนด้วยตัวแก้ไข Markdown ในตัวพร้อมรองรับการอัปโหลดรูปภาพ
- **โหมด Draft** — บันทึก Draft ก่อนเผยแพร่
- **กำหนดเวลาเผยแพร่** — กำหนดวันและเวลาในอนาคตสำหรับโพสต์ที่จะเผยแพร่
- **หมวดหมู่และ Tag** — จัดระเบียบโพสต์เพื่อให้เรียกดูได้ง่ายขึ้น
- **จัดการโพสต์** — แก้ไข ยกเลิกการเผยแพร่ หรือลบโพสต์ที่มีอยู่

## Theme Editor — ขั้นตอนโดยละเอียด

Theme Editor ให้คุณควบคุมภาพได้อย่างเต็มที่โดยไม่ต้องแตะ code:

1. **อัปโหลด logo** — คลิกพื้นที่อัปโหลด logo และเลือกไฟล์ PNG หรือ SVG แนะนำ SVG เพื่อให้เรนเดอร์ชัดในทุกขนาด ขนาด canvas ที่แนะนำคือ 200×60 px โดย logo จะถูกจำกัดให้พอดีกับ header
2. **อัปโหลด favicon** — คลิกพื้นที่อัปโหลด favicon และเลือกไฟล์ ICO หรือ PNG ขนาด 32×32 px Favicon ปรากฏในแท็บเบราว์เซอร์และบุ๊กมาร์ก
3. **เลือกสี** — คลิก swatch สีถัดจาก **สีหลัก** หรือ **สีรอง** เพื่อเปิด color picker ใส่ hex code โดยตรงหรือใช้ picker wheel การเปลี่ยนแปลงจะ preview แบบ live ในแผง
4. **เลือกฟอนต์** — ใช้ dropdown ฟอนต์เพื่อเลือกจาก system fonts และ Google Fonts ย่อหน้าตัวอย่างจะเรนเดอร์ทันทีด้วยการเลือกของคุณเพื่อให้คุณตัดสินความอ่านง่าย
5. **Custom CSS** — ขยาย Custom CSS editor เพื่อเพิ่ม overrides CSS จะถูกใส่หลัง stylesheet ของแพลตฟอร์ม กฎของคุณจึงมีลำดับความสำคัญสูงกว่า เพิ่ม prefix selector ด้วย class เฉพาะโดเมนเพื่อหลีกเลี่ยง collision
6. คลิก **Save Theme** เพื่อเผยแพร่การเปลี่ยนแปลงให้ผู้ใช้โดเมนทั้งหมดทันที

## Content — ขั้นตอนโดยละเอียด

ส่วน Content ควบคุมสิ่งที่ผู้ใช้เห็นบน dashboard และหน้า landing page:

- **ข้อความต้อนรับ** — เขียนด้วยข้อความธรรมดาหรือ markdown เรียบง่าย แสดงที่ด้านบน dashboard สำหรับผู้ใช้ที่เข้าสู่ระบบทุกคน ใช้เพื่อสื่อสาร context เฉพาะทีม แนวทาง หรือคำทักทายที่อบอุ่น
- **Feature toggles** — เปิด/ปิดการ์ด feature highlight แยกกัน หากโดเมนของคุณไม่ใช้ Video Editor ให้ซ่อนการ์ดนั้นเพื่อลดความยุ่งเหยิง
- **ประกาศ** — สร้างข้อความ banner หนึ่งข้อความหรือมากกว่า แต่ละประกาศมีหัวข้อ ข้อความหลัก ระดับความรุนแรง (info, warning, error) และวันหมดอายุเสริมที่ซ่อนอัตโนมัติหลังจากนั้น
- **Custom landing page** — editor เต็มหน้าสำหรับ landing page ที่ยังไม่ได้ยืนยันตัวตน รองรับ markdown พร้อม URL รูปภาพที่ฝัง ใช้เพื่ออธิบายการใช้งาน SmartAI Hub ขององค์กรคุณแก่ผู้ใช้ใหม่ที่อาจสนใจ

## Users — ขั้นตอนโดยละเอียด

การจัดการรายชื่อผู้ใช้ในโดเมนของคุณ:

- **Invite link** — สร้างลิงก์ sign-up ที่กำหนดขอบเขตไว้สำหรับโดเมนของคุณ แชร์ลิงก์ผ่านอีเมลหรือ chat ใครก็ตามที่ลงทะเบียนผ่านลิงก์จะถูกเพิ่มในโดเมนของคุณโดยอัตโนมัติด้วยบทบาทเริ่มต้น
- **เชิญทางอีเมล** — ส่งคำเชิญรายบุคคลไปยังอีเมลเฉพาะ แต่ละคำเชิญมีข้อความต้อนรับและกำหนดบทบาท (member, admin หรือ domain_admin) ก่อนที่ผู้ใช้จะเข้าสู่ระบบด้วยซ้ำ
- **การกำหนดบทบาท** — หากต้องการเปลี่ยนบทบาทของผู้ใช้ คลิกแถวผู้ใช้ เลือกบทบาทใหม่จาก dropdown และบันทึก การเปลี่ยนแปลงมีผลเมื่อผู้ใช้โหลดหน้าครั้งถัดไป
- **Activity log** — คลิกไอคอนกิจกรรมบนแถวผู้ใช้ใดก็ได้เพื่อดู 30 การดำเนินการล่าสุด: การเข้าสู่ระบบ การใช้เครดิต การใช้ฟีเจอร์ และการดำเนินการ admin ที่พวกเขาทำ
- **การจัดสรรเครดิต** — เลือกผู้ใช้และคลิก **Allocate Credits** เพื่อเพิ่มการให้เครดิตครั้งเดียว มีประโยชน์สำหรับการให้รางวัลผู้ใช้หลักหรือชดเชยสำหรับงานที่ล้มเหลว

## Blog — ขั้นตอนโดยละเอียด

การเผยแพร่โพสต์ไปยัง blog ในตัวของโดเมนคุณ:

- **สร้างโพสต์** — คลิก **New Post** เขียนใน markdown editor (รองรับ heading, list, code block และ table ครบถ้วน) และอัปโหลดรูปภาพโดยตรงในโพสต์โดยใช้ปุ่มรูปภาพในแถบเครื่องมือ
- **โหมด Draft** — โพสต์เริ่มต้นเป็น draft เฉพาะ admin เท่านั้นที่เห็น draft คลิก **Publish** เมื่อโพสต์พร้อมเผยแพร่
- **กำหนดเวลาเผยแพร่** — แทนที่จะคลิก Publish ทันที คลิก **Schedule** เลือกวันและเวลา และบันทึก โพสต์จะเผยแพร่อัตโนมัติตามเวลาที่กำหนด
- **หมวดหมู่** — สร้างหมวดหมู่จาก Category Manager (Blog settings) และกำหนดโพสต์ให้หมวดหมู่หนึ่งหรือมากกว่า หมวดหมู่ปรากฏเป็นแท็บตัวกรองในหน้า blog index
- **Tags** — เพิ่ม tags คั่นด้วยเครื่องหมายจุลภาคสำหรับแต่ละโพสต์ Tags ค้นหาได้และช่วยให้ผู้ใช้ค้นหาบทความที่เกี่ยวข้อง
- **จัดการโพสต์** — จากรายการโพสต์ คลิก **Edit** เพื่อแก้ไขโพสต์ที่เผยแพร่ **Unpublish** เพื่อส่งกลับเป็น draft หรือ **Delete** เพื่อลบถาวร

## เคล็ดลับการปรับแต่ง Theme

- ใช้ Hex Color Code ที่แน่นอนของแบรนด์คุณเพื่อความสอดคล้องกับสื่ออื่นๆ
- ทดสอบการเลือกสีทั้งในโหมดสว่างและมืดหากผู้ใช้ของคุณสามารถสลับ Theme ได้
- ให้การเปลี่ยนแปลง Custom CSS น้อยที่สุด — การอัปเดตแพลตฟอร์มอาจเปลี่ยนชื่อ Class ทำให้สไตล์กำหนดเองเสียหาย
- ใช้ฟอร์แมต SVG สำหรับ Logo เพื่อให้เรนเดอร์ชัดเจนในทุกความหนาแน่นของหน้าจอ

## เคล็ดลับการจัดการผู้ใช้

- **เชิญผู้ใช้พร้อมกำหนดบทบาทล่วงหน้า** — ประหยัดขั้นตอนเมื่อเทียบกับการเลื่อนตำแหน่งหลังจากลงทะเบียน
- **ใช้การระงับแทนการลบ** — บัญชีที่ถูกระงับสามารถเปิดใช้งานใหม่ได้ แต่บัญชีที่ถูกลบไม่สามารถ
- **ตรวจสอบผู้ใช้ที่ไม่ได้ใช้งานเป็นระยะ** — ผู้ใช้ที่ไม่ได้เข้าสู่ระบบนานกว่า 90 วันอาจไม่จำเป็นต้องเข้าถึงอีกต่อไป

## เคล็ดลับ Blog

- ใช้ฟีเจอร์ **กำหนดเวลาเผยแพร่** เพื่อรักษาความสม่ำเสมอของการโพสต์โดยไม่ต้องออนไลน์ในเวลาที่เผยแพร่พอดี
- เพิ่ม Tag ที่บอกรายละเอียดไปยังโพสต์เพื่อให้ผู้ใช้ค้นหาบทความที่เกี่ยวข้องได้ง่าย
- ให้ประกาศสั้นกระชับ — Banner ยาวมักถูกปิดโดยไม่ได้อ่าน
