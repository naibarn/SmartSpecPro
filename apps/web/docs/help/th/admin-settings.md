# การตั้งค่าระบบ

## ภาพรวม

การตั้งค่าระบบให้ผู้ดูแลระบบกำหนดค่าพฤติกรรมทั่วทั้งแพลตฟอร์ม รวมถึงอีเมล การผสานรวม การสร้างแบรนด์ และตัวเลือกประสบการณ์ผู้ใช้เริ่มต้น

## หมวดหมู่การตั้งค่า

### ทั่วไป
- ชื่อแพลตฟอร์มและการสร้างแบรนด์
- ภาษาเริ่มต้นสำหรับผู้ใช้ใหม่
- อีเมลติดต่อฝ่ายสนับสนุน

### อีเมล
- การกำหนดค่า SMTP server สำหรับ transactional email (รีเซ็ตรหัสผ่าน การแจ้งเตือน)
- ทดสอบการส่งอีเมลจากหน้าการตั้งค่า
- ข้อมูลประจำตัว SMTP เก็บแบบเข้ารหัส

### เครดิตและการเรียกเก็บเงิน
- การจัดสรรเครดิตเริ่มต้นสำหรับผู้ใช้ใหม่
- เปิด/ปิดใช้งานการเติมเครดิตด้วยตนเอง
- กำหนดเกณฑ์การแจ้งเตือนเครดิต

### ความปลอดภัย
- ระยะเวลา session timeout
- วิธีการยืนยันตัวตนที่อนุญาต (รหัสผ่าน, SSO)
- ข้อกำหนดความซับซ้อนของรหัสผ่าน

### Feature flags
- เปิด/ปิดใช้งานฟีเจอร์ทั่วทั้งแพลตฟอร์ม (Browser Session, Agencies, Video Editor)
- ควบคุมว่าฟีเจอร์ใดพร้อมใช้งานสำหรับ role ผู้ใช้เฉพาะ

### การผสานรวม
- กำหนดค่า webhook endpoint สำหรับการแจ้งเตือน event
- การจัดการ API key สำหรับการผสานรวมภายนอก
- การกำหนดค่า storage provider (S3/R2 สำหรับไฟล์สื่อ)

## การใช้การเปลี่ยนแปลง

การตั้งค่าส่วนใหญ่มีผลทันที บางการตั้งค่า (SMTP, storage) ต้องการการรีสตาร์ท service — UI จะแจ้งเมื่อจำเป็น

## Packages และราคา

จัดการ packages เครดิตที่ผู้ใช้สามารถเติมได้ด้วยตนเอง:

- ไปที่ **Admin → Packages** เพื่อดูและจัดการ packages ทั้งหมด
- **สร้าง package** — ตั้งชื่อ จำนวนเครดิต ราคา (ในสกุลเงินของคุณ) และคำอธิบายเสริมที่แสดงแก่ผู้ใช้ในหน้าราคา
- **Featured packages** — ทำเครื่องหมาย packages หนึ่งตัวหรือมากกว่าว่า featured จะปรากฏอย่างเด่นชัดที่ด้านบนของหน้าราคา
- **เครดิตทดลองใช้ฟรี** — กำหนดจำนวนเครดิตที่ผู้ใช้ใหม่ได้รับโดยอัตโนมัติเมื่อลงทะเบียน ตั้งเป็น 0 เพื่อปิดการทดลองใช้ฟรี
- **แก้ไขหรือเก็บถาวร** — อัปเดต package ใดก็ได้ตลอดเวลา หรือเก็บถาวรเพื่อซ่อนจากการซื้อใหม่โดยไม่กระทบผู้ใช้ที่มีเครดิตอยู่แล้ว

## Service Status

ตรวจสอบสุขภาพของทุก service บนแพลตฟอร์มจากที่เดียว:

- ไปที่ **Admin → Services** เพื่อดูสถานะปัจจุบันของ component backend ทั้งหมด
- **Services ที่ตรวจสอบ**: ฐานข้อมูล PostgreSQL, Redis cache, Celery workers, LLM providers, media providers และ S3/R2 storage
- **ตัวบ่งชี้สถานะ**: สีเขียว (สุขภาพดี), สีเหลือง (degraded — บางเมตริกสูงกว่าเกณฑ์), สีแดง (วิกฤต — service ล่มหรือ degraded อย่างรุนแรง)
- คลิก service ใดก็ได้เพื่อดูแผงรายละเอียดที่แสดงเมตริกล่าสุด จำนวน connection, อัตราข้อผิดพลาด และรายการ error log 20 รายการล่าสุด
- บาง service รองรับการ **Restart** โดยตรงจากหน้านี้ — ใช้เฉพาะเมื่อ service ไม่ตอบสนองและคุณยืนยันแล้วว่าไม่มีงานที่กำลังดำเนินการอยู่จะสูญหาย

## Audit Log

การเปลี่ยนแปลงการตั้งค่า admin ทั้งหมดถูกบันทึกใน audit log พร้อม timestamp ผู้ใช้ admin และค่าก่อน/หลัง เข้าถึง audit log ได้จาก **Admin → Audit**
