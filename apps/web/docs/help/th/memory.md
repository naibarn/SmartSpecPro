# ระบบ Memory

## Memory ทำอะไร

Memory ช่วยให้ AI จดจำความชอบ บริบทโปรเจกต์ การตัดสินใจ และข้อเท็จจริงสำคัญข้ามบทสนทนาทั้งหมด แทนที่จะต้องอธิบายการตั้งค่าซ้ำทุกครั้ง memory จะพาบริบทนั้นไปข้างหน้าโดยอัตโนมัติ

## โหมด Memory

| โหมด | คำอธิบาย |
|---|---|
| **Auto** | AI ตัดสินใจเองว่าอะไรควรบันทึกตามสัญญาณความสำคัญในบทสนทนา |
| **Always ask** | AI จะถามก่อนบันทึกอะไรก็ตามไว้ใน memory |
| **Off** | ไม่มีการบันทึกอัตโนมัติ (ยังสามารถบันทึกด้วยตนเองได้) |

เปลี่ยนโหมด memory ได้ที่ **Settings → Memory**

## ประเภท Memory

ระบบจัดระเบียบข้อมูลที่บันทึกไว้เป็น 9 หมวดหมู่:

| ประเภท | สิ่งที่เก็บ |
|---|---|
| **Preferences** | สไตล์ โทน รูปแบบ และความชอบด้าน output |
| **Facts** | ข้อความที่ต้องการให้ AI รู้ตลอด |
| **Decisions** | การตัดสินใจที่ส่งผลต่องานในอนาคต |
| **Project context** | เป้าหมาย ข้อจำกัด ผู้มีส่วนได้เสีย และภูมิหลังของโปรเจกต์ที่กำลังทำ |
| **Instructions** | คำสั่งที่ให้ AI ซ้ำๆ เป็นประจำ |
| **Summaries** | บันทึกสรุปจากบทสนทนาที่ผ่านมา |
| **Entities** | บุคคล บริษัท ผลิตภัณฑ์ หรือแนวคิดที่อ้างถึงบ่อย |
| **Workflows** | กระบวนการหรือเทมเพลตที่ใช้ซ้ำ |
| **Feedback** | การแก้ไขและหมายเหตุการปรับเทียบจากครั้งก่อน |

## Memory อัตโนมัติ

เมื่อเปิดโหมด auto ไว้ AI จะตรวจสอบบทสนทนาเพื่อหา:

- ข้อความที่แสดงความชอบหรือข้อเท็จจริงชัดเจน เช่น "ฉันชอบรายการ bullet สั้นๆ"
- รูปแบบซ้ำๆ ที่บ่งบอก workflow เช่น "ฉันเริ่มรายงานด้วย executive summary เสมอ"
- การตัดสินใจสำคัญที่ส่งผลต่องานที่จะมาถึง
- บริบทเฉพาะโปรเจกต์ที่ควรคงอยู่

## การสรุปอัตโนมัติ

บทสนทนาที่ยาวจะถูกสรุปและบันทึกเป็น memory โดยอัตโนมัติเมื่อจบลง ทำให้บริบทยังคงสดอยู่โดยไม่ทำให้ context window เต็มด้วยข้อความเก่า

## Memory ที่แยกตาม Persona

- เมื่อคุณใช้ Chat ร่วมกับ persona ระบบจะเก็บและดึง **long-term memory ตาม persona ที่ active อยู่**
- หมายความว่า persona แต่ละตัวสามารถมีข้อเท็จจริง ความชอบ กฎการทำงาน และบริบทระยะยาวของตัวเองได้
- หากคุณสลับไปอีก persona ระบบจะเปลี่ยนชุด long memory ที่ดึงมาใช้ตาม persona ใหม่นั้น
- แต่ **summary ของบทสนทนาและบริบทของห้องแชตเดิม** ยังอยู่กับ session เดิมตามปกติ ไม่ได้แยกใหม่ทุกครั้งที่สลับ persona
- แนวทางที่เหมาะคือใช้ persona เดิมต่อเนื่องกับงานบทบาทเดิม เพื่อให้ long memory ของ persona นั้นสะสมได้ชัดเจน

## Projects

คุณสามารถเชื่อม memory กับ **โปรเจกต์** เฉพาะได้ Memory ที่ผูกกับโปรเจกต์จะถูกโหลดเฉพาะเมื่อคุณทำงานใน context ของโปรเจกต์นั้น ทำให้ workspace ของคุณเป็นระเบียบ

วิธีสร้างโปรเจกต์:
1. ไปที่ **Settings → Memory → Projects**
2. สร้างโปรเจกต์ใหม่และตั้งชื่อและคำอธิบาย
3. เมื่อเริ่ม Chat session และเลือกโปรเจกต์นั้น memory ของโปรเจกต์จะถูกรวมโดยอัตโนมัติ

## การจัดการ Memory

- ไปที่ **Settings → Memory** เพื่อดู memory ที่บันทึกทั้งหมด
- คลิก memory ใดก็ได้เพื่อแก้ไขหรือลบ
- ใช้แถบค้นหาเพื่อหา memory เฉพาะด้วยคีย์เวิร์ด
- จัดกลุ่ม memory ตามประเภทหรือโปรเจกต์ผ่านตัวเลือกกรอง
- หากคุณทำงานหลาย persona ให้ตรวจดูด้วยว่า memory ที่ต้องการเก็บควรเกิดขึ้นภายใต้ persona ไหน เพื่อไม่ให้บริบทระยะยาวปะปนกัน

## เคล็ดลับใช้ Memory อย่างมีประสิทธิภาพ

- **พูดตรงๆ** — ประโยคอย่าง "ฉันต้องการ output เป็นภาษาอังกฤษทางการเสมอ" ทำให้ AI ตรวจจับและบันทึกได้ง่ายกว่า
- **แก้ไขข้อผิดพลาด** — หาก AI ทำอะไรผิด พูดตรงๆ ว่า "อย่าทำ X ในอนาคต" เพื่อให้บันทึกเป็นการปรับเทียบ
- **ใช้ Projects** — แยก memory สำหรับลูกค้าหรือโดเมนที่ต่างกัน เพื่อหลีกเลี่ยงบริบทปนกัน
- **ใช้ persona ให้ตรงบทบาท** — ถ้าต้องการให้ผู้ช่วยแต่ละตัวมี long memory ของตัวเอง ให้สลับไป persona นั้นก่อนคุยหรือบันทึก memory
- **ตรวจสอบเป็นระยะ** — Memory เก่าอาจล้าสมัย ตรวจสอบและทำความสะอาดใน Settings เป็นครั้งคราว
- **บันทึกด้วยตนเอง** — คลิก **Save to Memory** บนข้อความใดๆ ที่มีสิ่งสำคัญที่ต้องการเก็บไว้
