# แพ็กเกจเครดิตและราคา

## ภาพรวม

หน้าแพ็กเกจเครดิตช่วยให้แอดมินสร้างและจัดการระดับราคาสำหรับผู้ใช้ รองรับการซื้อเครดิตครั้งเดียวและสมาชิกแบบรายงวดพร้อมเชื่อมต่อ Stripe

## การสร้างแพ็กเกจ

1. กด **New Package**
2. กรอกรายละเอียด:
   - **ชื่อ** — ชื่อแสดง (เช่น "Starter", "Pro", "Enterprise")
   - **เครดิต** — จำนวนเครดิตที่รวมอยู่
   - **ราคา** — จำนวนเงินในสกุลเงินที่กำหนด
   - **รอบการเรียกเก็บ** — ครั้งเดียว, รายเดือน, รายไตรมาส, ครึ่งปี หรือรายปี
3. ตั้ง **Stripe Price ID** สำหรับประมวลผลการชำระเงิน (ถ้ามี)
4. กด **Save**

## ประเภทแพ็กเกจ

| ประเภท | คำอธิบาย |
|--------|---------|
| ครั้งเดียว | ผู้ใช้จ่ายครั้งเดียว รับเครดิตทันที |
| รายเดือน | สมาชิกรายงวด เครดิตรีเฟรชทุกเดือน |
| รายไตรมาส | ทุก 3 เดือน |
| ครึ่งปี | ทุก 6 เดือน |
| รายปี | ทุกปี (มักมีส่วนลด) |

## การจัดการแพ็กเกจ

- **เรียงลำดับ** — ลากแพ็กเกจเพื่อตั้งลำดับแสดงบนหน้าราคา
- **Feature** — ทำเครื่องหมายแพ็กเกจหนึ่งเป็น "แนะนำ" เพื่อเน้น (แสดง badge)
- **แก้ไข** — เปลี่ยนชื่อ ราคา หรือจำนวนเครดิต
- **ปิด** — ซ่อนแพ็กเกจจากการซื้อใหม่ (สมาชิกเดิมยังใช้แผนต่อได้)

## การเชื่อมต่อ Stripe

แต่ละแพ็กเกจสามารถเชื่อมกับ Stripe Price ID:

1. สร้างผลิตภัณฑ์และราคาใน Stripe dashboard
2. คัดลอก Price ID (ขึ้นต้นด้วย `price_`)
3. วางในช่อง **Stripe Price ID**

ระบบใช้ ID นี้สร้าง checkout session และจัดการสมาชิก

## เคล็ดลับ

- เสนออย่างน้อย 3 ระดับ (basic, standard, premium) สำหรับกลยุทธ์ราคาที่มีประสิทธิภาพ
- ใช้การเรียกเก็บรายปีพร้อมส่วนลดเพื่อส่งเสริมการสมัครระยะยาว
- ทำเครื่องหมาย feature ที่แพ็กเกจระดับกลาง — มักมีอัตรา conversion ดีที่สุด
- ทดสอบ checkout flow หลังสร้างหรือแก้ไขแพ็กเกจ
