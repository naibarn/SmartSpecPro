# Skills และคำสั่ง Slash

## Skills คืออะไร

Skills คือ workflow AI เฉพาะทางที่ไปไกลกว่าการตอบแชทธรรมดา แต่ละ skill มีวัตถุประสงค์ที่ชัดเจน input แบบมีโครงสร้าง และรูปแบบผลลัพธ์ที่คาดเดาได้ — เหมาะอย่างยิ่งสำหรับงานซ้ำๆ หรืองานเฉพาะด้าน

## พื้นฐานการใช้ Skill

- พิมพ์ `/` ในช่องข้อความเพื่อเปิดเมนู slash-command skill
- เปิดแผง **Skills** (ผ่านแถบเครื่องมือ) เพื่อควบคุมว่า skill ใดเปิดใช้งานในบทสนทนาปัจจุบัน
- ใช้ skills เมื่อต้องการให้ผู้ช่วยทำตามขั้นตอนเฉพาะทาง แทนคำตอบทั่วไป
- หากงานซ้ำๆ หรือเฉพาะด้าน ให้เลือก skill แทนการพิมพ์คำสั่งเดิมซ้ำทุกครั้ง

## การตรวจจับ Skill อัตโนมัติ

SmartAI Hub สามารถตรวจจับอัตโนมัติเมื่อข้อความของคุณตรงกับ skill — ไม่ต้องพิมพ์ `/` เสมอไป

### เคล็ดลับและตัวอย่าง

| สิ่งที่คุณพิมพ์ | Skill ที่น่าจะถูกตรวจจับ |
|---|---|
| `create image: แมวใส่หมวก` | การสร้างรูปภาพ |
| `create video: เปิดตัวสินค้า` | การสร้างวิดีโอ |
| `enhance this prompt: ...` | การปรับปรุง prompt |
| `เขียนรายงานวิจัยเรื่อง...` | Skill วิจัย/เอกสาร |

### วิธีการทำงานของการตรวจจับอัตโนมัติ

1. ข้อความของคุณถูกวิเคราะห์หา intent signal (คีย์เวิร์ด รูปแบบ บริบท)
2. ตัวตรวจจับ skill ให้คะแนน skill ผู้สมัครตามความน่าเชื่อถือ
3. หาก skill ใดได้คะแนนเกินเกณฑ์ จะถูกเลือกโดยอัตโนมัติ
4. แสดงป้าย skill ใน UI เพื่อบอกว่า skill ใดกำลังทำงาน
5. คุณสามารถยกเลิก skill ที่ตรวจจับอัตโนมัติและกลับไปแชทธรรมดาได้ตลอดเวลา

## การจัดการ Skills

- Skills สามารถเปิด/ปิดใช้งานต่อบทสนทนาจากแผง **Skills**
- ผู้ดูแลระบบสามารถเพิ่ม skill ที่กำหนดเองหรือปรับลำดับความสำคัญของ skill จากส่วน **Admin → Skills**
- Skills มีการจัดการเวอร์ชัน — การอัปเดต skill จะมีผลกับบทสนทนาใหม่

## รูปแบบผลลัพธ์ของ Skill

แต่ละ skill กำหนดโครงสร้างผลลัพธ์ของตัวเอง ประเภทผลลัพธ์ที่พบบ่อย:

- **Markdown text** — เนื้อหาที่จัดรูปแบบแล้ว รายงาน บทความ
- **Media generation trigger** — ส่งคำขอสร้างรูปภาพ วิดีโอ หรือเสียงโดยอัตโนมัติ
- **Structured data** — ตาราง JSON ผลลัพธ์เปรียบเทียบ
- **Prompt** — prompt ที่ปรับปรุงหรือมีโครงสร้างพร้อมสำหรับขั้นตอนถัดไป
