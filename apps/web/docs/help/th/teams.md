# ทีม AI

## ภาพรวม

ทีม AI คือการรวมกลุ่มของผู้ช่วย AI (agent) หลายตัวให้ทำงานร่วมกันเพื่อเป้าหมายเดียวกัน แทนที่จะคุยกับ AI คนเดียว คุณสามารถสร้างทีมที่แต่ละ agent มีความเชี่ยวชาญต่างกัน แล้วให้พวกเขาแบ่งงานและแลกเปลี่ยนผลลัพธ์ระหว่างกัน

ตัวอย่างเช่น ทีม "สร้างคอนเทนต์" อาจมี agent นักเขียน, agent นักออกแบบ, และ agent ตรวจสอบคุณภาพ ทำงานร่วมกันในคำขอเดียว

## เข้าถึงทีม

ทีมเข้าถึงได้จาก **สองที่**:

### หน้า Teams

คลิก **Teams** ในเมนูหลักด้านซ้าย (ต้องเปิด feature flag `ORCHESTRATOR_ENABLED`)

หน้า Teams มีสองส่วน:
- **แถบข้าง** — แสดงรายชื่อทีมทั้งหมดพร้อมค้นหา แต่ละรายการแสดงจำนวนสมาชิกและห้อง
- **พื้นที่หลัก** — แสดงสมาชิกและห้องของทีมที่เลือก หรือห้องสนทนาที่กำลังใช้งาน

### แถบข้าง Chat

ที่ด้านล่างของแถบข้าง **Chat** มีส่วน **Team Rooms** แบบยุบได้ คลิกเพื่อขยายและดูทีมของคุณ คลิกชื่อทีมเพื่อไปยังหน้า Teams

## สร้างทีม

### สร้างเอง

1. ไปที่หน้า **Teams** ในเมนูหลัก
2. กดปุ่ม **+** ที่หัวแถบข้าง (หรือปุ่ม **New Team** เมื่อยังไม่มีทีม)
3. กรอก **ชื่อทีม** และ **คำอธิบาย** (ไม่บังคับ)
4. เพิ่มสมาชิกโดยเลือก persona จากดรอปดาวน์ สมาชิกคนแรกจะถูกตั้งเป็น Lead อัตโนมัติ
5. กดไอคอนดาวเพื่อเปลี่ยนว่าสมาชิกคนไหนเป็น Lead
6. กด **Create Team**

### จากเทมเพลต

ในหน้าต่างสร้างทีมใหม่ คุณสามารถเลือก **เทมเพลตสำเร็จรูป** เพื่อเริ่มต้นเร็วขึ้น:

| เทมเพลต | การใช้งาน |
|---------|----------|
| Research & Analysis Team | วิจัยและวิเคราะห์แบบมีโครงสร้าง |
| Content Creation Team | เขียน แก้ไข และตรวจสอบ |
| Code Review Team | พัฒนาและตรวจสอบโค้ด |

เลือกเทมเพลตเพื่อสร้างทีมทันที สามารถปรับแต่งสมาชิกภายหลังได้

## สมาชิกทีม

### เพิ่มสมาชิก

กดปุ่ม **Add Member** ในหน้ารายละเอียดทีม เลือก persona จากรายการ — จะถูกเพิ่มเป็น Member โดยอัตโนมัติ

สมาชิกแต่ละคนคือ persona (ผู้ช่วย AI ที่มี system prompt และโมเดลที่ตั้งค่าไว้)

### บทบาท

| บทบาท | หน้าที่ |
|------|--------|
| **Lead (หัวหน้า)** | ประสานงาน รวมผลลัพธ์ ตัดสินใจขั้นสุดท้าย |
| **Member (สมาชิก)** | ดำเนินงานตามที่ได้รับมอบหมาย |

> **เคล็ดลับ:** ทีมที่ดีที่สุดควรมี Lead 1 คน และ Member 2-4 คน ทีมใหญ่เกินไปใช้ token มากขึ้นโดยไม่จำเป็น

## ห้องทีม (Team Room)

แต่ละทีมมีหนึ่งหรือหลาย **ห้อง** — พื้นที่สนทนาที่ agent แลกเปลี่ยนข้อความระหว่างรัน

### สร้างห้อง

1. เลือกทีมในหน้า Teams
2. กด **New Room** ในหน้ารายละเอียดทีมหรือแถบด้านบน
3. เลือก **ประเภทห้อง**:
   - **Team Chat** — อภิปรายแบบหลาย agent (ใช้บ่อยที่สุด)
   - **Direct** — สนทนาตัวต่อตัวกับ agent เฉพาะ
   - **Auto Team** — ระบบจัดการอัตโนมัติ ผู้ใช้มีส่วนร่วมน้อย
   - **Job Review** — ขั้นตอนตรวจสอบแบบมีโครงสร้าง
4. กรอก **วัตถุประสงค์/เป้าหมาย** เช่น "วิจัยเครื่องมือ CRM 5 อันดับแรกสำหรับธุรกิจขนาดเล็ก"
5. กด **Create Room**

### การ์ดห้อง

ในหน้ารายละเอียดทีม ห้องจะแสดงเป็นการ์ดที่มี:
- ประเภทและสถานะห้อง (active / archived)
- เป้าหมายของห้อง
- คลิกการ์ดเพื่อเข้าห้องสนทนา

### ส่งข้อความ

ในห้อง ใช้ช่องข้อความด้านล่าง:
- พิมพ์ข้อความแล้วกด **Enter** (หรือคลิก **Send**)
- ใช้ **Shift+Enter** สำหรับข้อความหลายบรรทัด
- ข้อความระบบ (เตือนงบประมาณ, ข้อผิดพลาด) แสดงด้วยสไตล์ต่างออกไป

## เปิด Team Room และ Workflow Board จาก Chat

- หากคุณกำลังคุยกับ persona ที่เป็นสมาชิกทีมอยู่ Chat สามารถสรุปสถานะงาน draft ล่าสุด artifact ที่เตรียมไว้ และการอัปเดตล่าสุดของห้องให้ได้
- เมื่อคำถามเกี่ยวข้องกับงานค้าง การอนุมัติ การแก้กลับ หรือ workflow หน้า Chat อาจแสดง **action card / link** เพื่อพาไปยัง Team Room หรือ Workflow Board ที่ตรงกับงานนั้น
- ลิงก์เหล่านี้ช่วยเปิด:
  - ห้องทีมที่เกี่ยวข้อง
  - thread ที่ต้องตอบกลับ
  - Workflow Board ของห้องนั้นโดยตรง
- การมองเห็นบริบทแบบนี้จะผูกกับ **persona ที่ active อยู่ในแชตปัจจุบัน**

## Workflow Board

- ใน Team Room จะมี **Workflow Board** สำหรับดูงานตามสถานะ เช่น งานที่กำลังทำ งานรอ feedback หรือจุดที่ค้างอยู่
- คุณสามารถเข้าถึง Workflow Board ได้จาก:
  - หน้า Teams โดยเปิดห้องที่ต้องการ
  - action card **Open Workflow Board** ที่แสดงในหน้า Chat
- เมื่อเปิดจากลิงก์ตรง ระบบจะพยายามพาไปยังห้องและเน้นบอร์ดที่เกี่ยวข้องให้อัตโนมัติ

## การอนุมัติและส่งกลับไปแก้

- หากงานอยู่ในสถานะรออนุมัติหรือรอการแก้ไข ควรดำเนินการใน **Team Room**
- หน้า Chat ใช้สำหรับดูบริบท ช่วยสรุปสิ่งที่เตรียมไว้ และพาไปยังตำแหน่งที่ถูกต้อง
- การกด **approve / reject / send back** ควรทำใน workflow ของ Team Room เพื่อให้สถานะงานตรงกันเสมอ

## เริ่มรัน

1. เปิดห้องแล้วกด **Start Run**
2. กรอก **วัตถุประสงค์** — อธิบายสิ่งที่ต้องการให้ทีมทำ
3. กด **Start**

หัวหน้าทีมจะรับวัตถุประสงค์ วิเคราะห์งาน แล้วแบ่งมอบหมายให้สมาชิกที่เหมาะสม

> **หมายเหตุ:** การรันใช้เครดิตจาก agent ทุกตัวที่เข้าร่วม

### Unified Skill Execution

เมื่อ agent ในทีมใช้ skill ระหว่างรัน จะผ่าน **ระบบ Unified Execution** เดียวกับ Chat:

- **ผลลัพธ์สม่ำเสมอ** — skill เดียวกันให้ผลลัพธ์เหมือนกันไม่ว่าจะถูกเรียกจาก agent ตัวใดหรือช่องทางใด
- **เลือกโมเดลอัตโนมัติ** — ระบบเลือกโมเดลที่เหมาะสมตาม skill requirement (vision, web search, thinking mode)
- **Rate Limiting** — จำกัดจำนวนครั้งการรันต่อผู้ใช้ เพื่อป้องกันการใช้เครดิตมากเกินไป
- **บันทึกการตรวจสอบ** — ทุกการรัน skill ในทีมจะถูกบันทึกไว้สำหรับ debug และติดตามต้นทุน

## ติดตามการรัน

ขณะรันทำงาน:

- บนเดสก์ท็อป แผง **Run Monitor** จะปรากฏทางขวาแสดง:
  - **Agent Roster** — ชื่อ agent แต่ละตัวและจำนวนเทิร์น
  - **สถิติ** — จำนวนเหตุการณ์ การใช้ token และจำนวน agent
  - **Event Timeline** — ฟีดกิจกรรมแบบเรียลไทม์
- ข้อความแสดงในห้องแบบ **เรียลไทม์** ผ่าน SSE
- ใช้ **Pause** เพื่อหยุดชั่วคราว หรือ **Stop** เพื่อหยุดทันที

ผลลัพธ์บางส่วนยังคงอยู่ในห้องหลังหยุดรัน

## Deep-Linking URL

สามารถบุ๊กมาร์กหรือแชร์ลิงก์ตรงไปยังทีม:
- `/teams` — เปิดหน้า Teams
- `/teams/:teamId` — เปิดหน้า Teams พร้อมเลือกทีมนั้น
- `/teams/:teamId?roomId=...&workItemId=...` — เปิดห้องและโฟกัสงานที่เกี่ยวข้อง
- `/teams/:teamId?roomId=...&workItemId=...&messageId=...&composeReply=1` — เปิด thread ที่ต้องตอบกลับ
- `/teams/:teamId?roomId=...&workItemId=...&panel=workflow` — เปิด Workflow Board ของห้องนั้น

## เก็บถาวรทีม

กดปุ่ม **Archive** ในแถบด้านบนของทีม ทีมที่เก็บถาวรจะถูกซ่อนจากรายการปกติ แต่ admin สามารถกู้คืนได้
