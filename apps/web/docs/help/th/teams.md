# ทีม AI

## ภาพรวม

ทีม AI คือการรวมกลุ่มของผู้ช่วย AI (agent) หลายตัวให้ทำงานร่วมกันเพื่อเป้าหมายเดียวกัน แทนที่จะคุยกับ AI คนเดียว คุณสามารถสร้างทีมที่แต่ละ agent มีความเชี่ยวชาญต่างกัน แล้วให้พวกเขาแบ่งงานและแลกเปลี่ยนผลลัพธ์ระหว่างกัน

ตัวอย่างเช่น ทีม "สร้างคอนเทนต์" อาจมี agent นักเขียน, agent นักออกแบบ, และ agent ตรวจสอบคุณภาพ ทำงานร่วมกันในคำขอเดียว

## สร้างทีม

1. ไปที่หน้า **Teams** แล้วกด **+ New Team**
2. กรอก **ชื่อทีม** และ **คำอธิบาย** ว่าทีมนี้ทำอะไร
3. เพิ่มสมาชิก agent อย่างน้อย 2 ตัว
4. กด **Create Team**

## สมาชิกทีม

### กำหนด Persona

สมาชิกแต่ละคนในทีมต้องมี **persona** ที่กำหนดบุคลิกและความเชี่ยวชาญ เลือก persona จากรายการที่มีอยู่ หรือสร้าง persona ใหม่จากหน้า Personas ก่อน

### ตั้งบทบาท

- **หัวหน้าทีม (Leader)** — ประสานงานและตัดสินใจขั้นสุดท้าย มีได้คนเดียว
- **สมาชิก (Member)** — ดำเนินงานตามที่ได้รับมอบหมาย มีได้หลายคน

หัวหน้าทีมทำหน้าที่เป็น orchestrator ที่แบ่งงานให้สมาชิกและรวมผลลัพธ์

## ห้องทีม (Team Room)

แต่ละทีมมี **ห้องทีม** เป็นพื้นที่สนทนาส่วนกลาง:

- ดูข้อความระหว่าง agent ทั้งหมดแบบ real-time
- เห็นว่า agent แต่ละตัวกำลังทำอะไรอยู่
- ส่งข้อความถึงทีมโดยตรงเพื่อสั่งงานหรือให้ข้อมูลเพิ่มเติม

## เริ่มงาน

ในห้องทีม พิมพ์งานที่ต้องการในช่องข้อความแล้วกด **Start** — หัวหน้าทีมจะรับคำสั่ง วิเคราะห์งาน แล้วแบ่งมอบหมายให้สมาชิกที่เหมาะสม

ตัวอย่างคำสั่ง:
- "สร้างบทความ SEO เกี่ยวกับ AI ความยาว 1,000 คำ"
- "วิเคราะห์ข้อมูลลูกค้าและสรุปแนวโน้มหลัก 5 ข้อ"
- "แปลเอกสารนี้เป็น 3 ภาษา"

## ติดตามความคืบหน้า

ในระหว่างทำงาน คุณจะเห็น:
- **กิจกรรม** — รายการขั้นตอนที่แต่ละ agent ดำเนินการ
- **ข้อความ** — การสื่อสารระหว่าง agent ในทีม
- **ความคืบหน้า** — เปอร์เซ็นต์งานที่เสร็จแล้ว

เมื่องานเสร็จ ผลลัพธ์รวมจะแสดงในห้องทีม

## เทมเพลตทีม

ไม่รู้จะเริ่มต้นยังไง? ใช้ **เทมเพลตทีมสำเร็จรูป** ที่มีให้เลือก:

- **Content Creation Team** — เขียน ออกแบบ ตรวจสอบ
- **Research Team** — วิจัย วิเคราะห์ สรุป
- **Customer Support Team** — ตอบคำถาม แก้ปัญหา ติดตาม

เลือกเทมเพลตแล้วปรับแต่ง persona ให้เหมาะกับความต้องการของคุณ

## เคล็ดลับการใช้งานทีม

- **กำหนดขอบเขตงานให้ชัดเจน** — ยิ่งคำสั่งชัด ทีมยิ่งทำงานได้ตรงเป้า
- **เลือก persona ที่หลากหลาย** — ทีมที่ agent มีทักษะต่างกันจะได้ผลลัพธ์ดีกว่า
- **ดูห้องทีมระหว่างทำงาน** — ช่วยให้เข้าใจกระบวนการและสามารถแทรกแซงได้หากต้องการ
