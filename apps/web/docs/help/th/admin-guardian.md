# ผู้ดูแลระบบ AI

## ภาพรวม

หน้าผู้ดูแลระบบ AI เป็นศูนย์กลางการมอนิเตอร์ระบบด้วยปัญญาประดิษฐ์สำหรับแอดมิน ระบบติดตามสุขภาพและความผิดปกติของแพลตฟอร์มแบบเรียลไทม์ แจ้งเตือนเมื่อพบเหตุการณ์ที่น่าสงสัย และรองรับการอนุมัติคำขอที่ต้องการการตรวจสอบจากผู้ดูแลระบบ

## วิธีเข้าถึง

ต้องมีสิทธิ์แอดมิน ไปที่เมนู **แอดมิน** ในแถบด้านซ้ายแล้วคลิก **ผู้ดูแลระบบ AI** หรือพิมพ์ URL `/admin/guardian` โดยตรง

## ความสามารถหลัก

- ดูแดชบอร์ดภาพรวมสุขภาพระบบแบบเรียลไทม์
- ตรวจสอบรายการเหตุการณ์ที่ตรวจพบโดยระบบ AI พร้อมระดับความรุนแรง
- จัดการเซ็นเซอร์ที่ใช้ตรวจจับความผิดปกติในระบบ
- อนุมัติหรือปฏิเสธคำขอที่ต้องการการตัดสินใจจากแอดมิน
- สนทนากับ Guardian Chat เพื่อสอบถามสถานะระบบและรับคำแนะนำ
- ดูประวัติเหตุการณ์และการดำเนินการที่ผ่านมา

## ขั้นตอนการใช้งาน

1. เปิดหน้าผู้ดูแลระบบ AI จากเมนูแอดมิน
2. ตรวจสอบแท็บ **แดชบอร์ด** เพื่อดูสถานะภาพรวมของระบบในขณะนั้น
3. คลิกแท็บ **เหตุการณ์** เพื่อดูรายการเหตุการณ์ที่ระบบตรวจพบล่าสุด
4. คลิกแต่ละเหตุการณ์เพื่อดูรายละเอียดและดำเนินการตอบสนองที่เหมาะสม
5. ไปที่แท็บ **เซ็นเซอร์** เพื่อกำหนดค่าและเปิดปิดเซ็นเซอร์แต่ละตัว
6. ตรวจสอบแท็บ **การอนุมัติ** เป็นประจำเพื่ออนุมัติคำขอที่รอการตัดสินใจ
7. ใช้ **Guardian Chat** เพื่อสอบถามปัญหาหรือขอคำแนะนำจาก AI ผู้ดูแลระบบ

## เคล็ดลับ

- ตั้งค่าระดับความไวของเซ็นเซอร์ให้เหมาะสมกับปริมาณการใช้งานของแพลตฟอร์ม เพื่อลดการแจ้งเตือนที่ไม่จำเป็น
- ตรวจสอบแท็บการอนุมัติอย่างน้อยวันละครั้ง เพราะคำขอที่รอนานเกินไปอาจกระทบประสบการณ์ผู้ใช้
- ใช้ Guardian Chat เมื่อต้องการวิเคราะห์แนวโน้มเหตุการณ์หรือสอบถามว่าควรตั้งค่าเซ็นเซอร์อย่างไร
- บันทึกและติดตามเหตุการณ์ที่เกิดซ้ำเพื่อระบุปัญหาเชิงระบบที่ต้องแก้ไขในระยะยาว
