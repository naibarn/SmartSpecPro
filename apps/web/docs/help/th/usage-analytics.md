# วิเคราะห์การใช้งานและตรวจสอบงาน

## ภาพรวม

SmartAI Hub มีสองหน้าสำหรับติดตามการใช้งานและงานเบื้องหลัง ได้แก่ **Usage Dashboard** ที่ /usage และ **Task Queue Monitor** ที่ /tasks ใช้ทั้งสองร่วมกันเพื่อทำความเข้าใจว่าเครดิตของคุณถูกใช้ไปที่ไหนและแพลตฟอร์มกำลังทำอะไรในเบื้องหลัง

## Usage Dashboard (/usage)

Usage Dashboard แสดงการใช้เครดิตของคุณตามช่วงเวลาและแบ่งตามโมเดลและประเภทฟีเจอร์

### ตัวเลือกช่วงเวลา

สลับระหว่างมุมมองรายวัน รายสัปดาห์ และรายเดือนโดยใช้ตัวเลือกช่วงเวลาที่ด้านบนของหน้า กราฟจะอัปเดตทันทีเพื่อแสดงการใช้งานในช่วงนั้น

### กราฟการใช้เครดิต

- **เครดิตที่ใช้ทั้งหมด** — กราฟแท่งหรือเส้นของการใช้งานโดยรวมในช่วงที่เลือก
- **ตามโมเดล** — ดูว่า LLM หรือโมเดลสื่อใดใช้เครดิตมากที่สุด มีประโยชน์สำหรับการเลือกโมเดลที่คุ้มค่า
- **ตามฟีเจอร์** — แบ่งตาม chat, การสร้างสื่อ, agency runs, presentations และฟีเจอร์อื่นๆ

### มุมมองผู้ดูแลระบบ — แบ่งตามผู้ใช้

ผู้ดูแลระบบเห็นตารางเพิ่มเติมที่แสดงการใช้งานแบ่งตามผู้ใช้ มีประโยชน์สำหรับ:

- ระบุผู้ใช้ที่ใช้งานมากซึ่งอาจต้องการการจัดสรรเครดิตเพิ่มขึ้น
- ตรวจจับรูปแบบการใช้งานที่ผิดปกติซึ่งอาจบ่งชี้การใช้งานอัตโนมัติในทางที่ผิด
- Export รายงานสำหรับการเรียกเก็บเงินหรือ chargeback

### การวิเคราะห์ต้นทุน

แผงต้นทุนแปลงการใช้เครดิตเป็นต้นทุน USD โดยประมาณตามราคาโมเดลที่ผู้ดูแลระบบกำหนด ใช้เพื่อ:

- ระบุว่าโมเดลใดมีต้นทุนต่อคำขอสูงที่สุด
- เปรียบเทียบต้นทุนของ agency run กับการ chat โดยตรง
- ตัดสินใจเกี่ยวกับการเปิดใช้หรือจำกัดโมเดลที่มีราคาแพง

### การแจ้งเตือนงบประมาณ

ผู้ดูแลระบบสามารถกำหนดเกณฑ์การใช้จ่ายจาก **Admin → Settings → Credits and billing**:

- ตั้งงบประมาณเครดิตรายเดือนต่อผู้ใช้หรือสำหรับโดเมนทั้งหมด
- ผู้ใช้จะได้รับการแจ้งเตือนในแอปเมื่อถึง 80% และ 100% ของงบประมาณ
- ผู้ดูแลระบบได้รับอีเมลสรุปเมื่องบประมาณโดเมนใกล้ถึงขีดจำกัด

## Task Queue Monitor (/tasks)

Task Queue Monitor แสดงงานเบื้องหลังที่กำลังทำงานหรือเพิ่งเสร็จสิ้น งานจะถูกสร้างขึ้นเมื่อคุณเรียกใช้การดำเนินการที่ใช้เวลามากกว่าสองสามวินาที

### ประเภทงาน

| ประเภทงาน | เกิดจาก |
|---|---|
| Media generation | การสร้างรูปภาพ วิดีโอ หรือเสียง |
| Presentation export | Export presentation เป็น PDF หรือวิดีโอ |
| Agency run | เริ่มต้น workflow ของ agency หลาย agent |
| Skill execution | รัน skill ที่เรียก API ภายนอก |
| Document processing | อัปโหลดและจัดทำดัชนีเอกสารขนาดใหญ่ |

### สถานะงาน

| สถานะ | ความหมาย |
|---|---|
| Pending | งานอยู่ในคิวและรอ worker |
| Running | งานกำลังถูกประมวลผลอยู่ |
| Completed | งานเสร็จสมบูรณ์ |
| Failed | งานพบข้อผิดพลาด — ดูข้อความแสดงข้อผิดพลาดสำหรับรายละเอียด |

### การจัดการงาน

- **Cancel** — คลิกปุ่มยกเลิกบนงานที่รอหรือกำลังทำงานเพื่อหยุด เครดิตสำหรับงานที่ยกเลิกอาจคืนบางส่วนขึ้นอยู่กับว่าการประมวลผลดำเนินไปไกลแค่ไหน
- **Retry** — งานที่ล้มเหลวแสดงปุ่ม Retry คลิกเพื่อนำงานกลับเข้าคิวด้วยพารามิเตอร์เดิม
- **View result** — งานที่เสร็จแล้วเชื่อมโยงไปยังผลลัพธ์ (ไฟล์สื่อ presentation หรือรายการใน library)

## เคล็ดลับการจัดการต้นทุน

- ใช้โมเดลขนาดเล็กสำหรับ draft เบื้องต้น และสลับไปใช้โมเดลขนาดใหญ่เฉพาะสำหรับผลลัพธ์สุดท้าย
- ใช้ **Prompt Enhancement** ก่อนสร้างรูปภาพเพื่อให้ได้ผลลัพธ์ที่ดีขึ้นในครั้งแรกและหลีกเลี่ยงการสร้างใหม่
- ตรวจสอบการแบ่ง **ตามฟีเจอร์** เป็นประจำ — agency run มักใช้เครดิตมากกว่าการ chat โดยตรง
- ตั้งการแจ้งเตือนงบประมาณก่อนที่คุณจะต้องการ ไม่ใช่หลังจากใช้จ่ายเกินไปแล้ว
