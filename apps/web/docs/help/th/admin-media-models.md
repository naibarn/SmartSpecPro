# โมเดล Media AI

## ภาพรวม

หน้า Media AI Models ช่วยให้แอดมินจัดการแค็ตตาล็อกโมเดลสร้างสื่อสำหรับรูปภาพ วิดีโอ และเสียง เปิด/ปิดโมเดล กำหนดค่า และควบคุมว่าผู้ใช้เข้าถึงโมเดลใดได้

## แค็ตตาล็อกโมเดล

ตารางหลักแสดงโมเดลสื่อที่ลงทะเบียนทั้งหมดพร้อม:

- **ชื่อ** — ตัวระบุโมเดล (เช่น `flux-pro`, `stable-diffusion-xl`)
- **ผู้ให้บริการ** — บริการที่โฮสต์โมเดล (FAL.ai, Kie.ai, Stable Diffusion ฯลฯ)
- **ประเภท** — รูปภาพ, วิดีโอ หรือเสียง
- **สถานะ** — เปิดใช้ (เขียว) หรือปิด (เทา)
- **ราคา** — เครดิตต่อการสร้าง

## การกรองและค้นหา

- **ค้นหา** ตามชื่อโมเดลหรือผู้ให้บริการ
- **กรอง** ตามประเภท (รูปภาพ/วิดีโอ/เสียง) หรือตามผู้ให้บริการ
- **กรอง** ตามสถานะ (เปิด/ปิด)

## การเปิดและปิดโมเดล

สลับสวิตช์ข้างโมเดลเพื่อเปิดหรือปิด:

- **เปิดใช้** — ผู้ใช้สามารถเลือกโมเดลนี้ใน Media Studio
- **ปิดใช้** — โมเดลถูกซ่อนจากผู้ใช้แต่การตั้งค่ายังคงอยู่

## การตั้งค่าโมเดล

กดแถวโมเดลเพื่อกำหนดค่า:

- **พารามิเตอร์เริ่มต้น** — ความละเอียด คุณภาพ ขั้นตอน ฯลฯ
- **ราคาเครดิต** — จำนวนเครดิตที่ใช้ต่อการสร้าง
- **Rate limit** — การสร้างสูงสุดต่อผู้ใช้ต่อชั่วโมง
- **ลำดับ** — ลำดับแสดงผลในตัวเลือกโมเดล

## เคล็ดลับ

- ปิดโมเดลที่มีอัตรา error สูงจนกว่าผู้ให้บริการจะเสถียร
- ตั้งราคาเครดิตสูงขึ้นสำหรับโมเดลราคาแพงเพื่อจัดการการใช้งาน
- เปิดโมเดลรูปภาพและวิดีโออย่างน้อยอย่างละหนึ่งตัวเสมอ
