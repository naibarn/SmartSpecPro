# การอนุมัติ

## ภาพรวม

หน้าการอนุมัติเป็นศูนย์กลางสำหรับแอดมินในการตรวจสอบและจัดการคำขอที่ต้องการการอนุมัติก่อนดำเนินการต่อ คำขอเหล่านี้อาจมาจากเวิร์กโฟลว์ที่มีขั้นตอนการตรวจสอบโดยมนุษย์ หรือจากการดำเนินการที่ระบบกำหนดว่าต้องผ่านการอนุมัติก่อน แอดมินสามารถดูรายละเอียด อนุมัติ หรือปฏิเสธแต่ละคำขอได้

## วิธีเข้าถึง

ต้องมีสิทธิ์แอดมิน ไปที่เมนู **แอดมิน** แล้วคลิก **การอนุมัติ** หรือพิมพ์ URL `/admin/approvals` โดยตรง ไอคอนแบดจ์จะแสดงจำนวนคำขอที่รอดำเนินการ

## ความสามารถหลัก

- ดูคำขออนุมัติทั้งหมดแยกตามแท็บสถานะ ได้แก่ รอดำเนินการ อนุมัติแล้ว และปฏิเสธแล้ว
- ตรวจสอบรายละเอียดของแต่ละคำขอ รวมถึงผู้ร้องขอ บริบท และข้อมูลที่เกี่ยวข้อง
- อนุมัติหรือปฏิเสธคำขอพร้อมเพิ่มหมายเหตุหรือเหตุผลประกอบ
- กรองคำขอตามประเภทหรือผู้ร้องขอ
- ดูประวัติการอนุมัติและการตัดสินใจที่ผ่านมา
- รับการแจ้งเตือนเมื่อมีคำขอใหม่เข้ามา

## ขั้นตอนการใช้งาน

1. เปิดหน้าการอนุมัติจากเมนูแอดมิน
2. แท็บ **รอดำเนินการ** จะเปิดขึ้นเป็นค่าเริ่มต้น แสดงคำขอที่ต้องการการตัดสินใจ
3. คลิกคำขอใดก็ได้เพื่อดูรายละเอียดทั้งหมด รวมถึงบริบทของคำขอและข้อมูลจากเวิร์กโฟลว์
4. อ่านรายละเอียดอย่างละเอียดก่อนตัดสินใจ
5. คลิก **อนุมัติ** หรือ **ปฏิเสธ** พร้อมพิมพ์หมายเหตุหากต้องการอธิบายเหตุผล
6. ระบบจะแจ้งผู้ร้องขอและดำเนินการต่อหรือหยุดตามการตัดสินใจของแอดมิน
7. ดูแท็บ **อนุมัติแล้ว** หรือ **ปฏิเสธแล้ว** เพื่อตรวจสอบประวัติการตัดสินใจ

## เคล็ดลับ

- ตรวจสอบแท็บรอดำเนินการอย่างน้อยวันละครั้ง เพราะคำขอที่รอนานอาจทำให้เวิร์กโฟลว์ของผู้ใช้ติดขัด
- เพิ่มหมายเหตุเมื่อปฏิเสธคำขอเสมอ เพื่อให้ผู้ร้องขอเข้าใจเหตุผลและปรับปรุงคำขอครั้งถัดไปได้
- ใช้ตัวกรองประเภทเพื่อดูคำขออนุมัติจากเวิร์กโฟลว์เฉพาะเมื่อมีคำขอจำนวนมาก
- หากไม่แน่ใจเกี่ยวกับคำขอ สามารถใช้ Guardian Chat เพื่อขอข้อมูลเพิ่มเติมก่อนตัดสินใจ
