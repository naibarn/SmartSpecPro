# คุณภาพเนื้อหา

## ภาพรวม

Content Quality Dashboard ช่วยให้แอดมินติดตามคุณภาพของเนื้อหาที่ระบบ AI สร้างขึ้นอย่างต่อเนื่อง แดชบอร์ดรวบรวมคะแนนคุณภาพจากหลายมิติ เช่น ความถูกต้องของข้อมูล ความสอดคล้องกับ prompt ความคิดสร้างสรรค์ และการปฏิบัติตามแนวทางของแบรนด์ ข้อมูลเหล่านี้ช่วยให้ทีมสามารถระบุปัญหาด้านคุณภาพได้เร็ว และปรับแต่ง prompt หรือเลือก model ที่เหมาะสมกว่า

## วิธีเข้าถึง

เข้าสู่ระบบในฐานะแอดมิน จากนั้นไปที่เมนูด้านซ้าย เลือก **Admin** และคลิก **Content Quality** หรือไปที่ URL `/admin/content-quality` โดยตรง

## ความสามารถหลัก

- ดูคะแนนคุณภาพเฉลี่ยของเนื้อหาแยกตามประเภท skill และ LLM provider
- ติดตามแนวโน้มคะแนนในช่วงเวลาต่างๆ เพื่อตรวจจับการถดถอยของคุณภาพ
- ดูตัวอย่างเนื้อหาที่ได้คะแนนสูงสุดและต่ำสุดเพื่อเป็น reference
- วิเคราะห์สาเหตุของคะแนนต่ำ เช่น prompt ที่ไม่ชัดเจน หรือ model ที่ไม่เหมาะสม
- เปรียบเทียบคุณภาพของ model ต่างๆ สำหรับงานประเภทเดียวกัน
- ดูอัตราการ reject และ revision ของเนื้อหาโดยผู้ใช้

## ขั้นตอนการใช้งาน

1. เปิดหน้า **Content Quality** จากเมนู Admin
2. เลือกประเภทเนื้อหาหรือ skill ที่ต้องการวิเคราะห์จากตัวกรองด้านบน
3. กำหนดช่วงเวลาที่ต้องการดูข้อมูลโดยใช้ Date Picker
4. ดูแผนภูมิแนวโน้มคะแนนเพื่อระบุช่วงเวลาที่คุณภาพมีปัญหา
5. คลิกที่จุดในแผนภูมิหรือแถวในตาราง เพื่อดูตัวอย่างเนื้อหาและรายละเอียด
6. ใช้แท็บ **Model Comparison** เพื่อเปรียบเทียบประสิทธิภาพของ model ต่างๆ
7. บันทึกข้อสังเกตหรือส่งออกรายงานเพื่อแบ่งปันกับทีม

## เคล็ดลับ

- ตั้งค่า threshold ขั้นต่ำของคะแนนคุณภาพสำหรับแต่ละประเภทเนื้อหา และตรวจสอบเป็นประจำ
- เนื้อหาที่ได้คะแนนต่ำสม่ำเสมอจาก model เดียวกันอาจบ่งบอกว่าควรเปลี่ยน default model สำหรับ skill นั้น
- ดูข้อมูลควบคู่กับ Funnel Dashboard เพื่อเข้าใจว่าคุณภาพเนื้อหาส่งผลต่อพฤติกรรมผู้ใช้อย่างไร
- ใช้ตัวอย่างเนื้อหาที่ได้คะแนนสูงในการปรับปรุง prompt ของ skill ที่ยังมีคะแนนต่ำ
