# ผู้ให้บริการสื่อ

## ภาพรวม

การจัดการผู้ให้บริการสื่อกำหนดค่าบริการภายนอกที่ขับเคลื่อนการสร้างรูปภาพ วิดีโอ และเสียง ตั้ง API key ตรวจสอบสุขภาพ จัดการโควตา และติดตามต้นทุนต่อผู้ให้บริการ

## การเพิ่มผู้ให้บริการ

1. กด **Add Provider**
2. เลือกประเภทผู้ให้บริการ (FAL.ai, Kie.ai, Stable Diffusion, Replicate ฯลฯ)
3. กรอก **API key** — จะถูกเข้ารหัสก่อนจัดเก็บ
4. กำหนดค่าตัวเลือก:
   - **Base URL** — override สำหรับ instance ที่โฮสต์เอง
   - **Timeout** — เวลารอสูงสุดสำหรับ request สร้างสื่อ
   - **Concurrent limit** — request ขนานสูงสุดไปยังผู้ให้บริการนี้
5. กด **Save**

## สุขภาพผู้ให้บริการ

การ์ดแต่ละผู้ให้บริการแสดง:

- **สถานะ** — ปกติ (เขียว), ถดถอย (เหลือง), ล่ม (แดง)
- **Latency** — เวลาตอบสนองเฉลี่ยของ 100 request ล่าสุด
- **อัตรา error** — เปอร์เซ็นต์ request ที่ล้มเหลว
- **Circuit breaker** — หาก error เกินเกณฑ์ ผู้ให้บริการจะถูกปิดชั่วคราว

การตรวจสอบสุขภาพรันอัตโนมัติทุก 60 วินาที

## การจัดการโควตา

ตั้งวงเงินการใช้จ่ายต่อผู้ให้บริการ:

- **วงเงินรายวัน** — USD สูงสุดต่อวัน
- **วงเงินรายเดือน** — USD สูงสุดต่อเดือน
- เมื่อถึงวงเงิน ระบบจะส่ง request ไปยังผู้ให้บริการอื่น

## การติดตามต้นทุน

แผงต้นทุนแสดง:

- **ค่าใช้จ่ายรวม** เดือนนี้ต่อผู้ให้บริการ
- **ต้นทุนต่อการสร้าง** แยกตามโมเดล
- **กราฟแนวโน้ม** แสดงค่าใช้จ่ายรายวัน 30 วันที่ผ่านมา

## เคล็ดลับ

- กำหนดค่าอย่างน้อยสองผู้ให้บริการเพื่อความซ้ำซ้อน — หากผู้หนึ่งล่ม อีกผู้จะรับหน้าที่
- ตั้งวงเงินรายวันแบบอนุรักษ์นิยมก่อน แล้วเพิ่มตามการใช้งานจริง
- ตรวจสอบอัตรา error รายสัปดาห์เพื่อระบุผู้ให้บริการที่ต้อง rotate API key
