# ตลาด

## Marketplace คืออะไร?

Marketplace คือศูนย์กลางสำหรับค้นหาและติดตั้งเนื้อหาที่สร้างโดยชุมชน — skills, agencies สำเร็จรูป และเทมเพลต agency แทนที่จะสร้าง workflow ตั้งแต่ต้น ให้เริ่มจากจุดเริ่มต้นที่ผ่านการพิสูจน์แล้วและปรับแต่งให้เหมาะกับความต้องการของคุณ

## Skill Marketplace (/marketplace)

Skill Marketplace ให้คุณเรียกดูและติดตั้ง AI skills ที่สร้างโดยชุมชน SmartAI Hub และทีมแพลตฟอร์ม

### เรียกดู skills

- ใช้ **แถบค้นหา** เพื่อค้นหา skill ตามชื่อหรือคำอธิบาย
- กรองตาม **หมวดหมู่**: การเขียนเนื้อหา, วิจัย, สร้างรูปภาพ, วิดีโอ, เสียง, วิเคราะห์, ประสิทธิภาพการทำงาน และอื่นๆ
- เรียงตาม **ติดตั้งมากที่สุด**, **คะแนนสูงสุด** หรือ **ใหม่ที่สุด**
- การ์ด skill แต่ละใบแสดงชื่อ skill, คำอธิบาย, ไอคอนหมวดหมู่, จำนวนการติดตั้ง และคะแนนเฉลี่ย

### ติดตั้ง skill

1. คลิกการ์ด skill เพื่อเปิดหน้ารายละเอียด
2. ตรวจสอบคำอธิบาย skill, prompt ตัวอย่าง และ field input
3. คลิก **Install** — skill จะถูกเพิ่มในบัญชีของคุณทันที
4. Skill พร้อมใช้งานในเมนู slash-command ของ Chat (`/`) และในแผง Skills

### หลังติดตั้ง

- Skill ที่ติดตั้งจะ sync โดยอัตโนมัติ — ไม่ต้องรีสตาร์ทเซิร์ฟเวอร์
- คุณสามารถถอนการติดตั้ง skill ได้ตลอดเวลาจาก **Settings → Skills**
- หาก skill ได้รับการอัปเดตโดยผู้เขียน คุณสามารถเลือกอัปเดตเป็นเวอร์ชันใหม่จาก Marketplace

## Agency Marketplace (/agencies/marketplace)

Agency Marketplace ให้คุณค้นหาทีม AI หลายตัวที่สร้างสำเร็จรูปและพร้อมใช้งาน

### เรียกดู agencies

- เรียกดูตาม **use case**: วิจัย, สร้างเนื้อหา, วิเคราะห์ข้อมูล, ผลิตวิดีโอ, ประสิทธิภาพการทำงาน
- รายการ agency แต่ละรายการแสดง agent ที่เกี่ยวข้อง ประเภทผลลัพธ์ทั่วไป เวลาทำงานเฉลี่ย และคะแนนผู้ใช้
- คลิก agency ใดก็ได้เพื่อดูตัวอย่างการตั้งค่า agent ก่อนติดตั้ง

### ติดตั้ง agency

1. เปิดรายการ agency และตรวจสอบการตั้งค่า agent
2. คลิก **Install Agency** — จะปรากฏในรายการ Agencies ของคุณทันที
3. เปิด agency และพิมพ์คำขอเพื่อเริ่มต้น run

## Agency Templates (/agencies/templates)

Agency Templates คือจุดเริ่มต้นที่คัดสรรสำหรับ use case agency ที่พบบ่อยที่สุด เทมเพลตดูแลโดยทีมแพลตฟอร์มและอัปเดตอยู่เสมอ

### หมวดหมู่เทมเพลตที่มี

- **Deep Research** — วิจัยจากหลายแหล่งพร้อม executive summary, ผลการค้นพบสำคัญ และคำแนะนำ
- **Storyboard Planner** — วางแผนวิดีโอแบบ scene-by-scene พร้อมบทพูด มุมกล้อง และ prompt สำหรับเสียงและวิดีโอ
- **Deck Builder** — สร้างสไลด์ทั้งชุดพร้อม speaker notes และคำแนะนำกราฟิก
- **Comparison Agent** — เปรียบเทียบตัวเลือกแบบ side-by-side พร้อมราคา ลิงก์หลักฐาน และคำแนะนำ
- **Custom** — เทมเพลต agency เปล่าสำหรับสร้างทั้งหมดตั้งแต่ต้น

### สร้างจากเทมเพลต

1. ไปที่ **Agencies → Templates**
2. คลิกการ์ดเทมเพลตใดก็ได้เพื่อดูตัวอย่าง
3. คลิก **Use Template** — agency ใหม่จะถูกสร้างพร้อม agent และ workflow ทั้งหมดที่กำหนดค่าไว้ล่วงหน้า
4. ตั้งชื่อ agency และปรับแต่งคำแนะนำ agent ก่อน run ครั้งแรก

## เคล็ดลับ

- **ลองใช้เทมเพลตก่อน** ก่อนสร้างตั้งแต่ต้น — เทมเพลตรวบรวม best practice สำหรับ workflow ทั่วไป
- **ตรวจสอบคะแนนและจำนวนการติดตั้ง** ก่อนติดตั้ง skill หรือ agency จากชุมชน ตัวเลขสูงกว่าบ่งบอกถึงความน่าเชื่อถือ
- **ดูตัวอย่างการกำหนดค่า** ก่อนติดตั้ง agencies — การเข้าใจโครงสร้าง agent ช่วยให้คุณเขียน prompt ได้ดีขึ้น
- หาก skill หรือ agency ไม่ทำงานตามที่คาดหลังติดตั้ง ให้ให้คะแนนและตรวจสอบว่ามีเวอร์ชันที่อัปเดตแล้วหรือไม่
