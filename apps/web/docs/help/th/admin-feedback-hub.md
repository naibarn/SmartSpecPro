# ศูนย์รวมข้อเสนอ (Feedback Hub)

## ภาพรวม

Feedback Hub คือหน้าจัดการ feedback สำหรับแอดมิน รวม ticket ทั้งหมดจากผู้ใช้ไว้ในที่เดียว พร้อมการวิเคราะห์โดย AI เพื่อช่วยให้การคัดกรองและแก้ไขปัญหาทำได้รวดเร็วยิ่งขึ้น

## รายการ Ticket

ด้านซ้ายแสดงรายการ ticket ทั้งหมดพร้อม:
- **badge สถานะ** แสดงสถานะปัจจุบัน
- **ประเภท** (Bug Report, Feature Request, Observation, Question)
- **วันที่สร้าง** และ **ชื่อผู้ใช้**

### ตัวกรอง

คัดกรองรายการตาม:
- **สถานะ** — new, triaged, in_progress, resolved, closed, deferred, duplicate
- **ประเภท** — bug, feature_request, observation, question
- **ช่วงเวลา** — เลือกวันที่เริ่มและสิ้นสุด

## รายละเอียด Ticket

เลือก ticket ด้านซ้ายเพื่อดูรายละเอียดด้านขวา:

- **หัวข้อ** และ **คำอธิบาย** ที่ผู้ใช้กรอก
- **ขั้นตอนจำลอง** — วิธีทำให้เกิดปัญหาซ้ำ
- **ผลที่คาดหวัง** และ **สิ่งที่เกิดขึ้นจริง**
- **ไฟล์แนบ** — รูปภาพ, PDF, หรือ Markdown ที่ผู้ใช้แนบมา

## การวิเคราะห์ AI

เมื่อ ticket ถูกสร้าง ระบบ AI จะวิเคราะห์อัตโนมัติและแสดงผลในกล่อง **AI Analysis**:

- **หมวดหมู่** — จัดประเภทอัตโนมัติ (bug, performance, feature request, question)
- **ลำดับความสำคัญ** — high, normal, หรือ low
- **สรุป** — สรุปปัญหาในหนึ่งประโยค
- **ตรวจจับซ้ำ** — แจ้งเตือนหากมี ticket ที่คล้ายกันเปิดอยู่แล้ว

## สถานะ Ticket

| สถานะ | ความหมาย |
|-------|---------|
| **new** | เพิ่งส่งมา ยังไม่ได้ดู |
| **triaged** | ผ่านการคัดกรองแล้ว |
| **in_progress** | กำลังดำเนินการแก้ไข |
| **resolved** | แก้ไขแล้ว แจ้งผู้ใช้แล้ว |
| **closed** | ปิด ticket โดยไม่ดำเนินการ |
| **deferred** | เลื่อนไปก่อน |
| **duplicate** | ซ้ำกับ ticket อื่น |

เปลี่ยนสถานะได้จาก dropdown **Status** ที่ด้านบนของรายละเอียด ticket

## ความคิดเห็นและการตอบกลับ

### ตอบกลับผู้ใช้

พิมพ์ข้อความในช่อง **Reply** แล้วกด **Send** เพื่อส่งข้อความถึงผู้ใช้ ผู้ใช้จะได้รับการแจ้งเตือนและมองเห็นข้อความนี้ในหน้า My Feedback

### บันทึกภายใน (Internal Note)

เปิดสวิตช์ **Internal** ก่อนกด Send เพื่อบันทึกเป็นข้อมูลภายในทีม ผู้ใช้จะไม่มองเห็นข้อความ internal note

## จัดการไฟล์แนบ

ในแท็บ **Attachments** ของ ticket:
- **ดู** — คลิกเพื่อเปิดไฟล์ในแท็บใหม่ (รูปภาพแสดง thumbnail)
- **ดาวน์โหลด** — บันทึกไฟล์ลงเครื่อง
- **ลบ** — ลบไฟล์แนบออกจาก ticket (ยืนยันก่อนลบ)

## สถิติ

แถบด้านบนแสดงจำนวน ticket แยกตามสถานะ:

| ตัวชี้วัด | คำอธิบาย |
|---------|---------|
| **Total** | จำนวน ticket ทั้งหมด |
| **New** | ยังไม่ได้คัดกรอง |
| **Triaged** | ผ่านการคัดกรองแล้ว |
| **In Progress** | กำลังดำเนินการ |
| **Resolved** | แก้ไขแล้ว |

## เคล็ดลับการจัดการ Feedback Hub

- **ใช้ตัวกรองสถานะ "new"** เพื่อดู ticket ใหม่ที่ยังไม่ได้ดู
- **ตรวจสอบ AI Analysis** ก่อนเสมอ — ช่วยประหยัดเวลาในการจัดประเภท
- **ใช้ internal note** เพื่อบันทึกแนวทางแก้ไขสำหรับทีม โดยไม่ให้ผู้ใช้เห็น
- **ตั้งสถานะ duplicate** แล้วลิงก์ไปยัง ticket ต้นฉบับ เพื่อติดตามได้ง่าย
