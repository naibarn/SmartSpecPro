# คีย์ API

## คีย์ API คืออะไร?

คีย์ API คือ Token การยืนยันตัวตนที่ช่วยให้คุณเข้าถึง SmartAI Hub แบบ Programmatic — จากสคริปต์ การผสานรวม หรือเครื่องมือของบุคคลที่สามของคุณเอง แทนที่จะเข้าสู่ระบบผ่านเบราว์เซอร์ คุณยืนยันตัวตนแต่ละ Request ด้วยคีย์

## คีย์ API ของผู้ใช้

จัดการคีย์ API ส่วนตัวได้ที่ **Settings → API**

### การสร้างคีย์ใหม่

1. ไปที่ **Settings → API**
2. คลิก **Generate New Key**
3. ใส่ชื่อที่สื่อความหมาย (เช่น "สคริปต์อัตโนมัติของฉัน", "การผสานรวม Zapier")
4. ตั้งวันหมดอายุหรือไม่ก็ได้ คีย์ที่ไม่มีวันหมดอายุจะใช้งานได้จนกว่าจะถูกเพิกถอน
5. คลิก **Generate**
6. **คัดลอกคีย์ทันที** — แสดงเพียงครั้งเดียวและไม่สามารถดึงกลับมาได้อีก เก็บไว้ในที่ปลอดภัยเช่น Password Manager หรือ Environment Variable

### การเพิกถอนคีย์

- ค้นหาคีย์ในรายการที่ **Settings → API**
- คลิก **Revoke** ข้างคีย์ที่ต้องการปิดใช้งาน
- คีย์หยุดทำงานทันที บริการใดๆ ที่ใช้คีย์นั้นจะได้รับการตอบสนอง `401 Unauthorized`

### Rate Limit

แต่ละคีย์มี Rate Limit เพื่อป้องกันการใช้งานในทางที่ผิด ค่า Limit เริ่มต้นแสดงอยู่ในหน้าการตั้งค่า API ติดต่อ Admin หากต้องการ Limit ที่สูงขึ้นสำหรับ Workflow อัตโนมัติ

## การจัดการคีย์ API สำหรับ Admin

Admin สามารถจัดการคีย์ของผู้ใช้ทั้งหมดได้ที่ **/admin/api-keys**:

- ดูคีย์ที่ใช้งานอยู่ทั้งหมดในทุก User
- ดูสถิติการใช้งานต่อคีย์ (จำนวน Request, วันที่ใช้ล่าสุด)
- กำหนด Rate Limit ทั่วไปที่ใช้กับคีย์ทั้งหมด
- เพิกถอนคีย์ใดก็ได้ทันทีหากจำเป็น
- ตรวจสอบรูปแบบการใช้งานที่ผิดปกติ

## การใช้ API

### Base URL

```
https://smartaihub.app/v1/
```

### การยืนยันตัวตน

ใส่คีย์ API ใน Header `Authorization` ของทุก Request:

```
Authorization: Bearer <คีย์-api-ของคุณ>
```

### เอกสาร API

เอกสาร API แบบ Interactive (Swagger UI) มีให้ที่:

```
https://smartaihub.app/v1/docs
```

### Endpoint ที่มีให้บริการ

| กลุ่ม Endpoint | คำอธิบาย |
|---|---|
| `/v1/skills` | รัน Skill และดึงคำนิยาม Skill |
| `/v1/agencies` | รัน Agency และดึงผลลัพธ์ |
| `/v1/presentations` | สร้างและจัดการ Presentation |
| `/v1/media` | สร้างภาพและวิดีโอ |
| `/v1/chat` | ส่งข้อความและดึงประวัติบทสนทนา |

### ตัวอย่าง Request

```bash
curl https://smartaihub.app/v1/chat \
  -H "Authorization: Bearer sk-คีย์-ของคุณ" \
  -H "Content-Type: application/json" \
  -d '{"message": "สรุปย่อหน้านี้เป็นสามจุด"}'
```

## การใช้เครดิต

การเรียก API ใช้เครดิตในอัตราเดียวกับการดำเนินการที่เทียบเท่าใน UI ต้นทุนเครดิตของแต่ละ Request จะส่งคืนใน Header การตอบสนอง `X-Credits-Used` เพื่อให้คุณตรวจสอบการใช้งานในการผสานรวมของคุณได้

## แนวปฏิบัติที่ดีที่สุด

- **อย่า Hardcode คีย์ในซอร์สโค้ด** — ใช้ Environment Variable หรือ Secrets Manager แทน
- **กำหนดวันหมดอายุ** — การหมุนเวียนคีย์ตามกำหนดเวลาช่วยจำกัดความเสียหายหากคีย์รั่วไหล
- **ใช้หนึ่งคีย์ต่อหนึ่งการผสานรวม** — คีย์แยกกันทำให้ง่ายต่อการเพิกถอนสิทธิ์เข้าถึงสำหรับการผสานรวมเดียวโดยไม่กระทบอื่น
- **ตรวจสอบการใช้งานเป็นประจำ** — ดูสถิติการใช้งานคีย์ที่ **Settings → API** เพื่อตรวจจับการเพิ่มขึ้นที่ผิดปกติ
- **อย่าแชร์คีย์** — แต่ละคนหรือบริการควรมีคีย์ของตัวเองเพื่อให้สามารถเพิกถอนสิทธิ์เข้าถึงได้แยกกัน
- **ให้ความนิยมคีย์อายุสั้น** — สำหรับสคริปต์ครั้งเดียว สร้างคีย์ที่หมดอายุใน 24 ชั่วโมงแทนการใช้คีย์อายุยาว
