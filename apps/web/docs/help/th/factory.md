# SaaS Factory

## ภาพรวม

SaaS Factory เป็นแดชบอร์ดจัดการโปรเจกต์ที่ช่วยให้คุณสร้างโปรเจกต์ รันเวิร์กโฟลว์หลายขั้นตอน จัดการเซสชัน ประเมิน quality gate และจัดการผลงานที่สร้างขึ้นด้วยระบบอนุมัติ

## การสร้างโปรเจกต์

1. กด **New Project** บนหน้า Factory
2. กรอกชื่อโปรเจกต์และคำอธิบาย
3. กำหนดขั้นตอนเวิร์กโฟลว์ — แต่ละขั้นตอนกำหนดการทำงาน (เรียก LLM, สร้างสื่อ, รันโค้ด ฯลฯ)
4. ตั้ง quality gate ระหว่างขั้นตอนเพื่อให้ผลลัพธ์ผ่านเกณฑ์ก่อนดำเนินการต่อ

## การรันเวิร์กโฟลว์

- **เริ่มเซสชัน** ภายในโปรเจกต์เพื่อเริ่มการทำงาน
- Orchestrator รันแต่ละขั้นตอนตามลำดับ ส่งผลลัพธ์ระหว่างขั้นตอน
- **Quality gate** ประเมินผลลัพธ์อัตโนมัติ — หากไม่ผ่าน เวิร์กโฟลว์จะหยุดรอการตรวจสอบ
- ติดตามความคืบหน้าแบบเรียลไทม์ด้วยตัวบ่งชี้สถานะของแต่ละขั้นตอน

## การจัดการผลงาน

เนื้อหาที่สร้างขึ้น (ข้อความ รูปภาพ โค้ด) จากแต่ละขั้นตอนจะถูกเก็บเป็น **artifact**

- ดู artifact ในแผงรายละเอียดเซสชัน
- **อนุมัติหรือปฏิเสธ** artifact ก่อนส่งต่อไปยังขั้นตอนถัดไป
- ดาวน์โหลด artifact แยกรายการ หรือส่งออกผลลัพธ์ทั้งเซสชัน

## ประวัติเซสชัน

- เซสชันทั้งหมดถูกบันทึกพร้อมประวัติการทำงานครบถ้วน
- รันเซสชันที่ล้มเหลวใหม่ หรือ clone เซสชันที่สำเร็จเป็นเทมเพลต
- กรองเซสชันตามสถานะ: กำลังรัน, เสร็จสิ้น, ล้มเหลว, หรือหยุดชั่วคราว

## เคล็ดลับ

- แบ่งเวิร์กโฟลว์ที่ซับซ้อนเป็นขั้นตอนย่อยพร้อม quality gate คั่นระหว่าง
- ใช้ชื่อขั้นตอนที่สื่อความหมายเพื่อให้ log การทำงานอ่านง่าย
- ตรวจสอบ artifact ทันที — เวิร์กโฟลว์ที่หยุดรอจะใช้ทรัพยากรจนกว่าจะอนุมัติ
