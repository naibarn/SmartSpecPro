# การตั้งค่าการแจ้งเตือน

## ภาพรวม

การตั้งค่าการแจ้งเตือนช่วยให้คุณควบคุมวิธีและเวลาที่จะได้รับการแจ้งเตือนสำหรับแต่ละหมวดหมู่ เข้าถึงแท็บ Notifications จากหน้า Settings เพื่อกำหนดช่องทางการส่ง ตัวกรองระดับความรุนแรง และกำหนดการปิดเสียงต่อหมวดหมู่

**Feature flag:** ต้องเปิดใช้งาน `notificationPreferencesEnabled` เพื่อให้แท็บ Notifications ปรากฏในหน้า Settings

## หมวดหมู่

SmartAI Hub จัดระเบียบการแจ้งเตือนเป็น 10 หมวดหมู่:

| หมวดหมู่ | คำอธิบาย |
|----------|----------|
| สุขภาพระบบ | แจ้งเตือนโครงสร้างพื้นฐาน, บริการล่ม, Health Check ล้มเหลว |
| งานสื่อ | การสร้างสื่อเสร็จสมบูรณ์, ล้มเหลว, และคำเตือนโควต้า |
| เวิร์กโฟลว์ | ผลลัพธ์การทำงานเวิร์กโฟลว์, ขั้นตอนสำเร็จ, ข้อผิดพลาด |
| ทักษะ | ผลลัพธ์การทำงานทักษะ, การตรวจจับ |
| ข้อเสนอแนะ | การส่งข้อเสนอแนะของผู้ใช้และการตอบกลับ |
| เอเจนซี่ | ผลลัพธ์การทำงานเอเจนซี่, การกระทำของเอเจนต์ |
| การติดตาม | การแจ้งเตือนจากเนื้อหาหรือผู้ใช้ที่ติดตาม |
| ข้อความตั้งเวลา | การส่งข้อความตามกำหนดเวลาและการเตือนความจำ |
| ความปลอดภัย | แจ้งเตือนการเข้าสู่ระบบ, เปลี่ยน 2FA, คำเตือนกิจกรรมที่น่าสงสัย |
| ธุรกิจ | แจ้งเตือนเครดิต, การแจ้งเตือนการเรียกเก็บเงิน, เกณฑ์การใช้งาน |

## การควบคุมต่อหมวดหมู่

สำหรับแต่ละหมวดหมู่ คุณสามารถกำหนดค่า:

### ช่องทางการส่ง

- **ในแอป** — การแจ้งเตือนปรากฏในกระดิ่งแจ้งเตือนและแผงการแจ้งเตือน (เปิดใช้งานตามค่าเริ่มต้น)
- **อีเมล** — รับอีเมลสำหรับการแจ้งเตือนระดับ high/critical หรือสรุปรวมสำหรับระดับอื่น
- **เทเลแกรม** — รับการแจ้งเตือนผ่าน Telegram Bot (เมื่อกำหนดค่าแล้ว)

### ระดับความรุนแรงขั้นต่ำ

ตั้งค่าเกณฑ์ขั้นต่ำต่อหมวดหมู่ การแจ้งเตือนที่ต่ำกว่าระดับนี้จะถูกซ่อนโดยอัตโนมัติ:

- **Low** — รับทุกอย่าง (ค่าเริ่มต้น)
- **Normal** — ข้ามการแจ้งเตือนที่มีความสำคัญต่ำ
- **High** — รับเฉพาะแจ้งเตือนระดับ high และ critical
- **Critical** — รับเฉพาะการแจ้งเตือนที่เร่งด่วนที่สุด

### ปิดเสียง

ปิดเสียงหมวดหมู่ชั่วคราวจนถึงวันที่และเวลาที่กำหนด หมวดหมู่ที่ปิดเสียงจะไม่ส่งการแจ้งเตือนจนกว่าจะหมดอายุ เหมาะสำหรับช่วงซ่อมบำรุงหรือช่วงที่มีสัญญาณรบกวนมาก

## อีเมลสรุป

แทนที่จะรับอีเมลแยกสำหรับทุกการแจ้งเตือน กำหนดค่าการสรุป:

- **รายชั่วโมง** — รับอีเมลสรุปทุกชั่วโมงพร้อมการแจ้งเตือนที่ไม่ใช่ระดับวิกฤต
- **รายวัน** — รับสรุปรายวันตามเวลาที่เลือก (0–23)

การแจ้งเตือนระดับ high และ critical จะถูกส่งทันทีเสมอโดยไม่ขึ้นกับการตั้งค่าสรุป

## ความสัมพันธ์กับฟีเจอร์อื่น

- **การข้ามจากการยกระดับ** — การแจ้งเตือนที่ยกระดับแล้ว (`isEscalated: true`) จะข้ามการตั้งค่าของคุณเสมอและส่งผ่านทุกช่องทาง
- **Admin Broadcasts** — การแจ้งเตือนทั่วทั้งระบบจะถูกส่งเสมอโดยไม่ขึ้นกับการตั้งค่าหมวดหมู่
- **การรวมกลุ่ม** — การแจ้งเตือนที่ถูกรวมกลุ่มจะเคารพการตั้งค่าของคุณ คุณจะเห็นเฉพาะผลลัพธ์ที่รวมแล้ว
- **เว็บฮุก** — การส่งเว็บฮุกแยกจากการตั้งค่าของผู้ใช้ เว็บฮุกทำงานตามตัวกรองหมวดหมู่และระดับความรุนแรงของตัวเอง

## เคล็ดลับ

- เริ่มต้นด้วยการปิดเสียงหมวดหมู่ที่ไม่จำเป็น — สามารถเปิดใหม่ได้เสมอ
- ตั้งค่า "High" เป็นระดับขั้นต่ำสำหรับหมวดหมู่ที่มีสัญญาณรบกวนมาก เช่น Media Jobs เพื่อเน้นเฉพาะความล้มเหลว
- ใช้อีเมลสรุปรายชั่วโมงเพื่อติดตามข่าวสารโดยไม่ท่วม Inbox
- นโยบายการยกระดับจะยังเข้าถึงคุณได้แม้คุณจะปิดเสียงหมวดหมู่ — นี่เป็นการออกแบบสำหรับแจ้งเตือนวิกฤต
