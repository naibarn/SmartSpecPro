# ประวัติสื่อ

หน้า **ประวัติสื่อ** ใช้สำหรับตรวจสอบรูปภาพ วิดีโอ และเสียงที่สร้างด้วย AI ในช่วงล่าสุด คุณสามารถย้อนดูผลลัพธ์ ดาวน์โหลดไฟล์ คัดลอกพรอมต์ เพิ่มรายการสำคัญเข้าคลัง และตรวจสอบงานที่ล้มเหลวหรือยังรอผลลัพธ์จากผู้ให้บริการได้จากหน้านี้

## สิ่งที่แสดงในหน้านี้

แต่ละรายการอาจแสดงข้อมูลต่อไปนี้:

- ตัวอย่างสื่อที่สร้างแล้ว
- ประเภทสื่อ เช่น รูปภาพ วิดีโอ หรือเสียง
- สถานะงาน เช่น รอดำเนินการ กำลังประมวลผล เสร็จแล้ว ล้มเหลว หรือยกเลิก
- โมเดลและพรอมต์ที่ใช้สร้าง
- เวลาเริ่มสร้างและเครดิตที่ใช้
- สถานะในคลัง หากรายการนั้นถูกบันทึกไว้แล้ว

โปรดจำไว้ว่า Media History เป็นพื้นที่ชั่วคราว ระบบจะแสดงประวัติล่าสุดได้สูงสุด **12 วัน** แต่สื่อบางรายการอาจขึ้นกับข้อจำกัดของผู้ให้บริการ API และอาจหมดอายุหรือลบออกก่อนกำหนด ควรดาวน์โหลดหรือเพิ่มรายการสำคัญเข้าคลังทันทีเมื่อแน่ใจว่าต้องการเก็บไว้

## ค้นหาและตัวกรอง

ใช้ช่องค้นหาเพื่อหารายการในหน้าปัจจุบันจากพรอมต์ โมเดล รหัสงาน สถานะ หรือสรุปข้อผิดพลาด จากนั้นใช้ตัวกรองเพื่อจำกัดรายการ:

- **ประเภท** ใช้กรองเฉพาะรูปภาพ วิดีโอ หรือเสียง
- **สถานะ** ใช้ดูเฉพาะงานที่เสร็จแล้ว กำลังทำงาน ล้มเหลว หรือถูกยกเลิก
- **ล้างตัวกรอง** ใช้รีเซ็ตคำค้นหา ประเภท สถานะ และหน้าที่กำลังดู

ใช้ปุ่มเปลี่ยนหน้าเพื่อดูรายการเก่าหรือใหม่กว่าภายในช่วงเวลาที่ระบบยังเก็บประวัติไว้

## มุมมองรายการและแกลเลอรี

เลือก **รายการ** เมื่อต้องการเทียบหลายงานอย่างรวดเร็ว มุมมองนี้เหมาะกับการดูสถานะ รหัสงาน พรอมต์ เครดิต และการเลือกหลายรายการ

เลือก **แกลเลอรี** เมื่อต้องการตรวจภาพรวมเชิง visual การ์ดจะแสดง preview, พรอมต์, โมเดล และปุ่มหลัก ส่วนคำสั่งรอง เช่น เพิ่มเข้าคลัง แชร์ เปิดเต็มจอ คัดลอกพรอมต์ หรือซิงก์ผลลัพธ์จากผู้ให้บริการ จะอยู่ในเมนู **การทำงานเพิ่มเติม**

## การทำงานที่ใช้บ่อย

- **รายละเอียด** — เปิดข้อมูลของงาน รวมถึงข้อมูลจากผู้ให้บริการหรือ debug เมื่อมี
- **ดาวน์โหลด** — เปิดหรือดาวน์โหลดไฟล์ที่สร้างแล้ว ควรทำก่อน URL หมดอายุ
- **เพิ่มเข้าคลัง** — บันทึกผลลัพธ์ที่เสร็จแล้วเพื่อใช้ซ้ำและค้นหาได้ระยะยาวกว่า
- **แชร์** — ใช้ได้หลังจากเพิ่มรายการเข้าคลังแล้ว
- **เต็มจอ** — ดูรูปภาพหรือวิดีโอขนาดใหญ่ขึ้น
- **คัดลอกพรอมต์** — นำพรอมต์เดิมไปใช้ต่อใน Media Studio หรือ Chat
- **ลองสร้างใหม่** — ส่งพรอมต์กลับไป Media Studio เพื่อสร้างอีกครั้งเมื่อรายการล้มเหลว

## งานล้มเหลว งานค้าง หรือยังไม่มีผลลัพธ์

ผู้ให้บริการบางรายอาจสร้างเสร็จหลังจากระบบอัปเดตสถานะครั้งแรก หากงานมีรหัสจากผู้ให้บริการแต่ยังไม่มี URL ผลลัพธ์ ให้ใช้ **ดึง URL** หรือ **ดึง URL ใหม่** เพื่อซิงก์สถานะล่าสุด หากงานล้มเหลว ให้เปิด **รายละเอียด** เพื่อดูสรุปข้อผิดพลาด แล้วลองแก้พรอมต์ เปลี่ยนการตั้งค่า หรือสร้างใหม่

## แนวทางที่แนะนำ

- เก็บรายการสำคัญไว้ในคลัง ไม่พึ่ง Media History เพียงอย่างเดียว
- ดาวน์โหลดไฟล์ที่พร้อมส่งงานทันทีหลังตรวจผ่าน
- คัดลอกพรอมต์ที่ได้ผลดีไว้ก่อนทดลอง variation
- ใช้ตัวกรองเพื่อตรวจงานที่ล้มเหลวหรือยังประมวลผลก่อนจบ session
- มอง URL จากผู้ให้บริการเป็นไฟล์ชั่วคราว แม้หน้านี้จะแสดงประกาศเก็บข้อมูล 12 วัน
