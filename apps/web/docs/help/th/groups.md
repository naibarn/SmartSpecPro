# กลุ่ม

## กลุ่มคืออะไร?

กลุ่มคือพื้นที่ทำงานร่วมกันที่ทีมงานและชุมชนสามารถทำงานด้วยกัน แชร์บทสนทนา และรวบรวมทรัพยากรได้ กลุ่มอาจเป็นทีมงาน ชุมชนโปรเจกต์ กลุ่มสนใจตามหัวข้อ หรือกลุ่มคนใดๆ ที่ต้องการทำงานร่วมกันในพื้นที่เดียวกัน

## การสร้างกลุ่ม

1. ไปที่ **Groups** ในแถบด้านข้าง
2. คลิก **Create Group**
3. ใส่ชื่อและคำอธิบายสั้นๆ
4. เลือกการมองเห็น:
   - **Public** — ทุกคนสามารถค้นพบและเข้าร่วมกลุ่มได้
   - **Private** — เฉพาะสมาชิกที่ได้รับเชิญเท่านั้นที่เข้าร่วมได้ กลุ่มจะไม่ปรากฏใน Discovery
5. คลิก **Create**

คุณจะกลายเป็นเจ้าของกลุ่มโดยอัตโนมัติ

## การเข้าร่วมกลุ่ม

- ไปที่ **Groups → Discover** เพื่อเรียกดูกลุ่มสาธารณะ
- ใช้แถบค้นหาเพื่อหากลุ่มตามชื่อหรือหัวข้อ
- คลิก **Join** บนกลุ่มสาธารณะใดก็ได้เพื่อเป็นสมาชิกทันที
- สำหรับกลุ่มส่วนตัว คลิก **Request to Join** — เจ้าของกลุ่มหรือ Admin ต้องอนุมัติคำขอของคุณ
- คุณยังสามารถเข้าร่วมกลุ่มผ่านลิงก์เชิญที่สมาชิกส่งมาได้

## ฟีเจอร์ของกลุ่ม

เมื่ออยู่ในกลุ่มแล้ว สมาชิกสามารถเข้าถึงร่วมกันได้:

- **Conversations** — เธรดแชทเฉพาะที่สมาชิกทุกคนในกลุ่มมองเห็น
- **Resources** — ไฟล์ ลิงก์ และเอกสารอ้างอิงที่สมาชิกอัปโหลดร่วมกัน
- **Members** — รายชื่อผู้เข้าร่วมกลุ่มทั้งหมดและบทบาท
- **Activity feed** — สรุปกิจกรรมล่าสุดของกลุ่ม

## การจัดการสมาชิก

เจ้าของกลุ่มและ Admin สามารถ:

- **เชิญสมาชิก** — ส่งลิงก์เชิญหรือค้นหาด้วยชื่อผู้ใช้/อีเมล
- **ลบสมาชิก** — ลบใครก็ได้ที่ไม่ใช่เจ้าของ
- **กำหนดบทบาท** — มอบบทบาท **Admin** ให้สมาชิกที่ไว้วางใจเพื่อช่วยจัดการกลุ่ม
- **อนุมัติคำขอเข้าร่วม** — สำหรับกลุ่มส่วนตัว ตรวจสอบและยอมรับหรือปฏิเสธคำขอที่เข้ามา

ไปจัดการสมาชิกได้ที่หน้ากลุ่มแล้วคลิก **Members → Manage**

## การค้นพบกลุ่ม

หน้า **Discover** ที่ **Groups → Discover** แสดงกลุ่มสาธารณะเรียงตามกิจกรรมและจำนวนสมาชิก คุณสามารถ:

- กรองตาม Tag หัวข้อ
- ค้นหาด้วยคีย์เวิร์ด
- เรียงตามใหม่ที่สุด กิจกรรมมากที่สุด หรือสมาชิกมากที่สุด

## เคล็ดลับ

- **ใช้ชื่อที่สื่อความหมาย** — ชื่อที่ชัดเจนช่วยให้คนเข้าใจวัตถุประสงค์ของกลุ่มก่อนเข้าร่วม
- **ตั้งคำอธิบายที่ชัดเจน** — อธิบายว่ากลุ่มนี้มีไว้เพื่ออะไรและสำหรับใครในช่องคำอธิบาย
- **เริ่มต้นแบบ Private** — หากกลุ่มเป็นทีมภายใน ตั้งเป็น Private เพื่อควบคุมสมาชิกภาพ
- **แต่งตั้ง Admin ตั้งแต่ต้น** — ให้สิทธิ์ Admin กับอีกอย่างน้อยหนึ่งคนเพื่อให้กลุ่มดำเนินต่อได้หากคุณไม่ว่าง
- **ใช้ Shared Resources** — อัปโหลดเอกสารอ้างอิงหรือลิงก์ในแท็บ Resources ของกลุ่มเพื่อให้สมาชิกทุกคนเข้าถึงได้ง่าย
