# แกลเลอรี่

## Gallery คืออะไร

Gallery คือฟีดรูปภาพ วิดีโอ และเสียงที่ผู้ใช้ SmartAI Hub สร้างขึ้น ออกแบบมาเพื่อการค้นพบ แรงบันดาลใจ และการนำเสนอผลงานของคุณ การเรียกดูเปิดให้ทุกคนเข้าถึง แต่การเผยแพร่ต้องล็อกอิน

## การเรียกดู Gallery

- มุมมองเริ่มต้นแสดง **เนื้อหาสาธารณะล่าสุด** เรียงจากใหม่สุด
- ใช้ **ตัวกรองประเภท** (รูปภาพ วิดีโอ เสียง) เพื่อจำกัดผลลัพธ์
- ใช้ **แถบค้นหา** เพื่อหาเนื้อหาด้วยคำสำคัญหรือแท็ก
- สลับระหว่างรูปแบบ **Grid**, **Masonry** และ **List** ตามที่เหมาะกับหน้าจอของคุณ
- คลิกรายการใดก็ได้เพื่อเปิดมุมมองรายละเอียดพร้อม Prompt การสร้าง โมเดล และผู้สร้าง

## เนื้อหาแนะนำ

- แท็บ **Featured** แสดงไฮไลต์ที่คัดสรรโดยทีมแพลตฟอร์ม
- รายการที่แนะนำปรากฏที่ด้านบนของฟีดเริ่มต้นและได้รับการมองเห็นมากขึ้น
- รายการสาธารณะใดก็ตามอาจได้รับการแนะนำ — คุณภาพ ความคิดสร้างสรรค์ และความน่าสนใจของ Prompt คือเกณฑ์หลัก

## ฟีเจอร์การมีส่วนร่วม

- **ถูกใจ** — คลิกไอคอนหัวใจเพื่อบันทึกรายการในคอลเลกชันที่ถูกใจ
- **จำนวนการดู** — มองเห็นบนแต่ละการ์ด แสดงจำนวนผู้ใช้ที่เปิดมุมมองรายละเอียด
- **ดาวน์โหลด** — ดาวน์โหลดไฟล์ความละเอียดต้นฉบับโดยตรงจากมุมมองรายละเอียด
- **คัดลอก Prompt** — คัดลอก Prompt การสร้างเพื่อใช้เป็นจุดเริ่มต้นสำหรับการปรับแต่งของคุณเอง

## การเผยแพร่ผลงาน

เพื่อแชร์รายการที่สร้างขึ้นไปยัง Gallery:

1. เปิดรายการใน **Media Studio**, **Media History** หรือ **Document Management**
2. คลิก **Share → Publish to Gallery**
3. เพิ่ม **แท็ก** และ **ชื่อ** ก่อนยืนยัน
4. รายการจะปรากฏใน Gallery สาธารณะภายในไม่กี่วินาที

คุณยังสามารถเผยแพร่โดยตรงจากผลการสร้างในการสนทนาโดยใช้ไอคอนแชร์ในข้อความ

## ความเป็นส่วนตัวและการลบ

- เฉพาะรายการที่คุณเผยแพร่อย่างชัดแจ้งเท่านั้นที่ปรากฏใน Gallery — ไฟล์ส่วนตัวและไฟล์แนบในการสนทนาจะไม่แสดงโดยอัตโนมัติ
- **Prompt** การสร้างจะแสดงต่อสาธารณะควบคู่กับรายการ หลีกเลี่ยงการส่งรายการที่สร้างจาก Prompt ที่มีข้อมูลละเอียดอ่อน
- **ยกเลิกการเผยแพร่** ได้ตลอดเวลาจากมุมมองรายละเอียด Gallery หรือจาก Document Management — รายการจะถูกลบออกจากฟีดสาธารณะทันที
- รายการที่ลบออกจากคลังจะถูกยกเลิกการเผยแพร่จาก Gallery โดยอัตโนมัติ

## เคล็ดลับ

- เพิ่มแท็กที่อธิบายรายละเอียดเมื่อเผยแพร่เพื่อให้ค้นพบได้ง่ายขึ้น
- ใช้ **Copy Prompt** บนรายการ Gallery ที่ชื่นชอบเพื่อศึกษาเทคนิค Prompt ที่มีประสิทธิภาพ
- ฟีด Gallery อัปเดตแบบ Real-time — รายการที่เพิ่งเผยแพร่ปรากฏโดยไม่ต้องโหลดหน้าใหม่
