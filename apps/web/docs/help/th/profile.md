# โปรไฟล์และบัญชี

## ภาพรวม

หน้าโปรไฟล์ช่วยให้คุณจัดการข้อมูลส่วนตัว การตั้งค่าความปลอดภัย การแจ้งเตือน และ API key เข้าถึงได้โดยกดรูปอวาตาร์ในเมนูด้านข้าง หรือไปที่ **Profile**

## ข้อมูลโปรไฟล์

- **ชื่อที่แสดง** — แสดงในข้อความแชทและคอมเมนต์
- **อีเมล** — อีเมลสำหรับเข้าสู่ระบบ (การเปลี่ยนต้องยืนยัน)
- **บริษัท** — ชื่อองค์กร (ไม่บังคับ)
- **อวาตาร์** — อัปโหลดรูปโปรไฟล์ (JPG, PNG, WebP; สูงสุด 2 MB)

กด **Save Changes** หลังแก้ไข

## ความปลอดภัย

### รหัสผ่าน
เปลี่ยนรหัสผ่านโดยกรอกรหัสผ่านปัจจุบันและเลือกรหัสใหม่ รหัสผ่านต้องมีอย่างน้อย 8 ตัวอักษร

### การยืนยันตัวตนสองขั้นตอน (2FA)
1. กด **Enable 2FA** ในแท็บ Security
2. สแกน QR code ด้วยแอป authenticator (Google Authenticator, Authy ฯลฯ)
3. กรอกรหัส 6 หลักเพื่อยืนยัน
4. บันทึก **recovery codes** ไว้ในที่ปลอดภัย — แสดงเพียงครั้งเดียว

ปิด 2FA โดยกรอกรหัสผ่านปัจจุบันและรหัส authenticator ที่ใช้ได้

## การแจ้งเตือน

กำหนดการแจ้งเตือนที่คุณได้รับ:

- **อีเมล** — สรุปอัปเดตสำคัญ
- **ไอคอนกระดิ่ง** — dropdown แจ้งเตือนในแอป
- **Telegram** — push notification แบบเรียลไทม์ (ต้องเชื่อมบัญชี Telegram)

## การตั้งค่า

- **ธีม** — สว่าง, มืด หรือตามระบบ
- **ภาษา** — อังกฤษหรือไทย (มีผลกับป้ายกำกับ UI ไม่ใช่ผลลัพธ์ AI)

## API keys

สร้าง API key ส่วนตัวสำหรับเข้าถึงโปรแกรม:

1. ไปที่แท็บ **API Keys**
2. กด **Generate New Key**
3. คัดลอก key ทันที — แสดงเพียงครั้งเดียว
4. ใช้ key ใน header `Authorization: Bearer <key>`

เพิกถอน key โดยกดไอคอนถังขยะข้าง key

## การลบบัญชี

ด้านล่างแท็บ Account กด **Delete Account** เพื่อลบบัญชีและข้อมูลทั้งหมดอย่างถาวร การดำเนินการนี้ไม่สามารถยกเลิกได้
