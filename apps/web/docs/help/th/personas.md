# บุคลิก AI (Personas)

## Persona คืออะไร

Persona คือบุคลิก AI ที่มีชื่อซึ่งคุณกำหนดค่าครั้งเดียวและนำมาใช้ซ้ำได้ในการสนทนาต่างๆ แต่ละ Persona มี System Prompt โทนเสียง ความรู้เฉพาะด้าน และสไตล์การสื่อสารของตัวเอง เมื่อคุณเปิดใช้งาน Persona ในการสนทนา ทุกการตอบกลับในเซสชันนั้นจะเป็นไปตามพฤติกรรมที่กำหนดของ Persona แทนผู้ช่วยเริ่มต้น

ตัวอย่างการใช้งาน: ผู้ช่วยเขียนธุรกิจแบบทางการ, คู่หูระดมสมองแบบสบายๆ, ผู้เชี่ยวชาญเฉพาะด้าน, หรือตัวละครสำหรับงานเขียนสร้างสรรค์

## การสร้าง Persona

1. ไปที่ **Settings → Personas** แล้วคลิก **New Persona**
2. กรอก **ชื่อ** — ให้สั้นและจดจำง่าย (เช่น "นักวิเคราะห์กฎหมาย", "นักเขียนสร้างสรรค์")
3. เพิ่ม **คำอธิบาย** — บันทึกสั้นๆ เพื่อช่วยให้คุณจำว่า Persona นี้ใช้ทำอะไร
4. ตั้งค่า **Nickname** ได้ตามต้องการ หากต้องการเรียก persona นี้จากหน้า Chat แบบรวดเร็ว เช่น `@น้องเจน` หรือ `@writer`
5. เขียน **System Prompt** — นี่คือคำสั่งหลักที่ส่งให้โมเดล ระบุให้ชัดเจนเกี่ยวกับโทนเสียง ความเชี่ยวชาญ และข้อจำกัด ตัวอย่าง:
   > "คุณคือบรรณาธิการกฎหมายที่กระชับ ตรวจสอบข้อความเพื่อความชัดเจนและระบุข้อความที่คลุมเครือ ใช้ภาษาทางการ ไม่ให้คำแนะนำทางกฎหมาย"
6. ตั้งค่า **Working Hours** ได้ตามต้องการ หาก persona นี้ควรมีตารางเวลาทำงานรายวันสำหรับการทำงานอัตโนมัติในอนาคต
7. อัปโหลด **Avatar** เพื่อระบุ Persona ในแถบเครื่องมือ Chat ได้ตามต้องการ
8. คลิก **Save**

## การใช้ Personas ในการสนทนา

- **Persona Selector** ปรากฏในแถบเครื่องมือ Chat (ไอคอนแสดง Avatar ของ Persona ที่ใช้งานอยู่)
- คลิกเพื่อเปิดตัวเลือก Persona และเลือก Persona ที่บันทึกไว้
- Persona ที่เลือกจะใช้งานเฉพาะในการสนทนาปัจจุบัน
- คุณสามารถเปลี่ยน Persona กลางคัน โดย Persona ใหม่จะมีผลตั้งแต่ข้อความถัดไป

## ตั้งเป็น Persona เริ่มต้น

- ในรายการ Persona สามารถกด **Set as default** เพื่อให้การสนทนาใหม่เริ่มด้วย persona นี้โดยอัตโนมัติ
- หากคุณไม่ได้ตั้งค่า default ของตัวเอง ระบบอาจใช้ default ที่องค์กรกำหนดไว้แทน
- คุณยังเปลี่ยน persona ของแชตปัจจุบันได้ทุกเมื่อจาก Persona Selector โดยไม่ต้องเริ่มห้องใหม่

## Nickname และการเรียก Persona จากหน้า Chat

- หาก persona มี **Nickname** คุณสามารถเรียก persona นั้นจากหน้า Chat ได้เร็วขึ้น
- รองรับทั้งการเรียกแบบ `@nickname` และการพูดถึง nickname ตรงๆ ในข้อความ หากระบบจับคู่ได้ชัดเจน
- เมื่อมีการจับคู่ nickname สำเร็จ ระบบจะสลับ persona ของบทสนทนานั้นให้กับข้อความถัดไป
- ถ้ามี persona หลายตัวที่ชื่อใกล้กัน ให้ใช้ `@nickname` เพื่อให้ชัดที่สุด

ตัวอย่าง:

- `@น้องเจน ช่วยสรุปข่าวเช้านี้ให้หน่อย`
- `writer ช่วยร่างโพสต์เปิดตัวสินค้า`

## Working Hours รายวัน

- เปิด **Use working hours** เมื่อต้องการกำหนดช่วงเวลาทำงานของ persona
- ตั้ง **Timezone** ได้หนึ่งค่า แล้วกำหนดเวลารายวันแยกสำหรับ Monday-Sunday
- วันที่ไม่ระบุเวลา จะถือว่าเป็น **วันหยุด** หรือไม่ได้เปิดทำงาน
- ตัวอย่างเช่น:
  - Monday-Friday `09:00-18:00`
  - Saturday `08:00-12:00`
  - Sunday เว้นว่าง = หยุด
- Working Hours ใช้เป็นข้อมูล availability สำหรับ automation และบริบทการทำงาน ไม่ได้บังคับปิดการแชตด้วยตัวเอง

## เทมเพลต Persona

เทมเพลตที่สร้างไว้ล่วงหน้าช่วยให้คุณเริ่มต้นได้รวดเร็วสำหรับกรณีใช้งานทั่วไป:

- **Professional Writer** — โทนทางการ ผลลัพธ์มีโครงสร้าง บริบทธุรกิจ
- **Creative Collaborator** — มีจินตนาการ สำรวจ ไม่ตีกรอบ
- **Data Analyst** — แม่นยำ เน้นตัวเลข สรุปมีโครงสร้าง
- **Language Tutor** — อธิบายอย่างอดทน แก้ไข ยกตัวอย่าง
- **Code Reviewer** — เน้นเทคนิค วิจารณ์เชิงสร้างสรรค์ แนวปฏิบัติที่ดี

เลือกเทมเพลตเมื่อสร้าง Persona ใหม่ แล้วปรับแต่ง System Prompt ตามความต้องการของคุณ

## การจัดการ Personas

- **แก้ไข** — อัปเดตชื่อ คำอธิบาย System Prompt หรือ Avatar ได้ตลอดเวลา การเปลี่ยนแปลงมีผลกับการสนทนาใหม่
- **เปลี่ยน Nickname / Working Hours** — ปรับวิธีเรียก persona และตารางเวลาทำงานของ persona ได้ภายหลัง
- **ตั้งเป็นค่าเริ่มต้น** — กำหนดว่า persona ใดควรเริ่มต้นในแชตใหม่ของคุณ
- **ทำสำเนา** — คัดลอก Persona ที่มีอยู่เป็นจุดเริ่มต้นสำหรับการปรับแต่ง
- **ลบ** — ลบ Persona อย่างถาวร การสนทนาที่ใช้อยู่จะไม่ได้รับผลกระทบจนกว่าจะเปลี่ยนไป
- **จัดเรียง** — ลาก Persona ในรายการเพื่อกำหนดลำดับที่ปรากฏในตัวเลือก

## เคล็ดลับการสร้าง Personas ที่มีประสิทธิภาพ

- ระบุอย่างชัดเจนใน System Prompt ว่า Persona **ไม่ควร** ทำอะไร — ข้อจำกัดสำคัญพอๆ กับความสามารถ
- ทดสอบ Persona ใหม่ด้วยข้อความตัวอย่างสักสองสามข้อความก่อนนำไปใช้งานจริง
- ควรเขียน System Prompt ไม่เกิน 500 คำ — Prompt ที่ยาวเกินไปเพิ่มการใช้ Token ต่อข้อความ
- ใช้ช่อง Description เพื่อบันทึกว่าสร้าง Persona นี้เมื่อไหร่และทำไม ไม่ใช่แค่บอกว่าทำอะไร
- หากเปิดใช้ Memory ระบบจะโหลด **long-term memory ตาม persona ที่กำลังใช้งานอยู่** ทำให้ persona แต่ละตัวมีบริบทระยะยาวของตัวเองได้
- บทสรุปของบทสนทนาและบริบทใน session เดิมยังคงอยู่ตามห้องแชตเดิม แม้คุณจะสลับ persona กลางทาง
