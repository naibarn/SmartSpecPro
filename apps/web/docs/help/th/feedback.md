# Feedback และรายงานบัก

## ภาพรวม

ระบบ feedback ช่วยให้คุณรายงานบัก ขอฟีเจอร์ใหม่ แชร์ข้อสังเกต หรือถามคำถามได้จากทุกหน้า การส่งของคุณจะถูก AI จัดประเภทอัตโนมัติและส่งต่อให้ทีมแอดมินพร้อมข้อมูลครบถ้วน

## วิธีส่ง feedback

1. **กดปุ่ม Feedback** มุมขวาล่างของทุกหน้า (ปุ่มสีม่วงรูป speech-bubble)
2. **เลือกประเภท**:
   - **Bug Report** — มีอะไรพังหรือทำงานไม่ถูกต้อง
   - **Feature Request** — แนะนำความสามารถใหม่หรือปรับปรุง
   - **Observation** — แชร์สิ่งที่สังเกตเห็น (ทั้งดีและไม่ดี)
   - **Question** — ถามคำถามเกี่ยวกับฟีเจอร์หรือวิธีการใช้งาน
3. **กรอกหัวข้อ** ที่สรุปปัญหาให้สั้นกระชับ
4. **เพิ่มรายละเอียด** ให้มากที่สุด — ขั้นตอนการทำซ้ำ ผลลัพธ์ที่คาดหวัง และสิ่งที่เกิดขึ้นจริง
5. กด **Submit Feedback**

## การแนบไฟล์

คุณสามารถแนบได้สูงสุด **5 ไฟล์** ต่อ ticket ประเภทไฟล์ที่รองรับ:

| ประเภท | นามสกุล | กรณีใช้งาน |
|--------|---------|-----------|
| รูปภาพ | `.jpg`, `.jpeg`, `.png`, `.webp` | ภาพหน้าจอ ภาพแสดง error |
| เอกสาร | `.pdf` | ข้อมูลจำเพาะ เอกสารอ้างอิง |
| Markdown | `.md` | ขั้นตอนการทำซ้ำแบบละเอียด |

**ขนาดจำกัด**: 5 MB ต่อไฟล์

### วิธีแนบไฟล์

- **ลากและวาง** ไฟล์ลงบนพื้นที่แนบไฟล์ใน dialog feedback ได้โดยตรง
- **กดที่พื้นที่แนบไฟล์** เพื่อเปิดตัวเลือกไฟล์
- ไฟล์จะแสดงเป็นรายการด้านล่างแสดงชื่อ ขนาด และปุ่มลบ
- ลบไฟล์ก่อนส่งได้โดยกด **X** ข้างไฟล์นั้น

### หาก upload ล้มเหลว

หาก ticket ถูกสร้างแล้วแต่ upload ไฟล์ล้มเหลว (เช่น ปัญหาเครือข่าย) dialog จะเปิดค้างพร้อมปุ่ม **Retry Upload** คุณสามารถ:
- กด **Retry Upload** เพื่อลองอีกครั้ง
- กด **Skip** เพื่อส่งโดยไม่มีไฟล์แนบ

Ticket ของคุณถูกบันทึกแล้ว — การ retry จะลองอัปโหลดไฟล์ใหม่เท่านั้น

## ติดตาม feedback ของคุณ

### หน้า My Feedback

ไปที่ **My Feedback** (ผ่านลิงก์ด้านล่างของ dialog feedback หรือจากเมนู) เพื่อดู ticket ทั้งหมดที่คุณส่ง

- **รายการ ticket** ด้านซ้ายแสดง badge สถานะ: New, Triaged, In Progress, Resolved, Closed
- **รายละเอียด ticket** ด้านขวาแสดงคำอธิบาย ไฟล์แนบ (พร้อม thumbnail สำหรับรูปภาพ) และการตอบกลับจากทีมซัพพอร์ต
- **Deep link**: แชร์ลิงก์ไปยัง ticket เฉพาะได้ด้วย `?ticketId=123`

### การแจ้งเตือน

คุณจะได้รับการแจ้งเตือนเมื่อ:
- แอดมิน **ตอบกลับ** ticket ของคุณ (เฉพาะ comment ที่ไม่ใช่ internal)
- สถานะ ticket เปลี่ยนเป็น **In Progress**, **Resolved**, หรือ **Closed**

กดการแจ้งเตือนใน bell dropdown เพื่อไปยังหน้าที่เกี่ยวข้องโดยตรง

## สิ่งที่เกิดขึ้นหลังคุณส่ง

1. **Auto-triage** — ระบบจัดประเภท ticket อัตโนมัติตามหมวดหมู่ (bug, performance, feature request, question) และความสำคัญ (high, normal, low)
2. **ตรวจจับซ้ำ** — หากมี ticket ที่คล้ายกันเปิดอยู่แล้ว ticket ของคุณอาจถูกทำเครื่องหมายเป็น duplicate
3. **เชื่อมโยง incident** — หากรายงานของคุณตรงกับ incident ของระบบที่กำลังเกิดขึ้น จะถูกเชื่อมโยงอัตโนมัติ
4. **แจ้งเตือนแอดมิน** — แอดมินทุกคนจะได้รับแจ้งเตือนพร้อมลิงก์ตรงไปยัง ticket ของคุณ

## เคล็ดลับการส่ง feedback ที่มีประสิทธิภาพ

- **แนบภาพหน้าจอ** — รูปภาพอธิบายได้ดีกว่าคำพูด แนบภาพหน้าจอของ error หรือพฤติกรรมที่ไม่คาดคิด
- **ระบุให้ชัดเจน** — "แชทใช้ไม่ได้" ยากที่จะจัดการ เทียบกับ "กด Send ในแชทได้ error 500 เมื่อเลือกโมเดล GPT-4"
- **หนึ่งปัญหาต่อหนึ่ง ticket** — หากมีหลายบัก ให้ส่งแยก ticket เพื่อติดตามแต่ละปัญหาได้อิสระ
- **ตรวจสอบ ticket ที่มีอยู่** — ก่อนส่ง ให้ดูหน้า My Feedback ว่าเคยรายงานปัญหาเดียวกันแล้วหรือไม่
