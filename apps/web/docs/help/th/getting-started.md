# เริ่มต้นใช้งาน SmartAI Hub

SmartAI Hub คือแพลตฟอร์ม AI สำหรับสร้างคอนเทนต์ ทำวิจัย สร้างสื่อ และระบบอัตโนมัติอัจฉริยะ คู่มือนี้จะช่วยให้คุณเข้าใจพื้นที่ทำงานหลักและเริ่มต้นใช้งานได้อย่างรวดเร็ว

## สิ่งที่คุณทำได้

- **แชทกับ AI** — ถามคำถาม ร่างเนื้อหา ระดมสมอง และวิเคราะห์ข้อมูลด้วย LLM ชั้นนำของโลก
- **สร้างสื่อ** — สร้างรูปภาพ วิดีโอ และเสียงจากคำอธิบายข้อความ
- **สร้าง Presentation** — เปลี่ยนคำขอในแชทเป็นสไลด์ได้ในไม่กี่วินาที
- **ใช้งาน Agency** — ส่งทีม AI หลายตัวไปจัดการงานวิจัย สตอรีบอร์ด และงานเปรียบเทียบที่ซับซ้อน
- **ท่องเว็บด้วย AI** — ใช้ Browser Session ให้ AI นำทางเว็บไซต์ รวบรวมข้อมูล และส่งผลลัพธ์แบบมีโครงสร้างกลับมาให้คุณ

## วิธีนำทางในระบบ

| พื้นที่ | วิธีเปิด | ใช้ทำอะไร |
|---|---|---|
| Chat | คลิก **Chat** ในแถบด้านข้าง | บทสนทนา, skills, สร้างสื่อ |
| Media Studio | คลิก **Media** ในแถบด้านข้าง | ดูและจัดการสื่อที่สร้าง |
| Presentations | คลิก **Presentations** ในแถบด้านข้าง | แก้ไขและส่งออกสไลด์ |
| Agency | คลิก **Agencies** ในแถบเครื่องมือใน Chat | เปิด workflow แบบ multi-agent |
| Browser Session | คลิก **Browser Session** ใน Chat | ท่องเว็บด้วย AI |
| Settings | คลิกรูปโปรไฟล์ → Settings | การตั้งค่า, memory, personas |
| Credits | คลิก **Credits** ในแถบด้านข้าง | ตรวจสอบยอดคงเหลือและเติมเครดิต |

## ขั้นตอนแนะนำสำหรับผู้เริ่มต้น

1. เปิด **Chat** แล้วพิมพ์คำถามหรือรายละเอียดงานที่ต้องการ
2. ลองพิมพ์ `/` เพื่อเปิดเมนู skill และสำรวจ workflow ที่มีอยู่
3. ขอภาพโดยพิมพ์ `create image: เมืองในอนาคตยามพระอาทิตย์ตก`
4. คลิก **Agencies** เพื่อสำรวจเทมเพลตอย่าง Deep Research หรือ Deck Builder
5. ไปที่ **Settings → Memory** เพื่อดูว่า AI จดจำความชอบของคุณอย่างไร

## แดชบอร์ด

หลังเข้าสู่ระบบ แดชบอร์ดจะแสดง:

- **ยอดเครดิต** — เครดิตคงเหลือของคุณ
- **บทสนทนาล่าสุด** — กลับไปทำงานต่อได้ทันที
- **Quick actions** — ทางลัดไปยัง Chat, Media Studio, และ Presentations
- **ภาพรวมการใช้งาน** — สรุปกิจกรรมของคุณ

## ขอความช่วยเหลือ

- คลิกปุ่ม **?** (Help) บนหน้าใดก็ได้เพื่อเปิด help ที่เกี่ยวข้อง
- เข้าศูนย์ช่วยเหลือที่ `/help` สำหรับทุกหัวข้อ
- ถามคำถามใน Chat — พิมพ์ "วิธีใช้..." แล้ว help assistant จะตอบจากเอกสาร

## เคล็ดลับด่วน

- เริ่มต้นที่ **Chat** สำหรับงานส่วนใหญ่ — เป็นจุดเริ่มต้นที่เร็วที่สุด
- ย้ายไปใช้ **Browser Session** เมื่อต้องการข้อมูลจากเว็บไซต์จริง
- ย้ายไปใช้ **Agencies** เมื่องานต้องการผลลัพธ์แบบมีโครงสร้าง เช่น รายงาน สไลด์ หรือสตอรีบอร์ด
- ใช้ **เครดิต** เพื่อติดตามและจัดการการใช้งาน AI ของคุณ
- เปลี่ยนภาษา (EN/TH) จาก Settings หรือปุ่มเปลี่ยนภาษาในแผง Help
