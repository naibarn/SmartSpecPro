# ระบบอัตโนมัติ

## ระบบอัตโนมัติคืออะไร?

ระบบอัตโนมัติให้คุณกำหนดงานที่มีโครงสร้างและทำซ้ำได้ที่ AI ดำเนินการทีละขั้นตอนในสภาพแวดล้อมเบราว์เซอร์จริง ต่างจาก Browser Session แบบครั้งเดียวที่คุณนำทางอย่างอิสระ ระบบอัตโนมัติถูกออกแบบสำหรับงานที่คุณต้องการรันอย่างสม่ำเสมอ — กระบวนการเดิม ผลลัพธ์เดิม ทุกครั้ง

คิดว่าเป็น copilot RPA (robotic process automation) ส่วนตัวที่คุณอธิบายด้วยภาษาธรรมดาแทนที่จะเป็น code

## ระบบอัตโนมัติ vs. Browser Session

| ฟีเจอร์ | Browser Session | ระบบอัตโนมัติ |
|---|---|---|
| เหมาะสำหรับ | การวิจัยและสำรวจแบบเปิด | กระบวนการที่มีโครงสร้างและทำซ้ำได้ |
| วิธีเริ่ม | อธิบายเป้าหมาย AI นำทางอย่างอิสระ | อธิบายผลลัพธ์ AI วางแผนขั้นตอนก่อน |
| ความสามารถทำซ้ำ | เฉพาะกิจ | ออกแบบให้รันหลายครั้ง |
| การควบคุมด้วยตนเอง | มี | มี — พร้อม pause points |

## Automation Copilot

Automation Copilot ช่วยคุณในทุกขั้นตอนของการสร้างและรันระบบอัตโนมัติ:

- **การวางแผน** — อธิบายผลลัพธ์ที่ต้องการด้วยภาษาธรรมดา (เช่น "กรอก timesheet รายสัปดาห์บนพอร์ทัล HR ของเรา") Copilot แบ่งเป็นขั้นตอนแยกก่อนดำเนินการใดๆ
- **ตรวจสอบ** — คุณสามารถตรวจสอบและแก้ไขขั้นตอนที่วางแผนไว้ก่อนระบบอัตโนมัติจะเริ่ม
- **การดำเนินการ** — Copilot ดำเนินการแต่ละขั้นตอนตามลำดับ หยุดชั่วคราวเมื่อต้องการ input หรือการยืนยันจากมนุษย์
- **การปรับตัว** — หาก layout หน้าเปลี่ยนแปลงหรือมี dialog ที่ไม่คาดคิดปรากฏขึ้น Copilot พยายามปรับตัวและแจ้งให้คุณทราบหากไม่สามารถดำเนินการต่อได้

## เริ่มต้นระบบอัตโนมัติ

1. ไปที่ **/automation**
2. อธิบายผลลัพธ์ที่ต้องการบรรลุ ระบุให้ชัดเจน: รวม URL เว็บไซต์ ข้อมูลที่จะกรอก และสถานะสุดท้ายควรเป็นอย่างไร
3. Copilot สร้างแผนทีละขั้นตอน ตรวจสอบแล้วคลิก **Start** เมื่อพร้อม
4. ระบบอัตโนมัติเปิดใน live browser session และเริ่มดำเนินการ

## Live Session (/automation/live/:sessionId)

เมื่อระบบอัตโนมัติกำลังทำงาน คุณสามารถดูและโต้ตอบได้แบบ real-time:

- **Live view** — เห็นเบราว์เซอร์เหมือนกับที่ระบบอัตโนมัติเห็น
- **ความคืบหน้าขั้นตอน** — แถบด้านข้างแสดงขั้นตอนที่กำลังดำเนินการอยู่และขั้นตอนที่เสร็จแล้ว
- **Pause** — หยุดการดำเนินการชั่วคราว ระบบอัตโนมัติรอให้คุณ resume
- **Resume** — ดำเนินการต่อจากที่หยุดไว้
- **Cancel** — หยุดระบบอัตโนมัติทั้งหมดและปิด browser session

## การเข้าควบคุม — การควบคุมด้วยตนเอง

บางขั้นตอนต้องการ input จากมนุษย์ที่ AI ไม่สามารถดำเนินการได้อย่างปลอดภัยด้วยตนเอง — รหัส multi-factor authentication, การยืนยันการชำระเงิน และ CAPTCHA เป็นตัวอย่างที่พบบ่อย

เมื่อ Copilot ถึงขั้นตอนที่ไม่สามารถดำเนินการได้อัตโนมัติ:

1. จะหยุดชั่วคราวและส่งการแจ้งเตือนให้คุณ
2. Live view จะ highlight องค์ประกอบที่ต้องการ input ของคุณ
3. คุณควบคุมเบราว์เซอร์โดยตรง ทำขั้นตอนให้เสร็จ แล้วคลิก **Resume** เพื่อส่งคืนการควบคุม

## Pause Points

คุณสามารถกำหนด pause points ที่ชัดเจนในแผนขั้นตอนก่อนระบบอัตโนมัติจะเริ่ม Pause point บอก Copilot ให้หยุดและรอการอนุมัติของคุณก่อนดำเนินการขั้นตอนถัดไป มีประโยชน์สำหรับ:

- ตรวจสอบข้อมูลก่อนส่ง
- ยืนยันการซื้อหรือการชำระเงิน
- ตรวจสอบผลลัพธ์ของการกรอกฟอร์มที่ซับซ้อนก่อนดำเนินการต่อ

## การบังคับใช้นโยบาย

ระบบอัตโนมัติทำงานในสภาพแวดล้อมเบราว์เซอร์แบบ sandbox พร้อมนโยบายความปลอดภัยที่กำหนดได้:

- **Allowed domains** — จำกัดระบบอัตโนมัติให้อยู่บนเว็บไซต์เฉพาะ
- **Blocked actions** — ป้องกันหมวดหมู่การดำเนินการบางประเภท (เช่น การซื้อ การส่งอีเมล)
- **Maximum steps** — กำหนดขีดสูงสุดจำนวนขั้นตอนที่ระบบอัตโนมัติสามารถดำเนินการได้ใน run เดียว

นโยบายเหล่านี้กำหนดโดย domain admin จาก **Admin → Settings**

## Use Cases

- กรอกฟอร์มที่เกิดขึ้นซ้ำ (timesheets, ใบเบิกค่าใช้จ่าย, รายการ CRM)
- ดึงข้อมูลจากหน้าเว็บเป็นรูปแบบที่มีโครงสร้าง
- ตรวจสอบหน้าเว็บว่ามีการเปลี่ยนแปลงและเรียกการแจ้งเตือน
- ทำงานจัดการบัญชีโดยอัตโนมัติในหลายไซต์
- ทดสอบ end-to-end สำหรับเว็บแอปพลิเคชัน

## เคล็ดลับ

- **ระบุผลลัพธ์ให้ชัดเจน** — "log in to X and download the monthly report as PDF" ให้ข้อมูล Copilot มากกว่า "get the report"
- **ตั้ง pause points สำหรับขั้นตอนที่ละเอียดอ่อน** — ขั้นตอนใดก็ตามที่เกี่ยวข้องกับเงิน การส่งฟอร์ม หรือการดำเนินการที่ย้อนกลับไม่ได้ควรมี pause สำหรับตรวจสอบด้วยตนเอง
- **ทดสอบด้วย run เดียวก่อน** — ก่อนกำหนดเวลาให้ระบบอัตโนมัติทำงานซ้ำ ให้ดู run เต็มใน live view เพื่อตรวจจับพฤติกรรมที่ไม่คาดคิด
- **ใช้ allowed domains** เพื่อป้องกันระบบอัตโนมัตินำทางไปยังไซต์ที่ไม่ต้องการ
