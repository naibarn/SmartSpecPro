# Agencies — ทีม AI หลายตัว

## Agencies คืออะไร

Agencies คือทีม AI หลายตัวที่ทำงานร่วมกันเพื่อทำงานที่ซับซ้อนและมีโครงสร้าง แต่ละ agency มี agent เฉพาะทาง (นักวิจัย นักเขียน นักวางแผน และอื่นๆ) ที่ทำงานร่วมกันโดยอัตโนมัติ ผลิต deliverable ที่ต้องใช้ความพยายามอย่างมากหากทำด้วยตนเอง

- Agencies เหมาะที่สุดสำหรับงานที่ต้องการ **ผลลัพธ์แบบมีโครงสร้าง** — รายงาน สตอรีบอร์ด deck ตารางเปรียบเทียบ
- ทำงานอัตโนมัติหลังจากคุณให้คำขอเริ่มต้น
- ผลลัพธ์จะแสดงใน **Preview Card** เพื่อตรวจสอบก่อนยืนยัน

## วิธีเริ่มต้น

1. คลิก **Agencies** ในแถบเครื่องมือ Chat (หรือ **Explore Agencies** บนหน้าต้อนรับ)
2. เรียกดูเทมเพลต agency ที่มีหรือสร้างเทมเพลตใหม่
3. รัน agency ด้วยวิธีใดวิธีหนึ่ง:
   - **เปิด agency** แล้วพิมพ์คำขอในหน้า Agency Chat เต็มจอ
   - **จากหน้า AI Chat**: คลิก **Run Agency** ใน header เลือก agency พิมพ์ข้อความ กด Enter — agency รัน inline โดยไม่ต้องออกจากหน้า chat
   - **จากหน้า AI Chat**: พิมพ์ `/run-agency` ในช่อง input แล้วเลือกจากรายการ
4. Agent ทำงานร่วมกันโดยอัตโนมัติ เมื่อเสร็จ **Preview Card** จะปรากฏ
5. ตรวจสอบ preview และคลิก **Save** เพื่อบันทึกไปยัง Library หรือ Presentation Editor

## เทมเพลต Agency ที่มีให้ใช้

### Deep Research
- **ผลลัพธ์**: Research Report
- **คำอธิบาย**: วิจัยจากหลายแหล่งพร้อม executive summary ผลการค้นพบสำคัญ ส่วนต่างๆ และคำแนะนำ
- **ตัวอย่าง**: "Research AI marketing trends in Southeast Asia 2026"

### Storyboard Planner
- **ผลลัพธ์**: Video Storyboard
- **คำอธิบาย**: แผนวิดีโอแบบ scene-by-scene พร้อมบทพูด มุมกล้อง แสง และ prompt สำหรับเสียงและวิดีโอ
- **ตัวอย่าง**: "สร้าง storyboard เปิดตัวสินค้าความยาว 60 วินาทีสำหรับแอปฟิตเนส"

### Deck Builder
- **ผลลัพธ์**: Presentation Deck
- **คำอธิบาย**: สไลด์ทั้งชุดพร้อมหัวข้อ bullet points speaker notes และคำแนะนำกราฟิก บันทึกตรงไปยัง Presentation Editor
- **ตัวอย่าง**: "Build a Q4 earnings presentation with 8 slides"

### Comparison Agent
- **ผลลัพธ์**: Comparison Table
- **คำอธิบาย**: เปรียบเทียบตัวเลือกแบบ side-by-side พร้อมราคา ความพร้อมใช้งาน ลิงก์หลักฐาน และคำแนะนำ
- **ตัวอย่าง**: "เปรียบเทียบโรงแรม 5 แห่งในเชียงใหม่ราคาต่ำกว่า 3,000 บาทต่อคืน"

## สถานะ Preview Card

| สถานะ | ความหมาย |
|---|---|
| **Preview Ready** | Agent เสร็จแล้ว ตรวจสอบ preview และตัดสินใจว่าจะบันทึกหรือไม่ |
| **Saving...** | กำลังบันทึก |
| **Committed** | บันทึกสำเร็จ สำหรับ deck จะถูกนำไปยัง Presentation Editor สำหรับประเภทอื่น ลิงก์ "View in Library" จะปรากฏใน toast |
| **Save Failed** | มีข้อผิดพลาด ปุ่ม Retry Save จะปรากฏเพื่อให้ลองอีกครั้ง |
| **Expired** | Preview หมดอายุก่อนที่คุณจะบันทึก รัน agency อีกครั้งเพื่อรับ preview ใหม่ |

## การบันทึกตามประเภท Output

| ประเภท Preview | ปุ่ม | ปลายทาง |
|---|---|---|
| Research / Storyboard / Comparison | Save to Library | Library (toast แสดงลิงก์ "View in Library") |
| Presentation Deck | Save as Presentation | นำไปยัง Presentation Editor โดยอัตโนมัติ |

## การดำเนินการอื่นๆ

- คลิกปุ่ม **X** บน Preview Card เพื่อปิดโดยไม่บันทึก
- หาก preview โหลดไม่ได้ จะมี toast ข้อผิดพลาดสีแดงปรากฏ ส่งข้อความเดิมอีกครั้งเพื่อลองใหม่
- หากการบันทึกล้มเหลว ปุ่มจะเปลี่ยนเป็น **Retry Save** คลิกเพื่อลองอีกครั้ง

## Agency Templates

เรียกดูเทมเพลต agency สำเร็จรูปได้ที่ **Agencies → Templates**:

- **Deep Research** — วิจัยจากหลายแหล่งพร้อม executive summary ผลการค้นพบสำคัญ ส่วนต่างๆ และคำแนะนำ เหมาะสำหรับการวิเคราะห์คู่แข่ง การวิจัยตลาด และ technical due diligence
- **Storyboard Planner** — วางแผนวิดีโอแบบ scene-by-scene พร้อมบทพูด มุมกล้อง แสง และ prompt สำหรับเสียงและวิดีโอ เหมาะสำหรับการผลิตวิดีโอและ pitch deck
- **Deck Builder** — สร้างสไลด์ทั้งชุดพร้อมหัวข้อ bullet points speaker notes และคำแนะนำกราฟิก บันทึกตรงไปยัง Presentation Editor
- **Comparison Agent** — เปรียบเทียบตัวเลือกแบบ side-by-side พร้อมราคา ความพร้อมใช้งาน ลิงก์หลักฐาน และคำแนะนำ เหมาะสำหรับการประเมิน vendor การเลือกผลิตภัณฑ์ และการเปรียบเทียบฟีเจอร์

คลิกเทมเพลตใดก็ได้เพื่อดูตัวอย่างการกำหนดค่า agent แล้วคลิก **Use Template** เพื่อสร้าง agency ใหม่ที่กำหนดค่าล่วงหน้าด้วย agent และ workflow ที่เหมาะสม ตั้งชื่อ agency ของคุณและปรับคำแนะนำ agent ใดก็ได้ก่อน run ครั้งแรก

## Agency Marketplace

เยี่ยมชม **Agencies → Marketplace** เพื่อค้นหา agencies ที่ชุมชนสร้างขึ้น:

- เรียกดูตามหมวดหมู่: วิจัย, สร้างเนื้อหา, วิเคราะห์ข้อมูล, ผลิตวิดีโอ และประสิทธิภาพการทำงาน
- แต่ละรายการแสดง agent ที่เกี่ยวข้อง ประเภทผลลัพธ์ทั่วไป เวลาทำงานเฉลี่ย และคะแนนผู้ใช้
- ดูตัวอย่างการกำหนดค่า agent ก่อนติดตั้ง — การเข้าใจโครงสร้างช่วยให้คุณเขียน prompt ได้ดีขึ้น
- **Install Agency** ด้วยคลิกเดียวเพิ่มไปยังรายการ Agencies ของคุณทันที

สำหรับการสร้าง agencies แบบกำหนดเองทั้งหมดตั้งแต่ต้น ดูคู่มือ [Agency Builder](/help/agency-builder)

## AI Agency Creator

**AI Agency Creator** ให้คุณอธิบายสิ่งที่ต้องการเป็นภาษาธรรมดา แล้ว AI จะออกแบบและสร้าง agency ทั้งหมดให้โดยอัตโนมัติ

### วิธีใช้งาน

1. เปิด **Agency Builder** แล้วคลิกปุ่ม **AI Agency Creator** (ไอคอนประกายไฟ)
2. อธิบายสิ่งที่คุณต้องการให้ agency ทำ ยิ่งเจาะจงยิ่งดี — ระบุ agent ที่ต้องการ หน้าที่ของแต่ละตัว และผลลัพธ์ที่คาดหวัง
3. แนบ **ไฟล์ spec** ได้ (PDF, DOCX, TXT หรือ MD สูงสุด 7.5 MB) พร้อมรายละเอียดเพิ่มเติม (ไม่บังคับ)
4. คลิก **Create Agency** — AI จะประมวลผลคำขอผ่านหลายขั้นตอน

### ขั้นตอนการสร้าง

AI Creator ทำงานผ่านขั้นตอนหลายเฟส:

| เฟส | สิ่งที่เกิดขึ้น |
|-----|---------------|
| **Discover** | วิเคราะห์ความต้องการ กำหนดความซับซ้อน และแนะนำความสามารถที่จำเป็น |
| **Plan** | สร้างแผนสถาปัตยกรรมโดยอ้างอิงจากการออกแบบ agency ในอดีตและบทเรียนที่ได้ |
| **Review Plan** | ตรวจสอบแผนด้วยตนเองเพื่อความสมบูรณ์ แก้ไขปัญหาอัตโนมัติ |
| **Design** | สร้าง specification ของ agency ทั้งหมดพร้อม agent เครื่องมือ และ workflow |
| **Review Design** | ตรวจสอบการออกแบบด้วยตนเองเพื่อความพร้อมใช้งานจริง |
| **Validate** | ตรวจสอบความถูกต้องของโครงสร้าง (การเชื่อมต่อ จุดเข้า ประเภท edge) |
| **Implement** | สร้าง agency ในฐานข้อมูลพร้อม agent และ flow ทั้งหมด |
| **Suggest** | สร้างคำแนะนำการปรับปรุง (ไม่บังคับ) |
| **Document** | เขียนคู่มือการใช้งานสั้นๆ สำหรับ agency ใหม่ |

### คำแนะนำการปรับปรุง

หลังสร้างเสร็จ คุณอาจเห็น **Recommended Improvements** — คำแนะนำจาก AI เกี่ยวกับวิธีทำให้ agency ดีขึ้น แต่ละคำแนะนำมี:

- **Impact** (high / medium / low) — การเปลี่ยนแปลงจะปรับปรุง agency มากแค่ไหน
- **Category** — ประเภทของการเปลี่ยนแปลง (เพิ่มความสามารถ อัปเกรดโหมด เพิ่มเครื่องมือ ฯลฯ)
- **Description** — การปรับปรุงจะทำอะไร

ตรวจสอบคำแนะนำเหล่านี้และนำไปปรับใช้ด้วยตนเองใน Agency Builder ตามต้องการ

### บันทึกเป็นเทมเพลต

หลังสร้าง agency คุณสามารถบันทึกเป็น **เทมเพลตที่ใช้ซ้ำได้**:

1. คลิก **Save as Template** ที่ด้านล่างของแผงเสร็จสมบูรณ์
2. ใส่ชื่อและคำอธิบาย (ไม่บังคับ)
3. คลิก **Save** — เทมเพลตจะปรากฏในไลบรารีเทมเพลตของคุณ

เทมเพลตเก็บ agent definitions, node configurations, model requirements และ communication flows — แต่ลบ unique ID ออกเพื่อให้แต่ละ instance ใหม่ได้ ID ใหม่

### เคล็ดลับเพื่อผลลัพธ์ที่ดีขึ้น

- **เจาะจง**: "สร้างทีมวิจัยที่มี web researcher, data analyst และ report writer" ได้ผลดีกว่า "สร้างอะไรสักอย่างสำหรับวิจัย"
- **ระบุความสามารถ**: ถ้าต้องการ web search, vision หรือ code execution ให้ระบุอย่างชัดเจน
- **อธิบายผลลัพธ์**: "agent สุดท้ายควรสร้างรายงาน markdown แบบมีโครงสร้างพร้อมส่วนต่างๆ" ช่วยให้ AI ออกแบบ workflow ที่เหมาะสม
- **แนบ spec**: สำหรับความต้องการที่ซับซ้อน แนบเอกสารพร้อมรายละเอียด
