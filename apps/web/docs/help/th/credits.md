# ระบบเครดิต

เครดิตคือสกุลเงินที่ใช้จ่ายสำหรับคำขอ AI บน SmartAI Hub ทุกครั้งที่ส่งข้อความ สร้างสื่อ หรือรัน agency ระบบจะหักเครดิตตามต้นทุนของการเรียกใช้โมเดล AI

## วิธีการทำงานของเครดิต

- คำขอ LLM แต่ละครั้งจะใช้เครดิตตามสัดส่วนของจำนวน token ที่ประมวลผล (input + output)
- การสร้างสื่อ (รูปภาพ วิดีโอ เสียง) ใช้เครดิตเป็นจำนวนคงที่ต่อการสร้างหนึ่งครั้ง ขึ้นอยู่กับ provider และการตั้งค่าคุณภาพ
- Agency ใช้เครดิตสำหรับแต่ละขั้นตอนของ agent ใน workflow
- ระบบจะแสดงต้นทุนเครดิตก่อนการดำเนินการที่มีค่าใช้จ่ายสูงเมื่อเป็นไปได้

## ตรวจสอบยอดคงเหลือ

ยอดเครดิตปัจจุบันแสดงอยู่ในแถบด้านบน คลิก **Credits** ในแถบด้านข้างเพื่อดูรายละเอียด:

- ยอดคงเหลือปัจจุบัน
- รายการธุรกรรมล่าสุดพร้อมเวลาและจำนวน
- รายละเอียดต้นทุนต่อคำขอแยกตามโมเดล

## การเติมเครดิต

คลิกปุ่ม **Top Up** บนหน้า Credits เพื่อซื้อเครดิตเพิ่มเติม เครดิตไม่มีวันหมดอายุและผูกกับบัญชีของคุณ

## ราคาโมเดล

โมเดล AI แต่ละตัวใช้เครดิตไม่เท่ากัน:

- **โมเดลประหยัด** (เช่น Gemini Flash, GPT-4o-mini) — ต้นทุนต่ำ เหมาะกับงานง่าย
- **โมเดลมาตรฐาน** (เช่น GPT-4o, Claude Sonnet) — สมดุลระหว่างต้นทุนและความสามารถ
- **โมเดลพรีเมียม** (เช่น GPT-o1, Claude Opus) — ต้นทุนสูง เหมาะกับงานให้เหตุผลซับซ้อน
- **สร้างสื่อ** — ต้นทุนคงที่ต่อครั้ง แตกต่างตามผู้ให้บริการและคุณภาพ

ค่าใช้จ่ายจริงต่อคำขอจะแสดงใน badge ต้นทุนข้อความหลังจากแต่ละการตอบกลับ

## วิเคราะห์การใช้งาน

ไปที่ **Usage** ในแถบด้านข้างเพื่อดู:

- ปริมาณการใช้เครดิตรายวัน/สัปดาห์/เดือน
- แยกตามโมเดลและประเภทฟีเจอร์
- ตัวขับเคลื่อนต้นทุนหลัก
- การแจ้งเตือนงบประมาณ (หากตั้งค่าไว้)

## Rate Limiting

การรัน skill (รวมถึงการสร้างสื่อ) มี rate limit ที่ **15 ครั้งต่อนาที** ต่อผู้ใช้ ใช้เท่ากันทั้ง Chat, Team Room และ Agency หากถึงขีดจำกัด ระบบจะแจ้งข้อผิดพลาด — รอสักครู่แล้วลองใหม่

## เคล็ดลับประหยัดเครดิต

- ใช้โมเดลขนาดเล็กสำหรับงานง่าย เช่น การสรุปและจัดหมวดหมู่
- สงวนโมเดลที่มีความสามารถสูงไว้สำหรับการให้เหตุผลซับซ้อน การเขียนโค้ด หรืองานสร้างสรรค์
- **การรันทีม AI** ใช้เครดิตจาก agent ทุกตัวที่เข้าร่วม — ตั้งงบประมาณสูงสุดใน stop policy เพื่อควบคุมค่าใช้จ่าย
- ใช้ skills เพื่อจัดโครงสร้าง prompt อย่างมีประสิทธิภาพแทนการพิมพ์คำสั่งยาวซ้ำๆ ด้วยมือ
- ตรวจสอบ tooltip ของตัวเลือกโมเดลเพื่อเปรียบเทียบค่าใช้จ่ายก่อนเปลี่ยนโมเดล
- ระบบ Unified Execution ใช้ **idempotency key** ในการติดตามเครดิต — แม้คำขอถูก retry ก็จะไม่ถูกเรียกเก็บซ้ำ
