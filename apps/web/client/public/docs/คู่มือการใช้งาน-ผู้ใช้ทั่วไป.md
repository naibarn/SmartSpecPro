# คู่มือการใช้งาน Agentic AI Workflow สำหรับผู้ใช้ทั่วไป

**เวอร์ชัน**: 1.0.0
**อัปเดตล่าสุด**: 8 กุมภาพันธ์ 2026

---

## ระบบนี้คืออะไร?

**Agentic AI Workflow** เป็นระบบที่ช่วยให้คุณสร้างและรันเวิร์กโฟลว์อัตโนมัติด้วย AI โดยไม่ต้องเขียนโค้ด

### ทำอะไรได้บ้าง?

✅ **สร้างเวิร์กโฟลว์แบบลากวาง** - ใช้ตัวแก้ไขแบบกราฟิก ไม่ต้องเขียนโค้ด
✅ **ใช้ AI หลายขั้นตอน** - เชื่อมต่อ LLM, สร้างรูปภาพ, ส่ง email ในเวิร์กโฟลว์เดียว
✅ **ตั้งจุดอนุมัติ** - ให้คนตรวจสอบก่อนดำเนินการขั้นตอนสำคัญ
✅ **ควบคุมงบประมาณ** - จำกัดการใช้เครดิตต่องาน ป้องกันใช้เกิน
✅ **ติดตามสถานะแบบ Real-time** - ดูความคืบหน้าของงานที่กำลังทำงานอยู่

---

## ส่วนประกอบหลักของระบบ

### 1. Visual Flow Editor (ตัวแก้ไขเวิร์กโฟลว์)
- **ลากวางโหนด** เพื่อสร้างขั้นตอนต่างๆ
- **เชื่อมโหนด** ด้วยเส้นเพื่อกำหนดลำดับการทำงาน
- **ตั้งค่าแต่ละโหนด** ตามที่ต้องการ

### 2. Dashboard (แดชบอร์ด)
- **ดูงานที่กำลังทำ** - Active Workflows
- **จัดการคำขออนุมัติ** - Pending Approvals
- **ดูประวัติการทำงาน** - Completed Jobs

### 3. Approval System (ระบบอนุมัติ)
- **ตรวจสอบก่อนดำเนินการ** - สำหรับงานที่มีความเสี่ยง
- **แสดงรายละเอียดงาน** - ให้ข้อมูลครบถ้วนก่อนตัดสินใจ
- **บันทึกเหตุผล** - เก็บประวัติการอนุมัติ/ปฏิเสธ

## วิธีใช้งานแบบ Step-by-Step

### 📋 ขั้นตอนที่ 1: สร้างเวิร์กโฟลว์

1. **เข้าสู่หน้า Visual Flow Editor**
   - คลิกเมนู "Workflows" > "Create New Workflow"

2. **เพิ่มโหนดเข้าสู่ Canvas**
   - ลากโหนดจากแถบด้านข้าง มาวางใน Canvas
   - โหนดที่ใช้บ่อย:
     - 🤖 **LLM Call** - เรียกใช้ AI เพื่อสร้างข้อความ
     - 🖼️ **Generate Image** - สร้างรูปภาพด้วย AI
     - 📧 **Send Email** - ส่งอีเมล
     - ✅ **Approval Gate** - รอการอนุมัติจากคน
     - 🔁 **Loop** - ทำซ้ำหลายรอบ
     - ⚡ **Conditional** - แยกทางตามเงื่อนไข

3. **เชื่อมโหนด**
   - คลิกจุดขอบของโหนดแรก แล้วลากไปยังโหนดถัดไป
   - สร้างเส้นเชื่อม เพื่อกำหนดลำดับการทำงาน

4. **ตั้งค่าแต่ละโหนด**
   - คลิกที่โหนดเพื่อเปิดแผง Settings
   - กรอกข้อมูลที่จำเป็น เช่น:
     - **LLM Call**: Model (GPT-4, Claude), Prompt, Temperature
     - **Generate Image**: Style, Size, Quality
     - **Approval Gate**: ชื่องาน, คำอธิบาย, ระดับความเสี่ยง

5. **ตั้งชื่อและบันทึก**
   - กรอกชื่อเวิร์กโฟลว์ (เช่น "สร้างบทความพร้อมรูปภาพ")
   - กรอกคำอธิบาย
   - คลิก "Save Workflow"

---

### ▶️ ขั้นตอนที่ 2: รันเวิร์กโฟลว์

1. **เลือกเวิร์กโฟลว์**
   - ไปที่หน้า "Workflows"
   - เลือกเวิร์กโฟลว์ที่ต้องการรัน

2. **กรอกข้อมูลเริ่มต้น (Inputs)**
   - ระบบจะแสดงฟอร์มสำหรับกรอกข้อมูล
   - กรอกข้อมูลที่เวิร์กโฟลว์ต้องการ เช่น:
     - หัวข้อบทความ
     - คีย์เวิร์ด
     - กลุ่มเป้าหมาย

3. **ตั้งค่างบประมาณ (Budget)**
   - กำหนดเครดิตสูงสุดที่ใช้ได้
   - ระบบจะหยุดอัตโนมัติ ถ้าใช้เกินที่กำหนด
   - ตัวอย่าง: "ใช้ได้สูงสุด 500 เครดิต"

4. **คลิก "Start Workflow"**
   - ระบบจะเริ่มทำงานทันที
   - คุณจะเห็นการ์ดแสดงสถานะ (JobCard)

---

### 👀 ขั้นตอนที่ 3: ติดตามสถานะ

**ดูสถานะจาก Dashboard**

เข้าหน้า Dashboard คุณจะเห็น:

1. **Active Workflows** (งานที่กำลังทำ)
   ```
   ┌─────────────────────────────────────────┐
   │ 📋 สร้างบทความพร้อมรูปภาพ               │
   ├─────────────────────────────────────────┤
   │ สถานะ: 🔄 กำลังทำงาน                    │
   │ ความคืบหน้า: ขั้นตอน 2/5               │
   │ เครดิตที่ใช้: 120 / 500                │
   │ เวลา: 2 นาที 30 วินาที                 │
   └─────────────────────────────────────────┘
   ```

2. **Pending Approvals** (งานที่รอการอนุมัติ)
   ```
   ┌─────────────────────────────────────────┐
   │ ✅ อนุมัติการส่งอีเมล                   │
   ├─────────────────────────────────────────┤
   │ ระดับความเสี่ยง: 🟡 ปานกลาง            │
   │ รายละเอียด:                             │
   │ ส่งอีเมลไปยัง 100 คน                    │
   │ หัวเรื่อง: "ข่าวสารประจำเดือน"         │
   │                                         │
   │ [อนุมัติ] [ปฏิเสธ]                      │
   └─────────────────────────────────────────┘
   ```

**สถานะต่างๆ ที่จะเห็น:**
- 🟡 **Pending** - กำลังรอเริ่มงาน
- 🔄 **Running** - กำลังทำงานอยู่
- ⏸️ **Waiting Approval** - รอการอนุมัติ
- ✅ **Completed** - เสร็จสมบูรณ์
- ❌ **Failed** - ล้มเหลว
- ⚠️ **Budget Exceeded** - ใช้เครดิตเกินที่กำหนด

---

### ✅ ขั้นตอนที่ 4: อนุมัติงาน

**เมื่อเวิร์กโฟลว์มาถึงจุด Approval Gate:**

1. **ได้รับการแจ้งเตือน**
   - เห็นแจ้งเตือนใน Dashboard
   - บางระบบส่งอีเมลหรือ Telegram แจ้ง

2. **ตรวจสอบรายละเอียด**
   - อ่านชื่อและคำอธิบายงาน
   - ดูข้อมูลที่งานจะดำเนินการ
   - ตรวจสอบระดับความเสี่ยง:
     - 🟢 **ต่ำ** - งานปกติทั่วไป
     - 🟡 **ปานกลาง** - ควรตรวจสอบ
     - 🟠 **สูง** - ต้องระวัง
     - 🔴 **วิกฤต** - ต้องพิจารณาอย่างละเอียด

3. **ตัดสินใจ**
   - **อนุมัติ**: คลิก "อนุมัติ" เวิร์กโฟลว์จะทำงานต่อ
   - **ปฏิเสธ**: คลิก "ปฏิเสธ" เวิร์กโฟลว์จะหยุดทันที

4. **เพิ่มความคิดเห็น (ไม่บังคับ)**
   - พิมพ์เหตุผลในช่อง Comment
   - เช่น "อนุมัติ - ตรวจสอบเนื้อหาแล้วเรียบร้อย"
   - เก็บไว้เป็นประวัติ

## ตัวอย่างการใช้งานจริง

### ตัวอย่างที่ 1: สร้างโพสต์โซเชียลพร้อมรูปภาพ

**เวิร์กโฟลว์:**
```
เริ่มต้น
  ↓
LLM: เขียนข้อความโพสต์
  ↓
LLM: คิดคำสั่งสร้างรูป (prompt)
  ↓
Generate Image: สร้างรูปตาม prompt
  ↓
Approval Gate: ตรวจสอบโพสต์และรูป
  ↓
Send Telegram: ส่งไปยังช่องทางโซเชียล
  ↓
เสร็จสิ้น
```

**วิธีใช้:**
1. เลือกเวิร์กโฟลว์ "สร้างโพสต์โซเชียล"
2. กรอก Input:
   - หัวข้อ: "เทรนด์ AI ในปี 2026"
   - โทนเสียง: "มืออาชีพ แต่เข้าถึงง่าย"
   - กลุ่มเป้าหมาย: "นักธุรกิจ"
3. กำหนดงบประมาณ: 300 เครดิต
4. คลิก "Start"
5. รอระบบสร้างข้อความและรูป
6. เมื่อมีการแจ้งเตือน ให้เข้าไปอนุมัติ
7. ตรวจสอบข้อความและรูปภาพ
8. คลิก "อนุมัติ" ระบบจะส่งโพสต์อัตโนมัติ

---

### ตัวอย่างที่ 2: วิเคราะห์ข้อมูลและสรุปรายงาน

**เวิร์กโฟลว์:**
```
เริ่มต้น
  ↓
Read File: อ่านไฟล์ข้อมูล
  ↓
LLM: วิเคราะห์ข้อมูล
  ↓
LLM: สร้างกราฟและแผนภูมิ
  ↓
LLM: เขียนสรุปรายงาน
  ↓
Approval Gate: ตรวจสอบรายงาน
  ↓
Send Email: ส่งรายงานให้ผู้บริหาร
  ↓
เสร็จสิ้น
```

**วิธีใช้:**
1. เลือกเวิร์กโฟลว์ "วิเคราะห์และสรุปรายงาน"
2. กรอก Input:
   - อัปโหลดไฟล์ CSV หรือ Excel
   - ระบุประเด็นที่สนใจ
   - ระบุผู้รับรายงาน (อีเมล)
3. กำหนดงบประมาณ: 800 เครดิต
4. คลิก "Start"
5. รอระบบวิเคราะห์และสร้างรายงาน
6. อนุมัติรายงานก่อนส่ง
7. ระบบส่งอีเมลพร้อมไฟล์แนบอัตโนมัติ

## คำถามที่พบบ่อย (FAQ)

### ❓ งานหยุดทำงานด้วยข้อความ "Budget Exceeded" ทำไงดี?

**สาเหตุ**: เครดิตที่กำหนดไว้หมดก่อนงานเสร็จ

**วิธีแก้:**
1. ตรวจสอบเครดิตคงเหลือในบัญชี
2. เพิ่มเครดิต หรือ
3. รันเวิร์กโฟลว์ใหม่ โดยกำหนดงบประมาณเพิ่มขึ้น

**คำแนะนำ:**
- เวิร์กโฟลว์ที่ใช้ LLM หลายครั้ง ควรกำหนดงบสูงกว่า 500 เครดิต
- เวิร์กโฟลว์ที่สร้างรูปหรือวิดีโอ ควรกำหนดงบสูงกว่า 1,000 เครดิต

---

### ❓ คำขออนุมัติหายไป หรือหาไม่เจอ

**สาเหตุ**: คำขออนุมัติหมดอายุ (Expired)

**วิธีแก้:**
1. เช็คใน Dashboard ส่วน "Expired Approvals"
2. เวิร์กโฟลว์จะหยุดทำงานโดยอัตโนมัติ
3. ต้องรันเวิร์กโฟลว์ใหม่ตั้งแต่ต้น

**คำแนะนำ:**
- คำขออนุมัติมีอายุ 1 ชั่วโมง (ค่าเริ่มต้น)
- ถ้าต้องการเวลามากกว่า ให้แจ้งผู้ดูแลระบบตั้งค่า

---

### ❓ เวิร์กโฟลว์ล้มเหลว (Failed) ต้องทำยังไง?

**ขั้นตอนตรวจสอบ:**
1. คลิกที่การ์ดงานเพื่อดูรายละเอียด
2. อ่านข้อความ Error
3. ตรวจสอบสาเหตุที่พบบ่อย:
   - ❌ **"Disallowed tools found"** - เวิร์กโฟลว์ใช้เครื่องมือที่ไม่อนุญาต
   - ❌ **"Prompt injection detected"** - มีข้อความที่ระบบตรวจจับว่าอันตราย
   - ❌ **"Graph cycle detected"** - เวิร์กโฟลว์มีการวนซ้ำไม่รู้จบ
   - ❌ **"Too many nodes"** - มีโหนดมากเกิน 100 โหนด

**วิธีแก้:**
- แก้ไขเวิร์กโฟลว์ตามข้อความ Error
- ถ้าไม่แน่ใจ ติดต่อผู้ดูแลระบบ

---

### ❓ อยากให้เวิร์กโฟลว์ทำซ้ำหลายครั้ง ทำยังไง?

**ใช้โหนด Loop:**
1. ลากโหนด "Loop" มาวางใน Canvas
2. ตั้งค่า:
   - **จำนวนรอบ**: เช่น 10 ครั้ง
   - **เงื่อนไขหยุด**: ถ้ามี (เช่น "หยุดเมื่อได้ผลลัพธ์ที่พอใจ")
3. เชื่อมโหนดที่ต้องการให้ทำซ้ำ เข้ากับ Loop
4. ระบบจะทำงานวนซ้ำตามจำนวนที่กำหนด

**ข้อจำกัด:**
- Loop ซ้อน Loop ได้สูงสุด 3 ชั้น
- Loop หนึ่งรอบทำได้สูงสุด 100 ครั้ง

---

### ❓ ต้องการให้งานแยกทางตามเงื่อนไข ทำได้ไหม?

**ใช้โหนด Conditional:**
1. ลากโหนด "Conditional" มาวาง
2. ตั้งเงื่อนไข เช่น:
   - "ถ้าคะแนนมากกว่า 80"
   - "ถ้าผลลัพธ์มีคำว่า 'อนุมัติ'"
3. เชื่อมเส้นออก 2 ทาง:
   - เส้นสีเขียว: เงื่อนไขเป็นจริง
   - เส้นสีแดง: เงื่อนไขเป็นเท็จ
4. เชื่อมเส้นแต่ละทางไปยังโหนดถัดไปตามที่ต้องการ

## เคล็ดลับการใช้งาน

### ✨ เคล็ดลับที่ 1: ใส่จุดอนุมัติก่อนงานสำคัญ

❌ **ไม่ควร:**
```
LLM: เขียนอีเมล → Send Email: ส่งทันที
```

✅ **ควร:**
```
LLM: เขียนอีเมล → Approval Gate: ตรวจสอบ → Send Email: ส่ง
```

**เหตุผล**: ป้องกันความผิดพลาด เช่น ส่งอีเมลผิดคน หรือเนื้อหาผิด

---

### ✨ เคล็ดลับที่ 2: ตั้งงบประมาณอย่างสมเหตุสมผล

📊 **แนวทาง:**
- เวิร์กโฟลว์ง่ายๆ (2-3 ขั้นตอน): 100-300 เครดิต
- เวิร์กโฟลว์ปานกลาง (4-6 ขั้นตอน): 300-800 เครดิต
- เวิร์กโฟลว์ซับซ้อน (7+ ขั้นตอน): 800-2,000 เครดิต
- มี Loop หรือสร้างรูป/วิดีโอ: +50% จากค่าปกติ

**ตัวอย่าง:**
- "เขียนบทความ 1 เรื่อง" → 200 เครดิต
- "สร้างโพสต์พร้อมรูป 10 โพสต์" → 1,500 เครดิต

---

### ✨ เคล็ดลับที่ 3: ตั้งชื่อและคำอธิบายที่ชัดเจน

❌ **ชื่อไม่ดี**: "เวิร์กโฟลว์ 1", "ทดสอบ", "Test Flow"

✅ **ชื่อดี**:
- "สร้างบทความ SEO พร้อมรูปประกอบ"
- "วิเคราะห์ข้อมูลยอดขายและสร้างรายงาน"
- "สร้างโพสต์โซเชียล 10 โพสต์พร้อมกำหนดเวลาโพสต์"

**เหตุผล**: หาง่าย เข้าใจง่าย ไม่สับสน

---

### ✨ เคล็ดลับที่ 4: ทดสอบก่อนใช้งานจริง

**วิธีทดสอบ:**
1. สร้างเวิร์กโฟลว์ใหม่
2. ตั้งงบประมาณเล็กน้อย (เช่น 50 เครดิต)
3. ใช้ข้อมูลทดสอบ (ไม่ใช่ข้อมูลจริง)
4. รันและดูว่าทำงานถูกต้องหรือไม่
5. แก้ไขจุดที่ผิดพลาด
6. ทดสอบซ้ำจนมั่นใจ
7. จึงค่อยใช้ข้อมูลจริง

---

### ✨ เคล็ดลับที่ 5: ระบุความเสี่ยงตรงตามความเป็นจริง

**ระดับความเสี่ยงควรเป็น:**
- 🟢 **ต่ำ** - อ่านข้อมูล, ประมวลผลภายใน, ไม่มีผลกระทบภายนอก
- 🟡 **ปานกลาง** - ส่งอีเมลจำนวนน้อย, เขียนไฟล์
- 🟠 **สูง** - ส่งอีเมลจำนวนมาก, เรียก API ภายนอก, ใช้เงินจริง
- 🔴 **วิกฤต** - ลบข้อมูล, เปลี่ยนแปลง configuration, รันโค้ด

**เหตุผล**: ทำให้ผู้อนุมัติระมัดระวังตามควร

## การรักษาความปลอดภัย

### 🔒 สิ่งที่ระบบป้องกันอัตโนมัติ

✅ **Prompt Injection** - ระบบตรวจจับและบลอกข้อความที่พยายามหลอกให้ AI ทำผิด
✅ **เครื่องมือที่อันตราย** - ห้ามใช้เครื่องมือที่รันโค้ดหรือเข้าถึงระบบโดยตรง
✅ **การใช้ทรัพยากรเกินจำกัด** - จำกัดจำนวนโหนด, Loop ซ้อน Loop
✅ **งบประมาณ** - หยุดอัตโนมัติถ้าใช้เกินที่กำหนด
✅ **ข้อมูล Tenant** - แยกข้อมูลของแต่ละองค์กร ไม่ปะปนกัน

### 🛡️ สิ่งที่ผู้ใช้ควรระวัง

⚠️ **อย่าใส่ข้อมูลส่วนตัวลงใน Prompt** - เช่น รหัสผ่าน, เลขบัตรเครดิต
⚠️ **ตรวจสอบก่อนอนุมัติ** - อ่านรายละเอียดให้ครบก่อนคลิก "อนุมัติ"
⚠️ **ระวัง Loop ไม่รู้จบ** - ตั้งเงื่อนไขหยุดที่ชัดเจน
⚠️ **เก็บประวัติการอนุมัติ** - เขียน Comment ทุกครั้งเพื่อตรวจสอบย้อนหลังได้
