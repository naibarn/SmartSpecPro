# วางแผนสอดแทรกสินค้าละครแนวตั้ง — วิธีใช้

สอดแทรกสินค้าในตอนอย่างเป็นธรรมชาติโดยไม่อ้างสรรพคุณเกินจริง

สกิลนี้เป็นส่วนหนึ่งของไปป์ไลน์ตอนละครแนวตั้ง จะไม่ทำงานอัตโนมัติจากแชท และไม่เรียกใช้ผู้ให้บริการที่มีค่าใช้จ่ายเอง ผลลัพธ์เป็น JSON แบบมีโครงสร้างที่แดชบอร์ดนำไปแสดงเป็นพรอมป์ คำเตือน และการซ่อมแซม
