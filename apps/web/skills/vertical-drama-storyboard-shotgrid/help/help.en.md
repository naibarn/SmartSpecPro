# Vertical Drama Storyboard Shotgrid — Help

Convert an episode script into exactly 9 key vertical storyboard shots in a 3x3 grid (imported storyboard-shotgrid-skill).

This skill is part of the Vertical Drama episode pipeline. It does not auto-trigger from chat and never bills or calls paid providers on its own. Outputs are structured JSON that the Dashboard presents as prompts, warnings, and repair actions.
