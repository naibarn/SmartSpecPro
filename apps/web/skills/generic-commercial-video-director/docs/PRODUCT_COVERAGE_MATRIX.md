# Product Demonstration Coverage Matrix — v4

| Product family | Correct-use focus | Mechanism issue | Recommended visual explanation | Preferred production split |
|---|---|---|---|---|
| Shampoo / cream / cosmetics | dispense/apply to correct body area | texture/contact | macro insert, literal demo, optional before/after | mostly generated plate; exact packshot in post |
| Floor / surface cleaner | correct target surface, apply/wipe/scrub sequence | cleaning action may be partly invisible | cleaning-lift, before/after, macro | physical plate + subtle explanatory overlay |
| Washing machine | load/close/select/start | internal drum/agitation/spin | cutaway, motion trace, time compression | appliance plate + cutaway/graphics |
| Vacuum cleaner | correct contact with debris/surface | suction path hidden | particle/airflow path, cleaning proof | plate + tracked explanatory overlay |
| Air conditioner / fan / purifier | activate/set/use correctly | airflow/temp/particles invisible | airflow streamlines, thermal gradient, particle flow | clean plate + post VFX |
| Smartphone / tablet | correct hardware handling and supported feature flow | UI/text fidelity | virtual screen, UI replacement, callout | clean device plate + exact UI composite |
| Laptop / software / SaaS | supported workflow | digital behavior | UI composite, data overlay | screen capture/composite + presenter/VO |
| Power tools | grip/position/activation | internal rotation + material contact | motion trace, cutaway | physical action plate + safety-aware callouts |
| Food / beverage | supported prep/serve/consume | texture/steam/flow | macro, time compression | mostly literal plate |
| Toys | correct play affordance | product motion | motion trace/callout if needed | mostly literal plate |
| Vehicle | correct operation | hidden system behavior | motion trace, data callout | vehicle plate + overlays |

## Rule

The taxonomy is not exhaustive. Unknown products are resolved from:
1. observed form factor,
2. user description,
3. source-of-truth references,
4. verified research,
5. category convention only as a provisional fallback.

Every product-specific feature visualization requires evidence binding.
