# ตรวจจับคนในภาพสำหรับระบุผู้พูด

Skill นี้อ่านภาพ Start frame ที่อนุมัติแล้วและส่งกรอบตำแหน่งพร้อมคำบรรยายของคนที่มองเห็น ขั้นเทียบกับโปรไฟล์ตัวละครในตอนอาจบันทึกผลจับคู่ผู้พูดที่มั่นใจและไม่กำกวมให้อัตโนมัติ ผู้ใช้เปลี่ยนคนที่บันทึกไว้ได้ การตรวจจับนี้ไม่ผูกบทพูดเองและไม่เพิ่มตัวละครถาวรในคลัง

แต่ละคำตอบของโมเดลจะรายงานจำนวน token ระบบคิดเครดิตต่อการเรียก skill ตามราคาที่ตั้งไว้ โดยไม่เกินเครดิตต้นทุนโมเดลที่วัดได้ ยอดเครดิตที่รายงานตรงกับยอดที่หักจริง และจะเริ่มตรวจจับเมื่อผู้ใช้กดเท่านั้น
