# Detect people for speaker mapping

This skill analyzes an approved Start Frame and returns visible people with normalized image regions and distinguishing appearance cues. A separate episode-profile matching step can automatically save confident, unambiguous speaker matches. You can change any saved selection. Detection itself never assigns dialogue or creates permanent character records.

Each model response reports token usage. The credit ledger charges each skill run using its configured skill price, capped by the measured model-work credits. Reported credits match the amount actually deducted. Detection runs only after you request it.
