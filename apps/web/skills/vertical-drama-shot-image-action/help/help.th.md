# แต่งพรอมป์ภาพสำหรับแอคชันช็อตเดี่ยวละครแนวตั้ง

สกิลนี้แต่งพรอมป์สร้างภาพสุดท้ายสำหรับแอคชันภาพช็อตเดี่ยวแบบเรียกใช้ตามต้องการ
ในไปป์ไลน์ละครแนวตั้ง:

- **`multi_angle_grid`** — ภาพเดียวที่มีกริด 3x3 (9 ช่อง) ของฉากเดียวกัน
  ถ่ายจากมุมกล้อง 9 มุมที่ต่างกัน เพื่อให้ผู้ใช้เลือกมุมที่ถูกใจที่สุด
- **`repair`** — นำคำสั่งแก้ไขที่ผู้ใช้พิมพ์เอง มาปรับพรอมป์ภาพปัจจุบันของช็อตนั้น
  โดยคงรายละเอียดอื่นทั้งหมดไว้เหมือนเดิม

สกิลนี้ถูกเรียกโดยตรงจาก `server/services/verticalDramaShotImageAction.ts`
(เรียกจาก `generateStartFrameAngleVariations` และ `repairShotImage` ใน
`server/routers/verticalDramaEpisodes.ts`) ไม่ใช่จากแชทหรือการตรวจจับอัตโนมัติ
