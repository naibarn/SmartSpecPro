# Automotive Reference Storyboard

This skill was generated from the furniture-reference-storyboard operating pattern and rewritten for ยานยนต์.

It preserves the current product reference as the source of truth for:

- exact product category and subtype
- shape, silhouette, and physical proportions
- countable components and small construction details
- material class, texture, finish, and pattern scale
- physical markings, labels, tags, package text, and brand marks
- realistic product scale and use context

The skill defaults to image-only output. Added visible text is controlled by `image_text_mode`, `image_text_language`, and `image_text_custom_language`.
