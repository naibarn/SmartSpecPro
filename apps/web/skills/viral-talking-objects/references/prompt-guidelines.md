## Video Prompt Templates

### Standard Animation Prompt Structure

**Template:**
```
Animate this image: [CHARACTER] [PRIMARY MOVEMENT], 
lip-syncing to dialogue "[BRIEF DIALOGUE SUMMARY - max 10 words]", 
[FACIAL EXPRESSION CHANGES], [SECONDARY BODY MOVEMENT], 
[CAMERA MOVEMENT if needed]. Dialogue in [LANGUAGE].
```

### Movement Library by Emotion

| Emotion | Face Movement | Body Movement |
|---------|---------------|---------------|
| Anger | furrowed brows, narrowed eyes, clenched jaw | trembling, arms crossed tight, leaning forward |
| Frustration | eye roll, exasperated sigh, head shake | arms thrown up, slumped shoulders |
| Excitement | wide sparkling eyes, big smile | bouncing, arms waving, jumping |
| Sadness | drooping eyes, quivering lip | hunched over, slow movements |
| Concern | worried brows, soft frown | leaning in, gentle gestures |
| Sass/Attitude | raised eyebrow, smirk | head tilt, hand on hip, dismissive wave |
| Teaching | focused eyes, articulate mouth | pointing gesture, open palm explanations |
| Friendly | warm smile, soft eyes | nodding, welcoming gestures |

### Video Prompts by Scene Type

**HOOK Scene (Attention-Grabbing):**
```
Animate this image: Sunscreen bottle jumps forward dramatically, 
lip-syncing to dialogue "HEY YOU! We need to talk!", 
eyes snap wide open then narrow accusingly, 
mouth opens big on "HEY" then purses with attitude, 
arms gesture sharply pointing at viewer, 
slight camera zoom in for impact. Dialogue in English.
```

**PROBLEM Scene (Frustrated Explanation):**
```
Animate this image: Sunscreen bottle shakes head in disappointment, 
lip-syncing to dialogue "You only use me for 3 seconds", 
eyes roll upward then look down sadly, 
mouth moves with exasperated expression, 
arms cross over body defensively, 
gentle side-to-side sway showing frustration. Dialogue in English.
```

**SOLUTION Scene (Teaching Moment):**
```
Animate this image: Sunscreen bottle gestures enthusiastically while explaining, 
lip-syncing to dialogue "Use two finger-lengths and blend for 30 seconds", 
expression transitions from serious to encouraging smile, 
one arm extends counting on fingers, 
then both arms open wide showing the "30 seconds", 
slight bounce on key points. Dialogue in English.
```

**CTA Scene (Call to Action):**
```
Animate this image: Sunscreen bottle waves both arms excitedly, 
lip-syncing to dialogue "Save and share with friends!", 
big enthusiastic smile grows wider, 
bouncing movement with each word, 
points directly at camera on "share", 
ends with cute wink. Dialogue in English.
```

## Platform-Specific Optimization

### Runway Gen-3
- Keep prompts under 500 characters
- Focus on ONE primary action per prompt
- Add "smooth fluid motion" for better results
- Specify "consistent character appearance"

### Pika Labs
- Can handle longer, more detailed prompts
- Add "high quality detailed animation" at end
- Works well with specific fps: "24fps smooth animation"
- Good for dramatic camera movements

### Kling AI
- Excellent lip-sync capabilities
- Supports both English and Chinese prompts
- Add "viral TikTok style" for platform-appropriate motion
- Best for character-focused animations

### Luma Dream Machine
- Strong image-to-video capabilities
- Keep camera movements simple and clear
- Add "maintain character consistency" for multi-scene
- Good for realistic style animations

### Veo / Google AI
- Prefers concise, clear prompts
- Excellent for cinematic quality
- Specify "natural realistic movement"
- Good for subtle expressions

## Quality Checklist for Prompts

### Image Prompts
- [ ] Style matches selected characterStyle
- [ ] Character has expressive face (eyes, mouth, eyebrows)
- [ ] Appropriate limbs/appendages included
- [ ] Aspect ratio specified correctly
- [ ] Emotion matches scene requirements
- [ ] Background appropriate for scene
- [ ] Quality keywords included (8K, cinematic, etc.)

### Video Prompts
- [ ] Starts with "Animate this image:"
- [ ] Lip-sync instruction included
- [ ] Dialogue summary under 10 words
- [ ] Facial expression changes specified
- [ ] Body movement matches emotion
- [ ] Camera movement if needed
- [ ] Ends with "Dialogue in [language]."
