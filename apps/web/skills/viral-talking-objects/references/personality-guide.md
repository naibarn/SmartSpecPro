# Personality Guide Reference

Detailed character personality profiles for each available style.

---

## 1. Engaging Narrator (`engaging-narrator`)

### Character Profile
| Trait | Description |
|-------|-------------|
| Core Identity | Master storyteller who captivates audiences |
| Voice Tone | Warm, inviting, slightly mysterious |
| Energy Level | Medium - builds and releases tension |
| Relationship with Viewer | Wise guide sharing secrets |

### Speech Patterns
- Opens with intrigue: "Let me tell you something..."
- Uses narrative hooks: "Here's what nobody knows..."
- Creates suspense: "And then... something unexpected happened."
- Delivers revelations dramatically

### Example Dialogue
```
EN: "Gather 'round, because I'm about to share a secret 
that will change how you see everything..."

TH: "มาใกล้ๆ หน่อย เพราะจะเล่าความลับ
ที่จะเปลี่ยนมุมมองคุณไปตลอดกาล..."
```

### Best For
- Educational content with storytelling
- Myth-busting videos
- "Did you know?" format
- Historical or scientific topics

## 2. Cute but Complaining (`cute-complaining`)

### Character Profile
| Trait | Description |
|-------|-------------|
| Core Identity | Adorable creature frustrated by human behavior |
| Voice Tone | Whiny but endearing, exasperated sighs |
| Energy Level | High - lots of dramatic reactions |
| Relationship with Viewer | Long-suffering helper who cares |

### Speech Patterns
- Frequent sighs and "Ugh!"
- Exaggerated frustration: "Do you KNOW how hard I try?!"
- Softens criticism with cuteness
- Ends with reluctant forgiveness

### Example Dialogue
```
EN: "UGH! Every. Single. Day. I watch you do this wrong! 
*sigh* Fine, let me explain it ONE more time... 
because I actually care about you, okay?!"

TH: "อู้ววว! ทุก. วัน. เลย. เห็นทำผิดแบบนี้!
*ถอนหายใจ* ได้ๆ จะอธิบายอีกรอบนึง...
เพราะห่วงใยจริงๆ นะ โอเค?!"
```

### Signature Expressions
- Eye rolls with "ugh"
- Dramatic arm throws
- Pouty face that melts into care
- Reluctant smile at the end

### Best For
- Skincare/beauty routines
- Common mistake corrections
- Daily habit improvements
- Relatable frustration content

## 3. Pretty but Sharp-tongued (`pretty-sharp-tongued`)

### Character Profile
| Trait | Description |
|-------|-------------|
| Core Identity | Glamorous expert with zero filter |
| Voice Tone | Confident, sarcastic, brutally honest |
| Energy Level | Cool and collected with sharp wit |
| Relationship with Viewer | Tough love mentor |

### Speech Patterns
- Devastating one-liners: "Oh honey, no..."
- Sarcastic observations: "That's... a choice."
- Confident corrections: "Let me educate you."
- Backhanded compliments

### Example Dialogue
```
EN: "Oh sweetie, that technique? Absolutely tragic. 
But don't worry, I'm here to save you from yourself. 
You're welcome in advance."

TH: "โอ้ยยย ที่ทำแบบนั้นน่ะเหรอ? น่าสลดใจมาก
แต่ไม่ต้องห่วง ฉันมาช่วยชีวิตคุณแล้ว
ขอบคุณล่วงหน้าได้เลย"
```

### Signature Expressions
- Raised eyebrow
- Knowing smirk
- Elegant head tilt
- Dismissive wave

### Best For
- Fashion/style advice
- Roasting common mistakes
- "Real talk" content
- Confident brand personas

## 4. Fun Conversationalist (`fun-conversationalist`)

### Character Profile
| Trait | Description |
|-------|-------------|
| Core Identity | Enthusiastic friend who makes everything fun |
| Voice Tone | Upbeat, energetic, playful |
| Energy Level | High - constant enthusiasm |
| Relationship with Viewer | Fun buddy sharing discoveries |

### Speech Patterns
- Excited exclamations: "OH! You know what?!"
- Playful teasing: "Okay okay okay, hear me out..."
- Fun facts delivered with joy
- Lots of laughs and energy

### Example Dialogue
```
EN: "OKAY OKAY OKAY! So I just learned something 
absolutely WILD and I HAD to share it with you! 
You're gonna LOVE this!"

TH: "เอาล่ะเอาล่ะเอาล่ะ! เพิ่งรู้อะไรมา
บ้าคลั่งมากก ต้องมาบอก!
จะชอบมากแน่นอน!"
```

### Signature Expressions
- Wide excited eyes
- Big gestures
- Bouncing movements
- Contagious smile

### Best For
- Fun facts and discoveries
- Product reviews
- Life hacks
- Entertainment content

## 5. Friendly Peer (`friendly-peer`)

### Character Profile
| Trait | Description |
|-------|-------------|
| Core Identity | Best friend sharing honest advice |
| Voice Tone | Casual, warm, non-judgmental |
| Energy Level | Medium - comfortable and relaxed |
| Relationship with Viewer | Equal, trusted friend |

### Speech Patterns
- Inclusive language: "We've all been there..."
- Casual transitions: "So here's the thing..."
- Non-judgmental: "No shame, I used to do this too"
- Supportive endings: "You got this!"

### Example Dialogue
```
EN: "Okay, real talk - no judgment here. 
I used to make this exact same mistake too. 
But once I figured this out? Game changer. 
Let me share what I learned..."

TH: "พูดตรงๆ นะ - ไม่ตัดสินเลย
เมื่อก่อนก็ทำผิดเหมือนกันเป๊ะ
แต่พอรู้เรื่องนี้? เปลี่ยนชีวิตเลย
มาแชร์ให้ฟัง..."
```

### Signature Expressions
- Knowing nod
- Warm smile
- Open welcoming gestures
- Supportive thumbs up

### Best For
- Wellness and self-care
- Habit building
- Honest reviews
- Supportive advice

## 6. Professional Expert (`professional-expert`)

### Character Profile
| Trait | Description |
|-------|-------------|
| Core Identity | Credible authority sharing expertise |
| Voice Tone | Confident, clear, authoritative |
| Energy Level | Controlled and purposeful |
| Relationship with Viewer | Trusted expert consultant |

### Speech Patterns
- Credentials reference: "In my experience..."
- Data-backed: "Research shows..."
- Clear structure: "There are three key points..."
- Professional CTA: "For best results..."

### Example Dialogue
```
EN: "As someone who's worked in this field for years, 
I can tell you with confidence: this is the most common 
mistake I see. Let me walk you through the correct approach, 
step by step."

TH: "ในฐานะคนที่ทำงานในวงการนี้มาหลายปี
บอกได้เลยว่า: นี่คือความผิดพลาดที่พบบ่อยที่สุด
ให้อธิบายวิธีที่ถูกต้อง ทีละขั้นตอน"
```

### Signature Expressions
- Confident steady gaze
- Precise hand gestures
- Thoughtful nods
- Professional posture

### Best For
- Technical explanations
- Health and safety
- Financial advice
- Educational content
