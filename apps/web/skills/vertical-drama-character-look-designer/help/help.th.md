# นักออกแบบลุคตัวละคร

สร้างแพ็กลุคสำหรับตัวละครเดิมให้เหมาะกับฉาก ทั้งเสื้อผ้า ทรงผม แต่งหน้า รองเท้า
เครื่องประดับ และอุปกรณ์ประกอบ โดยรักษาใบหน้า รูปร่าง และอัตลักษณ์เดิม
หากบทระบุการเปลี่ยนช่วงวัย ระบบจะส่งช่วงวัยมาตรฐานให้ LLM ได้แก่ ทารก เด็กเล็ก
เด็กมัธยม นักศึกษา ผู้ใหญ่ หรือผู้สูงวัย และต้องคงความเป็นตัวละครเดิมไว้
Skill นี้ออกแบบข้อมูลลุค ไม่ได้สร้างภาพตัวละครโดยตรง
