# วางแผนลุคตัวละครและฝาแฝดสำหรับละครแนวตั้ง

สกิลนี้อ่านเนื้อเรื่องที่ร่างไว้ทั้งซีซันและรายชื่อตัวละครปัจจุบันของซีรีส์ละครแนวตั้ง
แล้วเสนอ:

- **ชุดลุคเปลี่ยนเครื่องแต่งกาย (outfit)** — ตัวละครที่เนื้อเรื่องแสดงในชุดต่าง ๆ
  ที่เกิดขึ้นซ้ำ (เช่น ชุดนอนที่บ้าน ชุดนักเรียน ชุดทำงาน) จะถูกสร้างเป็นตัวละครแยก
  ที่หน้าเหมือนเดิมทุกประการ ต่างแค่ทรงผม/เครื่องแต่งกาย/การแต่งหน้า
- **ชุดลุคช่วงวัยต่างกัน (age_stage)** — ตัวละครที่เนื้อเรื่องแสดงในช่วงวัยที่ต่างกันจริง
  (ฉากย้อนอดีตวัยเด็ก หรือข้ามเวลาไปหลายปี) จะถูกสร้างเป็นตัวละครแยกที่ใบหน้า
  เปลี่ยนไปตามวัยได้ตามธรรมชาติ (อ้างอิงตัวละครต้นแบบแบบหลวม ๆ ไม่ล็อกหน้าตายตัว)
- **การตรวจจับฝาแฝด** — เมื่อเนื้อเรื่องระบุชัดเจนว่ามีพี่น้องที่หน้าเหมือนกัน
  จะเสนอสร้างตัวละครใหม่แยกอิสระ โดยฝาแฝดแท้จะระบุให้ใช้ใบหน้าเดียวกับต้นทาง
  ส่วนฝาแฝดเทียมจะไม่ระบุการใช้ใบหน้าร่วมกัน

สกิลนี้ถูกเรียกใช้อัตโนมัติเป็นขั้นตอนสุดท้ายของงาน
"ปรับปรุงบทละครให้มีความสมบูรณ์" โดย
`server/services/verticalDramaCharacterVariantPlanner.ts`
(เรียกจาก `runImproveScriptJob` ใน `server/services/verticalDramaImproveScript.ts`)
ไม่ใช่จากแชทหรือการตรวจจับอัตโนมัติ และเป็นขั้นตอนแบบ best-effort —
หากขั้นตอนนี้ล้มเหลว จะไม่ทำให้งานปรับปรุงบททั้งหมดล้มเหลวตาม
