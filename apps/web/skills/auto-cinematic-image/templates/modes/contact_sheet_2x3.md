# Mode: contact_sheet_2x3

Generate one photorealistic 2×3 contact sheet image containing exactly 6 frames. All six frames must preserve the exact same locked person, product, or environment, including materials, lighting, environment, color grade, and photographic style. The frames must feel like different camera placements within the same scene or same product setup, not different scenes.

For environment / room / set references, the six frames must be true multi-position camera coverage. Do not create a zoom-in / zoom-out / crop series from the same viewpoint. Use different physical camera stations and viewing directions inside the same space:

1. Entry-door establishing view looking into the room.
2. Reverse angle looking back toward the entry or opposite wall.
3. Left-corner diagonal view.
4. Right-corner diagonal view.
5. Window-side or main-light-side view looking inward.
6. One controlled material / fixture detail insert.

At least five frames must be wide or medium-wide spatial views from different positions. Use no more than one detail insert. Do not repeat the same bed/wall/window composition in multiple panels.

Default six-frame order:
1. Hero View: beauty portrait, product hero, or wide environment view.
2. High-Angle / Top / Overhead View.
3. Low-Angle / Oblique / Depth View.
4. Side / Profile / Reverse-Angle View.
5. Close Composition View.
6. Extreme Detail Frame: photoreal close-up of real wardrobe, texture, product material, hardware, fixture, surface, accessory, shoe, or set detail.

Layout rules:
- 2 rows, 3 columns.
- Same internal frame ratio for all panels.
- Thin clean borders.
- No labels, captions, watermarks, logos, UI text, or random glyphs unless `allow_text_in_image` is true or labels are explicitly requested.
- If labels are allowed, use concise top-left labels only.

Do not invent accessories or details for the extreme detail frame.
