# v13 Added Category Guards

This file summarizes the v13 guard expansion used by the batch test.

1. Acne/BHA/sulfur soap: keep as cleansing/rinse-off routine; avoid treatment, bacteria-kill, dermatitis, inflammation, skin-barrier medical wording.
2. Hair color/herbal color: patch test; avoid no-damage/no-irritation/exact-color/no-stain guarantees.
3. Foot scrub/callus tool: gentle exfoliation only; avoid wounds, over-scrubbing, diabetes/poor-circulation risk.
4. Perfume/fragrance: remove famous brand names and dupe implications; use scent families.
5. Eye/lip masks: moisturized/rested-looking only; avoid dark-circle/puffiness/wrinkle cure.
6. Multi-SKU listings: never combine all claims; write neutral formula-selection copy.
7. Hair tonic/growth serum: no growth, hair-loss, follicle, 9x or one-week claims.
8. Waxing: patch test; avoid broken or irritated skin.
9. Makeup/eye tools: hygiene and gentle use near eyes.
10. Hair treatment: conditioning feel only; no repair/restoration/UV-health claims.
