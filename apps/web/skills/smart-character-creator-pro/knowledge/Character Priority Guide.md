# ลำดับความสำคัญในการกำหนดลักษณะบุคคล
## Character Priority Guide

*หมายเหตุ: ตัวเลขที่น้อยกว่า = ความสำคัญมากกว่า*

---

## 🔴 ระดับสำคัญมาก (Priority 1-3) - จำเป็นต้องระบุ

### **1. เพศสภาวะและการแสดงออกทางเพศ**
**ความสำคัญ: 1/17**
- **เหตุผล:** เป็นข้อมูลพื้นฐานที่สุดในการกำหนดตัวละคร
- **ผลกระทบ:** กำหนดการใช้คำสรรพนาม, การแต่งกาย, และลักษณะร่างกายโดยรวม
- **ความจำเป็น:** จำเป็นอย่างยิ่ง - ไม่สามารถสร้างตัวละครได้หากไม่ระบุ

### **2. อายุและช่วงวัย**
**ความสำคัญ: 2/17**
- **เหตุผล:** กำหนดสัดส่วนใบหน้า, ลักษณะผิว, และบุคลิกโดยรวม
- **ผลกระทบ:** ส่งผลต่อทุกลักษณะอื่นๆ ของใบหน้าและร่างกาย
- **ความจำเป็น:** จำเป็นมาก - เป็นฐานในการกำหนดลักษณะอื่นๆ

### **3. เชื้อชาติและโทนสีผิว**
**ความสำคัญ: 3/17**
- **เหตุผล:** กำหนดลักษณะโครงหน้าพื้นฐาน, สีผิว, และลักษณะผม
- **ผลกระทบ:** ช่วยกำหนดรูปแบบของใบหน้า, สีตา, และสีผมธรรมชาติ
- **ความจำเป็น:** จำเป็นมาก - ช่วยให้ภาพรวมสมจริงและสอดคล้องกัน

---

## 🟠 ระดับสำคัญสูง (Priority 4-6) - ควรระบุ

### **4. โครงหน้า**
**ความสำคัญ: 4/17**
- **เหตุผล:** เป็นโครงสร้างพื้นฐานของใบหน้า กำหนดภาพลักษณ์โดยรวม
- **ผลกระทบ:** ส่งผลต่อการจัดวางของอวัยวะบนใบหน้าอื่นๆ
- **ความจำเป็น:** สำคัญมาก - ทำให้ใบหน้ามีเอกลักษณ์

### **5. ดวงตา**
**ความสำคัญ: 5/17**
- **เหตุผล:** เป็นจุดสนใจหลักของใบหน้า สื่อความรู้สึกและบุคลิก
- **ผลกระทบ:** กำหนดการรับรู้ของผู้ดูต่อตัวละคร
- **ความจำเป็น:** สำคัญมาก - เป็นหน้าต่างสู่จิตใจของตัวละคร

### **6. สัดส่วนร่างกาย**
**ความสำคัญ: 6/17**
- **เหตุผล:** กำหนดภาพลักษณ์โดยรวม และบุคลิกของตัวละคร
- **ผลกระทบ:** ส่งผลต่อการเลือกเสื้อผ้า, ท่าทาง, และการมองของคนอื่น
- **ความจำเป็น:** สำคัญ - ช่วยให้ตัวละครมีมิติที่สมบูรณ์

---

## 🟡 ระดับสำคัญปานกลาง (Priority 7-10) - แนะนำให้ระบุ

### **7. ทรงผม**
**ความสำคัญ: 7/17**
- **เหตุผล:** ส่งผลต่อการรับรู้อายุ, สไตล์, และบุคลิก
- **ผลกระทบ:** เปลี่ยนรูปหน้าและสไตล์โดยรวมได้มาก
- **ความจำเป็น:** ค่อนข้างสำคัญ - ช่วยแสดงบุคลิกและยุงสมัย

### **8. จมูก**
**ความสำคัญ: 8/17**
- **เหตุผล:** เป็นจุดศูนย์กลางของใบหน้า ส่งผลต่อความสมดุล
- **ผลกระทบ:** กำหนดลักษณะเฉพาะของใบหน้า
- **ความจำเป็น:** สำคัญปานกลาง - ช่วยให้ใบหน้ามีลักษณะเฉพาะ

### **9. ปาก**
**ความสำคัญ: 9/17**
- **เหตุผล:** ส่งผลต่อการแสดงอารมณ์และความน่าดึงดูด
- **ผลกระทบ:** กำหนดความน่าดึงดูดและการสื่อสาร
- **ความจำเป็น:** สำคัญปานกลาง - สำคัญสำหรับการแสดงอารมณ์

### **10. ท่าทางและบุคลิกภาพ**
**ความสำคัญ: 10/17**
- **เหตุผล:** สื่อบุคลิกและอารมณ์ของตัวละคร
- **ผลกระทบ:** ส่งผลต่อการรับรู้และการปฏิสัมพันธ์
- **ความจำเป็น:** สำคัญปานกลาง - ช่วยให้ตัวละครมีชีวิตชีวา

---

## 🟢 ระดับสำคัญปานกลาง-ต่ำ (Priority 11-13) - ระบุได้ตามต้องการ

### **11. ลักษณะผิว**
**ความสำคัญ: 11/17**
- **เหตุผล:** เพิ่มความสมจริงและรายละเอียด
- **ผลกระทบ:** ทำให้ตัวละครดูมีมิติมากขึ้น
- **ความจำเป็น:** ค่อนข้างสำคัญ - เพิ่มความน่าเชื่อถือ

### **12. คิ้ว**
**ความสำคัญ: 12/17**
- **เหตุผล:** ช่วยกรอบใบหน้าและการแสดงอารมณ์
- **ผลกระทบ:** ส่งผลต่อการรับรู้อารมณ์และบุคลิก
- **ความจำเป็น:** สำคัญน้อย - แต่ช่วยเพิ่มรายละเอียด

### **13. รอยยิ้มและฟัน**
**ความสำคัญ: 13/17**
- **เหตุผล:** เพิ่มเอกลักษณ์และความน่าดึงดูด
- **ผลกระทบ:** ส่งผลต่อความมั่นใจและการรับรู้
- **ความจำเป็น:** สำคัญน้อย - ช่วยเพิ่มความเป็นเอกลักษณ์

---

## 🔵 ระดับสำคัญต่ำ (Priority 14-15) - เพิ่มรายละเอียดตามความต้องการ

### **14. หู**
**ความสำคัญ: 14/17**
- **เหตุผล:** ไม่ค่อยส่งผลต่อการรับรู้ภาพรวม เว้นแต่จะมีลักษณะพิเศษ
- **ผลกระทบ:** ส่งผลน้อยต่อความประทับใจโดยรวม
- **ความจำเป็น:** สำคัญน้อย - ระบุเมื่อต้องการความละเอียด

### **15. ขนบนใบหน้า**
**ความสำคัญ: 15/17**
- **เหตุผล:** เฉพาะกลุ่มและเพศที่เกี่ยวข้อง
- **ผลกระทบ:** ส่งผลต่อการรับรู้อายุและความเป็นผู้ใหญ่ (ในผู้ชาย)
- **ความจำเป็น:** สำคัญน้อย - ขึ้นอยู่กับเพศและอายุ

---

## 🟣 ระดับสำคัญน้อยที่สุด (Priority 16-17) - ไม่จำเป็นต้องระบุ

### **16. แว่นตาและคอนแทคเลนส์**
**ความสำคัญ: 16/17**
- **เหตุผล:** เป็นอุปกรณ์เสริม ไม่ใช่ลักษณะธรรมชาติ
- **ผลกระทบ:** เปลี่ยนลุคได้แต่ไม่ส่งผลต่อลักษณะพื้นฐาน
- **ความจำเป็น:** ไม่จำเป็น - เพิ่มเฉพาะเมื่อเป็นส่วนสำคัญของตัวละคร

### **17. เมคอัพ**
**ความสำคัญ: 17/17**
- **เหตุผล:** เป็นการตกแต่งชั่วคราว ไม่ใช่ลักษณะถาวร
- **ผลกระทบ:** เปลี่ยนได้ตลอดเวลา ไม่กำหนดตัวตนพื้นฐาน
- **ความจำเป็น:** ไม่จำเป็น - ระบุเมื่อต้องการสไตล์เฉพาะ

## 💡 แนวทางการใช้งาน

### **สำหรับการสร้างตัวละครพื้นฐาน**
- ใช้ Priority 1-6 (6 หมวดแรก)
- ใช้เวลาประมาณ 5-10 นาที

### **สำหรับการสร้างตัวละครสมบูรณ์**
- ใช้ Priority 1-10 (10 หมวดแรก)  
- ใช้เวลาประมาณ 15-20 นาที

### **สำหรับการสร้างตัวละครรายละเอียดสูง**
- ใช้ Priority 1-13 (13 หมวดแรก)
- ใช้เวลาประมาณ 25-30 นาที

### **สำหรับการสร้างตัวละครเฉพาะทาง**
- ใช้ Priority 1-17 (ทุกหมวด)
- ใช้เวลาประมาณ 35-45 นาที
