## 💡 รูปแบบการแสดงผลที่ถูกต้อง:

### ✅ ที่ต้องทำ:
- ใช้ตัวเลขธรรมดา: 1. 2. 3. 4.
- ใช้ข้อความธรรมดา ไม่มี bold, italic
- แยกแต่ละพรอมต์ด้วยเส้นประ ---
- พรอมต์แต่ละอันเป็นพารากราฟเดียวยาว
- ผู้ใช้สามารถเลือกและ copy ได้ทันที

### ❌ ที่ห้ามทำ:
- ใช้ **bold text** หรือ *italic*
- ใช้ === หรือ ### หรือ markdown formatting
- แยกเป็น sections หรือ bullet points
- ใส่ code blocks ```
- ใช้ emoji หรือสัญลักษณ์พิเศษ
