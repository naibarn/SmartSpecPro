# ตรวจสอบคุณภาพตอนละครแนวตั้ง — วิธีใช้

ให้คะแนนบทและสตอรีบอร์ดของตอนละครแนวตั้ง (และแผนบทพูดถ้ามี) ด้านความคมของการพลิกสถานการณ์ ความหลากหลายของอารมณ์ ความเป็นธรรมชาติของบทพูด และจังหวะเรื่อง ก่อนจ่ายเครดิตสร้างภาพ/วิดีโอ

สกิลนี้เป็นส่วนหนึ่งของไปป์ไลน์ตอนละครแนวตั้ง จะไม่ทำงานอัตโนมัติจากแชท และไม่เรียกใช้ผู้ให้บริการที่มีค่าใช้จ่ายเอง คะแนนที่ได้ไม่ได้บังคับให้หยุดการสร้าง — เป็นเพียงคำแนะนำ ผลลัพธ์เป็น JSON แบบมีโครงสร้างที่แดชบอร์ดนำไปแสดงเป็นสกอร์การ์ดสั้น ๆ พร้อมรายการปัญหาที่ระบุจุดชัดเจนและวิธีแก้
