# Output Contract — Vertical Drama Preset Synthesizer

Every output must validate against `schemas/output.schema.json` before being returned to the Create Series Wizard.

Required top-level fields: title, category, logline, mainPlot, seasonArc, tone, cliffhangerStyle, characters, visualBible, mixRecipe, warnings, contract_version.

The output is a draft only. It is not persisted as a global or private preset unless another workflow explicitly saves it later.
