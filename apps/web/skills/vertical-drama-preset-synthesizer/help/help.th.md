# ผู้ช่วยผสมแนวเรื่องซีรีย์แนวตั้ง

สกิลนี้ช่วยผสมหลายรสชาติเรื่อง เช่น ร้านอาหาร บริการลูกค้า ธุรกิจท้องถิ่น และชีวิตประจำวัน ให้กลายเป็นพรีเซ็ตซีรีย์แนวตั้งหนึ่งชุดที่แก้ต่อได้

สกิลนี้ไม่ทำงานอัตโนมัติ ไม่สร้างภาพ/วิดีโอ และคืนผลลัพธ์เป็น JSON ที่ระบบตรวจสอบก่อนนำไปแสดงในหน้า Create Series Wizard
