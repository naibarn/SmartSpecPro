Smart AI Hub Worker Runtime Pack third-party notices

This runtime pack bundles third-party components used only for local HyperFrames
render execution.

- HyperFrames and @hyperframes/producer are bundled from their npm packages.
- Node.js is bundled for Linux x64 execution inside WSL2.
- Chrome for Testing / Chrome Headless Shell is bundled for browser rendering.
- FFmpeg and ffprobe are bundled from BtbN FFmpeg-Builds GPL Linux x64 static
  builds. The bundled FFmpeg build includes NVIDIA NVENC encoders.
- Noto/Liberation/Ubuntu-compatible fonts are bundled for Thai-capable text
  rendering.

Redistribution of this runtime pack must continue to preserve the applicable
upstream licenses and notices for each bundled component.
