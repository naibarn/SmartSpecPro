# Test Design — Autonomous Completion & Gap Closure

| Requirement | Observable behavior | Test level/location | RED evidence | GREEN command | Residual boundary |
|---|---|---|---|---|---|
| Recoverable gaps do not become terminal blockers | Structured policy emits a repair/substitute/verify/queue action for each recoverable failure class | Python unit: `skills/orchestra/tests/test_lifecycle_policy.py` and 20 case fixture | Pre-change inspection found only declarative route scenarios; no executable lifecycle policy oracle existed | `python3 -m unittest discover -s skills/orchestra/tests -v` | Tests decision kernel, not stochastic adherence by every host LLM |
| True blockers are narrow and evidenced | Only enumerated external/security/product-authority cases produce `TRUE_BLOCKER` | Python unit boundary cases | Evaluator absent | Same command | Does not grant external credentials or legal/security acceptance |
| Stall detection changes strategy | Repeated same blocker with no delta marks `STALLED_STRATEGY`, prohibits previous strategy | Python unit transition cases | Evaluator absent | Same command | Multi-session persistence remains an orchestration artifact responsibility |
| Independent work continues | Waiting work with ready independent unit selects it only when prerequisites are complete and evidence is fresh | Python unit WorkUnit selection case | Pre-change implementation had no readiness evaluator | Same command | Does not execute the work unit or verify external predicate adapters |
| Resume is actionable | Resume chooses the exact next ready unit and preserves unresolved requirements, tried/prohibited strategies, and wait predicates | Python unit resume case | Pre-change implementation had no resume-capsule behavior | Same command | Does not prove external runner wakeup delivery |
| Completion states remain distinct | Completion rejects missing/empty authoritative ledger, missing per-requirement evidence, stale verification, unintegrated changes, and required-but-missing deployment/acceptance | Python unit completion cases | Pre-change implementation had no completion oracle | Same command | Does not verify real deployment, provider, browser, or customer acceptance evidence |
