NEW TOPIC CREATION WORKFLOW
================================================================================

Step 1: Create English markdown
        ├─ File: docs/help/en/{slug}.md
        ├─ Add YAML frontmatter (slug, title, icon, section, order, pages, tags)
        └─ Add markdown content

Step 2: Create Thai markdown (1:1 translation)
        ├─ File: docs/help/th/{slug}.md
        ├─ Same slug as English version
        └─ All text translated to Thai

Step 3: Update manifest (if new section needed)
        ├─ Check _manifest.json
        └─ Add new section entry if not present (most new features use "advanced")

Step 4: (Optional) Add i18n keys for ChatHelpDialog
        ├─ Only if feature should appear in help.* modal
        ├─ locales/en.ts: add "help.{feature}.* keys
        ├─ locales/th.ts: add "help.{feature}.* Thai translations
        └─ Update ChatHelpDialog.tsx to render new section

Step 5: Test
        ├─ Restart server (cache TTL = 5 min)
        ├─ Query help.getTopic("your-slug", "en")
        ├─ Verify HTML renders
        └─ Verify search index includes topic

================================================================================
CACHE BEHAVIOR
================================================================================

Components: All cached with 5-minute TTL
├─ Manifest cache
├─ Topic cache (per slug + locale)
├─ Search index cache
└─ Contextual topics cache

Cache keys: "{locale}:{slug}" or "{locale}:manifest" or "{locale}:search"

Clear cache:
├─ Restart server (automatic)
├─ Wait 5 minutes (automatic)
└─ Manual: Not exposed via API (service caches in-memory)

Development:
└─ After editing docs/help/en/chat.md → Restart server to see changes
